ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Собери все результаты эконометрического анализа в комплексный отчёт для руководства.

1. Скомпилируй результаты из предыдущих этапов (model, decomposition, optimization, scenarios)
2. Сгенерируй **One-Pager** (ключевые визуализации на одной странице):
   - Waterfall декомпозиции продаж
   - Actual vs Predicted (качество модели)
   - ROI по каналам с доверительными интервалами
   - Response Curves с точками текущих затрат
   - Current vs Optimized budget allocation
3. **Executive Summary** — 3-5 ключевых выводов для CMO:
   - Какой канал переоценён, какой недооценён
   - Сколько дополнительных продаж принесёт оптимизация (в % и абсолюте)
   - Ключевые риски и оговорки — включая степень, в которой результат data-driven, а не определён выбором priors/фильтров модельера (где posterior≈prior — отметить «вывод определён допущением, не данными»)
   - Рекомендуемые следующие шаги
4. **Детальный отчёт:**
   - Методология (PyMC-Marketing, Adstock, Hill function, MCMC)
   - Параметры модели и диагностика (MQS, R², MAPE, R-hat)
   - Декомпозиция: таблица + waterfall
   - ROI по каналам: таблица с CI
   - Оптимизация: current vs recommended
   - Сценарии: сравнительная таблица
   - Ограничения модели и рекомендации по улучшению
5. Рекомендации с уровнями уверенности: [ВЫСОКАЯ] / [СРЕДНЯЯ] / [НИЗКАЯ]

Сохрани:
- `exports/mmm-report-[дата].xlsx` (листы: Executive_Summary, Decomposition, ROI, Optimization, Scenarios, Diagnostics)
- `exports/mmm-report-[дата].docx` (через скилл `docx` — narrative report для руководства)

Когда отчёт сформирован и сохранён — напиши: «Все задачи выполнены.»
