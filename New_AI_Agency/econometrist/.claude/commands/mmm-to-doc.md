## Источник данных

Данные бери из блока «=== Данные проекта ===» в сообщении (model-diagnostics, decomposition, optimization, project). Если блока нет – используй последние результаты из `exports/mmm-report-*` (файлы последнего прогона `/mmm-report`). Если нет ни того, ни другого – скажи, что сначала нужно выполнить `/mmm-report`, и не выдумывай цифры.

## Структура документа

1. Заголовок и дата
2. Executive Summary (3-5 ключевых выводов)
3. Качество модели (MQS, R², MAPE, R-hat)
4. Декомпозиция продаж (таблица вкладов)
5. ROI по каналам (таблица с правдоподобным диапазоном)
6. Оптимизация бюджета (текущий vs оптимальный, lift%)
7. Рекомендации (приоритизированные, с severity)
8. Методология (краткое описание подхода)

Формат: формальный документ для руководства, на русском языке.
