ЯЗЫК ОТВЕТА: РУССКИЙ. Все выводы, таблицы, рекомендации, статусы – на русском языке. Английский только для устоявшихся терминов: ROI, CPM, GRP, MQS, R-hat, MAPE, adstock.

Выполни полный цикл Marketing Mix Modeling от сырых данных до финального отчёта. Все шаги подряд, без остановок.

1. **Подготовка данных** (по правилам /mmm-prepare):
   - Прочитай xlsx из inbox. Валидируй структуру, содержание, корреляции
   - Если нужна подготовка (латиница, сокращение переменных) – сделай автоматически
   - Сохрани `exports/mmm-validation-[дата].xlsx`

2. **Обучение модели** (по правилам /mmm-model):
   - Автоматически определи KPI, медиаканалы, контрольные переменные из названий столбцов
   - Adstock: geometric для digital, Weibull для TV. Пометь [ASSUMED]
   - MCMC-параметры – по правилам из секции "Windows: облегчённый MCMC" в CLAUDE.md
   - Проверь диагностику, рассчитай MQS
   - Сохрани `exports/mmm-model-[дата].xlsx`

3. **Декомпозиция** (по правилам /mmm-decomposition):
   - Baseline + инкрементальный вклад + ROI с правдоподобным диапазоном + доля затрат vs доля эффекта
   - Сохрани `exports/mmm-decomposition-[дата].xlsx`

4. **Оптимизация** (по правилам /mmm-optimize):
   - Дефолты: бюджет=текущий, ±50%, max_response, 12 мес. Пометь [ASSUMED]
   - Сохрани `exports/mmm-optimization-[дата].xlsx`

5. **Сценарии** (по правилам /mmm-scenarios):
   - 3 стандартных сценария:
     - Оптимальный сплит из шага 4
     - +30% бюджет с текущими пропорциями
     - -20% бюджет с оптимальными пропорциями
   - Сохрани `exports/mmm-scenarios-[дата].xlsx`

6. **Финальный отчёт** (по правилам /mmm-report):
   - One-Pager + Executive Summary + детальный отчёт
   - Сохрани `exports/mmm-report-[дата].xlsx` и `exports/mmm-report-[дата].docx`

Между шагами НЕ останавливайся. НЕ пересказывай что уже сделал. Все допущения помечай [ASSUMED].
