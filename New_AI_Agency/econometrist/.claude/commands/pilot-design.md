ЯЗЫК ОТВЕТА: РУССКИЙ. Все выводы, таблицы, рекомендации, статусы – на русском языке. Английский только для устоявшихся терминов: ROI, CPM, GRP, MQS, R-hat, MAPE, adstock.

Спроектируй 4–6-недельный пилот для валидации оптимизационных рекомендаций pipeline на практике, прежде чем полным бюджетом переходить на новый сплит.

## Зачем

MMM – статистическая модель. Её прогноз может быть оптимистичным из-за переобучения, unit-mixing, изменений рынка. Пилот – способ проверить гипотезу «новый микс даёт +N%» на ограниченном бюджете и в ограниченный период, прежде чем коммитить весь план.

## Источники

Данные проекта приложены к сообщению блоком «=== Данные проекта ===» (model-diagnostics, decomposition, optimization, project). Из него бери:
- optimization – текущее vs оптимальное распределение, lift%
- decomposition – текущий ROI каналов, unit_smell
- project – unit_costs (если заданы); media-колонки – в validation

Если нужного файла в блоке нет – скажи прямо, какого шага pipeline не хватает; не выдумывай.

## Структура ответа

**1. Контекст пилота (2–3 строки)**
- Ожидаемый lift из оптимизации (+N%)
- Основные сдвиги: канал A +X%, канал B −Y%
- Риски: thin data / unit mixing / перенасыщение (если smell-flags есть)

**2. Параметры пилота (компактно, списком)**
- **Длительность:** 4–6 недель (4 если динамичная категория, 6 если TV/brand)
- **Бюджет пилота:** 20–30% от общего медиа-бюджета, остальные 70–80% продолжают идти по текущему плану (контрольная группа во времени)
- **Гео-сплит** (альтернатива, если есть гео-таргетинг): регионы РАНДОМНО распределить на контроль/тест со стратификацией по размеру – группировка по размеру до распределения сужает диапазон оценки эффекта ≈ на 10% (Vaver & Koehler 2011). ДО запуска оценить мощность: хватит ли числа регионов и длительности, чтобы увидеть эффект заявленного размера (ширина диапазона зависит от длины теста, доли тестовых регионов, разницы в тратах). Результат анализировать регрессией pre/test-периодов (TBR), не наивным сравнением средних. Применимо в РФ для digital (Яндекс.Директ, VK Реклама – есть гео-таргетинг); для федерального ТВ без региональных вставок метод неприменим
- **Метрики:** KPI модели (продажи/упаковки/SOM) понедельно, plus awareness/brand health если доступны

**3. Как измерять (4–5 строк)**
- **Что сравниваем:** KPI в пилоте vs forecast из модели при новом миксе
- **Статистическая значимость:** короткий пилот не даст правдоподобный диапазон уже 10%. Значимые отклонения – выше 15%, ищи такие
- **Чего ждать:** внутри ожидаемого правдоподобного диапазона – модель валидна, бюджет можно масштабировать. Ниже нижней границы – модель переоценила эффект, откатиться к текущему плану
- **Контрфактуальная оценка (когда гео-сплита нет, напр. федеральное ТВ):** оцени инкрементальный эффект через синтетический контроль – модель прогнозирует, «что было бы без нового микса», по непострадавшим рядам (другие бренды категории, немедийные регионы); эффект = факт минус контрфактуал, с расширяющимся во времени правдоподобным диапазоном, значим пока кумулятивный диапазон не пересёк ноль (Brodersen 2015, CausalImpact/BSTS). Не требует рандомизации – работает и для единой нацио-кампании
- **После пилота – замкни цикл:** передай фактический результат обратно в модель (перезапусти /mmm-model с informative prior `[CALIBRATED]` по факту пилота, mmm-model п.3.5), чтобы следующая оптимизация опиралась на подтверждённый эффект, а не только на исторические данные

**4. Чек-лист запуска**
```
☐ Зафиксировать текущие unit_costs (чтобы потом не смешивать)
☐ Отключить другие эксперименты на период пилота
☐ Предупредить агентство о новых ставках
☐ Настроить еженедельный отчёт по фактическому KPI
☐ Определить критерий отката (−X% от ожидания → stop)
```

**5. Красные флаги – когда НЕ запускать пилот**
- Ratio < 2 – модель ненадёжна, пилот ничего не докажет
- Lift < 2% – шум перекроет эффект, пилот бессмыслен
- Unit mixing в оптимизации – сначала добавить unit_costs и пересчитать
