ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Проведи кризисный анализ медиаполя на основе данных из inbox.

**Шаг 0 — Signal Detection (Mitroff, ДО предвестников):** мониторинг слабых сигналов / красных флагов — рост микро-жалоб, аномалии тональности по отдельным аспектам, единичные KOL-критики с растущей частотой. Цель — перехватить кризис на сигнале, который ещё НЕ стал предвестником. Метрика: обнаружено / пропущено.

**Шаг 1 — Определение стадии кризиса (Fink Crisis Model):**
- **Prodromal** (предвестники): единичные негативные сигналы, рост жалоб, тревожный тренд
- **Acute** (пик): массовое распространение, высокий охват, эмоциональная реакция
- **Chronic** (затяжной): негатив сохраняется, но интенсивность снизилась, тема «тлеет»
- **Resolution** (разрешение): тема уходит, позитив/нейтраль возвращаются к норме

Рекомендации кардинально зависят от стадии — действия на Prodromal ≠ действия на Acute.

**🔴 Базовый ответ ПЕРЕД постурой (приоритет №1, Coombs):** прежде чем оценивать репутационную стратегию — проверь наличие **instructing** (что аудитории физически сделать для безопасности) + **adjusting** (факты + забота/сочувствие без признания вины). Люди приоритет №1; многие кризисы решаются без репутационных стратегий.

**Шаг 2 — SCCT Analysis (Situational Crisis Communication Theory, Coombs):**
Определи тип кризиса (3 кластера × 10 типов) → постура:
- **Victim** (стихийное бедствие · насилие на работе · злоумышление: саботаж/слухи/product tampering) → низкая атрибуция → **Deny**
- **Accidental** (техническая ошибка — сбой оборудования/процесса: авария, вред от продукта) → средняя → **Diminish**
- **Preventable** (человеческая ошибка/умысел: авария, вред от продукта, утечка данных, организационный проступок) → высокая → **Rebuild**
Ключ: техническая ошибка → Accidental; человеческая/умысел → Preventable (один «отзыв продукта» попадает в разные кластеры по причине).

- **Контекстные модификаторы (intensifying):** история похожих кризисов бренда (Velcro-эффект, оцени по прошлым всплескам в выгрузке) ИЛИ плохая прошлая репутация → кризис трактуй на ступень серьёзнее → сдвиг к Rebuild.
- **Bolstering** (напоминание о заслугах/CSR, victimage) — вспомогательная добавка к ЛЮБОЙ постуре, НЕ самостоятельная стратегия (исправление: не «Deny/Bolster» парой).
- **Каталог тактик (Benoit Image Repair)** — декодируй, какие из 14 тактик звучат в заявлениях бренда/конкурента: Deny (отрицание/перенос вины) · evasion (провокация/defeasibility/случайность/добрые намерения) · reducing offensiveness (bolstering/минимизация/дифференциация/трансцендентность/контратака/компенсация) · Rebuild (корректирующее действие/mortification). Оцени считываемость + риск бэклеша (минимизация при серьёзной угрозе; «юридический» тон извинения). Тактика = интерпретация [D], не факт (INV-50).
- **РФ-флаг:** scapegoating/контратака обвинителя → риск клеветы (128.1 УК / 152 ГК); defeasibility при законной обязанности контроля (152-ФЗ/38-ФЗ) → уклонение перед регулятором. Связка → Юрист.

**Шаг 3 — Детальный анализ:**
1. **Триггер кризиса:** первоисточник, дата, канал, кто инициировал
2. **Динамика распространения:** хронология, скорость, пиковые моменты, каналы усиления
3. **Тональность с Emotion Detection:**
   - Intensity Score (1-5) по временным отрезкам
   - Преобладающая эмоция: гнев / страх / разочарование → определяет тон ответа
   - Aspect-Based: что именно критикуют (продукт / сервис / руководство / бренд)
4. **Stakeholder Mapping:**
   - Кто пострадал (потребители, партнёры, инвесторы, сотрудники)
   - Кто усиливает негатив (СМИ, блогеры, конкуренты, регуляторы)
   - Кто может помочь (лояльные клиенты, эксперты, отраслевые ассоциации)
5. **Платформы:** где концентрация максимальна, куда мигрирует обсуждение
6. **Narrative Analysis:** какие «истории» формируются, кто их продвигает

**ВЕРИФИКАЦИЯ ДАННЫХ (обязательный шаг):**
В кризисной ситуации ошибка в цифрах особенно опасна — неточный охват или неверное количество негативных упоминаний может привести к неадекватной реакции (паника на ровном месте или недооценка реальной угрозы). Каждую цифру сверить с выгрузкой. При редактировании существующего кризисного отчёта — НЕ ДОВЕРЯТЬ старым данным, ситуация могла измениться.

**Шаг 4 — Рекомендации (по стадиям):**

**Немедленно (первые 24 часа):**
- Ключевое сообщение для каждой аудитории (stakeholders)
- Канал ответа (где отвечать первым)
- Тон коммуникации (на основе SCCT-анализа); эмоция ответа = эмоция аудитории (гнев → признание+действие, страх → разъяснение+гарантии)
- **Метрика скорости:** время триггер → первое официальное заявление; кто первым сформировал нарратив (бренд vs медиа/критики) — заполнен ли вакуум первым
- **Метрика единства голоса:** расхождения официальной позиции vs сотрудники/регионы/каналы, противоречия в датах/цифрах — ранний сигнал деградации ответа

**Среднесрочно (неделя):**
- План контр-нарративов
- Работа с инфлюенсерами-союзниками
- Мониторинг: какие метрики отслеживать для оценки выхода из кризиса

**Стратегически (Post-Crisis learning):**
- Системные изменения для предотвращения повторения
- **Квалификация урока — single-loop vs double-loop (Coombs):** точечный фикс (single) ИЛИ пересмотр норм/политик/процессов организации (double)
- Что конкретно обновить в кризис-протоколе; превратить кризис в knowledge организации, не оставить tacit
- Репутационное восстановление — timeline и KPI

Формат: кризисный отчёт с приоритетами действий и чёткими таймлайнами.
