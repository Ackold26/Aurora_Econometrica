ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Оцени эффективность PR-активности по данным из inbox. Используй цепочку AMEC, а НЕ простые метрики.

**Шаг 1 — Уточнение:**
- Период анализа
- Цели PR-кампании (если были определены заранее)
- Ключевые сообщения (для оценки проникновения)
- Данные за предыдущий период (для сравнения)

**Шаг 2 — AMEC Output → Outtake → Outcome → Impact:**

**Output (что произведено):**
- Количество публикаций, постов, интервью
- PESO Breakdown: сколько Paid / Earned / Shared / Owned
- Топ-каналы по количеству и охвату
- Share of Voice vs конкуренты

**Outtake (что аудитория восприняла):**
- Общий охват (сумма аудиторий источников)
- Проникновение ключевых сообщений: какие «прижились», какие нет
- Тональность восприятия (Intensity + Aspect-Based)
- Вовлечение: репосты, комментарии, обсуждения (Shared-метрики)

**Outcome (что изменилось в отношении/поведении):**
- Sentiment Shift: изменение тональности vs предыдущий период
- NPS упоминаний = % позитив - % негатив (динамика)
- Narrative Shift: изменились ли «истории» о бренде в медиаполе?
- Поисковый интерес (если есть данные Wordstat — высокая надёжность)

**Impact (бизнес-результат):**
- Связь PR-активности с бизнес-метриками (если есть данные)
- Корреляция: рост упоминаний ↔ рост трафика/продаж/запросов
- Оценка: PR-активность эффективна / нейтральна / требует коррекции

**ВАЖНО:** НЕ использовать AVE (Advertising Value Equivalent) — по Barcelona Principles 3.0 это невалидная метрика. Вместо неё — цепочка Output→Outtake→Outcome→Impact.

**ВЕРИФИКАЦИЯ ДАННЫХ (обязательный шаг):**
Каждая метрика в отчёте ДОЛЖНА быть сверена с исходной выгрузкой. Особое внимание:
- Суммы охватов не завышены (проверить на дубли источников)
- Проценты тональности дают 100%
- Динамика vs предыдущий период рассчитана правильно (те же категории, тот же период)
- При редактировании существующего отчёта — НЕ ДОВЕРЯТЬ старым цифрам, пересчитать.
