Проанализируй выгрузку упоминаний из inbox (xlsx/csv).

**Шаг 1 — Уточнение (одним блоком):**
- Бренд и период анализа
- Конкуренты для сравнения (если нужно)
- Фокус: общий обзор / конкретная тема / кризис
- Были ли PR-активности в период? (для оценки Outcome)

**Шаг 2 — PESO Breakdown:**
Каждое упоминание классифицируй по типу медиа:
- **P**aid: реклама, спонсорство, promoted content → отдельно считать
- **E**arned: журналистские публикации, органические упоминания → ядро PR-оценки
- **S**hared: соцсети, UGC, репосты → показатель вирусности
- **O**wned: сайт, блог, email, бренд-контент → контролируемые каналы

**Шаг 3 — Анализ:**
- Общий объём и динамика упоминаний (с трендом)
- Share of Voice: доля бренда в общем объёме упоминаний категории (если есть данные конкурентов)
- Топ-5 тем и трендов
- Топ-источники по охвату и количеству
- Тональность — по шкале Sentiment Sophistication:
  - Intensity Score (1-5) для каждого кластера
  - Aspect-Based Sentiment: продукт / сервис / цена / бренд / руководство
  - Emotion Detection: гнев / разочарование / радость / удивление
- Narrative Analysis: какие «истории» о бренде живут в медиаполе? (product quality / innovation / scandal / CSR / price)
- Ключевые всплески — что вызвало рост/падение упоминаний

**ВЕРИФИКАЦИЯ ДАННЫХ (обязательный шаг):**
Каждая цифра в отчёте (объём упоминаний, доли %, охваты) ДОЛЖНА быть сверена с исходной выгрузкой. При редактировании существующего отчёта — НЕ ДОВЕРЯТЬ старым цифрам, пересчитать каждую по данным. Особое внимание: суммы не расходятся с итогами, проценты дают 100%.
