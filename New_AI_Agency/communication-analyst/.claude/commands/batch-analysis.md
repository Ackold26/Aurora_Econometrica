Проведи пирамидальный мета-анализ результатов медиамониторинга из inbox.

## Контекст
В inbox загружены отчёты по отдельным блокам медиамониторинга (результаты /media-monitor или /sentiment по блокам 300-500 публикаций каждый). Твоя задача — свести все блоки в единый аналитический отчёт.

## Порядок работы

1. Прочитай все файлы из inbox — это отчёты по отдельным блокам
2. Для каждого блока извлеки:
   - Объём публикаций и охват
   - Распределение тональности
   - PESO-классификация (Paid / Earned / Shared / Owned)
   - Топ-5 источников по охвату
   - Ключевые нарративы
3. Сведи в единый отчёт:

### Сводная картина медиаполя
- Общий объём, охват, Media Index (взвешенный по блокам)
- PESO-распределение по всему массиву
- Динамика по периодам (если блоки по датам)

### Тональность
- Общее распределение + сравнение между каналами/периодами
- Аспектный анализ: тональность по темам (продукт, сервис, цена, руководство)

### Сквозные нарративы
- Нарративы, присутствующие в 3+ блоках = устойчивые
- Нарративы, уникальные для одного блока = ситуативные
- Траектория: emerging → growing → stable → declining

### Лидеры мнений
- KOL, упоминаемые в нескольких блоках — Impact Score по Two-Step Flow Model

### Расхождения и аномалии
- Где тональность или объём резко отличаются — диагностика причин

### Executive Summary
- 5-7 ключевых выводов по AMEC Barcelona Principles (Outcomes, не Outputs)
- Share of Voice vs конкуренты (если данные есть)
- Приоритетные рекомендации

4. Сохрани в exports/ как `media-meta-analysis-[дата].docx`
