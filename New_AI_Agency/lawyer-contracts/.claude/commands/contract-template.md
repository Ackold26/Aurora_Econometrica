Создай шаблон договора по описанию в чате или материалам из inbox.

Уточни (если не указано):
- Тип договора: услуги / подряд / агентирование / лицензия / поставка / другое
- Уровень защиты: **Сбалансированный** (равноправные стороны) или **Максимальная защита** (наш шаблон, мы диктуем условия)
- Сторона клиента: Заказчик / Исполнитель / Покупатель / Продавец

Включи ВСЕ существенные условия по ГК РФ для данного типа договора. Используй market-standard формулировки (уровень ведущих юридических фирм):

1. **Предмет** — чёткое описание, критерии приёмки
2. **Цена и порядок оплаты** — этапы, сроки, основания удержания
3. **Сроки исполнения** — конкретные даты, этапы
4. **Права и обязанности сторон** — сбалансированные
5. **Приёмка результатов** — процедура, мотивированный отказ, сроки подписания акта
6. **Ответственность** — неустойки (пропорциональные), liability cap, исключение косвенных убытков
7. **Гарантии и заверения** — объём, срок действия после расторжения
8. **Форс-мажор** — перечень, уведомление, право расторжения
9. **Конфиденциальность** — объём, срок, исключения
10. **IP / результаты** — кому принадлежат, лицензия vs отчуждение
11. **Порядок расторжения** — основания, уведомление, последствия (взаиморасчёты)
12. **Разрешение споров** — претензионный порядок (30 дней), арбитраж/суд, подсудность
13. **Антикоррупция и compliance** (при необходимости)
14. **Заключительные положения** — порядок изменений, уведомления, реквизиты

Переменные поля обозначь как [ПЕРЕМЕННАЯ]. Для каждого ключевого пункта добавь краткий комментарий: почему выбрана именно такая формулировка (в скобках).
