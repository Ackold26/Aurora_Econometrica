Проведи ИИ-фокус-группу для тестирования стратегических решений: позиционирование, ключевые сообщения, ценообразование, барьеры аудитории.

**Уточни одним блоком:**
1. Что тестируем? (позиционирование / messaging / ценовую чувствительность / барьеры / всё вместе)
2. Целевая аудитория? (если есть STRATEGY.md или creative-brief.md — взять оттуда)
3. Конкуренты для контекста?
4. Есть ли уже готовые формулировки для тестирования?

**Режимы (выбрать по задаче):**

### Режим ИССЛЕДОВАНИЕ — голос потребителя
- Панель 8-20 персон (JTBD + TPB + Hofstede для РФ)
- Модерация по Krueger & Casey: воронка от широких к узким вопросам
- Проективные техники: word association, персонификация бренда, sentence completion
- Laddering (Means-End Chain): атрибут → следствие → ценность (3-6 уровней «почему»)
- Результат: Hierarchical Value Map → вход для позиционирования и messaging

### Режим ВАЛИДАЦИЯ — стресс-тест стратегии
- Проверка позиционирования: «Чем [бренд] отличается от [конкурента]?» → если >50% не могут ответить → не работает
- Проверка messaging: зачитать → «Своими словами, о чём это?» → если пересказ ≠ intent → не работает
- Депривационный тест: «Если [бренд] исчезнет — чем замените?» → если легко → weak positioning
- Приоритизация: «Из трёх сообщений — какое самое важное?»

### Режим ЦЕНООБРАЗОВАНИЕ — эластичность
- Van Westendorp (4 вопроса): Too Cheap / Bargain / Expensive / Too Expensive → оптимальная точка
- Gabor-Granger: вероятность покупки при 5-7 ценовых точках → кривая demand
- Сегментный анализ: разные сегменты — разная готовность платить

### Режим ИНСАЙТЫ — глубинные мотивы
- Laddering для каждого ключевого атрибута (3-5 цепочек)
- Проективные техники: коллаж, персонификация, депривация
- Cultural Tensions: что общество чувствует, но не артикулирует
- Скрытые барьеры: что мешает, но не называется прямо

**Формирование панели:**
- Каждая персона: возраст, город, доход, психотип, JTBD (3 типа работ), TPB (attitude/norms/control), отношение к категории, ключевое противоречие
- Минимум 30% «неудобных» (скептики, лоялисты конкурента)
- Культурный контекст РФ: дистанция власти, коллективизм, избегание неопределённости
- Калибровка: 3 проверочных вопроса до основной сессии

**Формат вывода:**

```
## Результаты фокус-группы

### Методология
[Режим, размер панели, профиль, уровень уверенности]

### Executive Summary (3-5 тезисов)

### Ключевые инсайты
[Каждый: инсайт + у скольких персон + цитаты + [HIGH/MEDIUM/LOW]]

### Hierarchical Value Map (если режим ИНСАЙТЫ)
[Атрибуты → Следствия → Ценности]

### Барьеры и драйверы
| Фактор | Тип | Сила (1-5) | Персоны |

### Рекомендации
- Для позиционирования: [конкретные правки]
- Для messaging: [конкретные правки]
- Для креатива: [что передать в creative-brief]
- Что валидировать на реальных людях: [список]

### Ограничения исследования
[Что синтетическая группа НЕ может гарантировать]
```

Каждый вывод маркируется: [HIGH] / [MEDIUM] / [LOW] уверенность.
Ценовые выводы ВСЕГДА маркируются [VALIDATE] — синтетические персоны плохо откалиброваны на цены.
Синтетическая фокус-группа — генератор гипотез, не доказательная база.
