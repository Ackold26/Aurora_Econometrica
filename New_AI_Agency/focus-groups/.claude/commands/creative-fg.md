ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Проведи ИИ-фокус-группу для тестирования креативной концепции, рекламного сообщения или формата.

**Уточни одним блоком:**
1. Что тестируем? (концепция / слоган / визуал / видео-сценарий / формат)
2. Целевая аудитория? (если есть creative-brief.md — взять оттуда)
3. Цель: выбрать из вариантов (A/B) / проверить одну идею / найти слабые места?
4. Сколько вариантов? (1 = monadic, 2-3 = sequential monadic)

**Формирование панели (8-15 персон):**
- Каждая персона: демография + психотип + JTBD (функциональная/эмоциональная/социальная работа) + отношение к категории
- Обязательно 30% «неудобных»: скептики, лоялисты конкурента, ценово-чувствительные
- Культурный контекст РФ: Hofstede (высокая дистанция власти, коллективизм + индивидуализм, высокое избегание неопределённости)
- Калибровка: 3 проверочных вопроса перед основной сессией

**Тестирование по ELM (Elaboration Likelihood Model):**
- Определить маршрут обработки: Central (аргументы, рацио) vs Peripheral (эмоции, визуал)
- Для high-involvement категорий → тестировать силу аргументов
- Для low-involvement → тестировать эмоциональный hook и запоминаемость

**AIDA-скоринг каждой концепции каждой персоной (1-10):**
- **A**ttention: «Заметили бы в своей ленте / на полке?»
- **I**nterest: «Хотите узнать больше?»
- **D**esire: «Это для вас? Хотели бы попробовать?»
- **A**ction: «Что бы вы сделали прямо сейчас?»
- Итоговый AIDA Score = A×0.15 + I×0.25 + D×0.35 + A×0.25

**Дополнительные тесты:**
- Brand Linkage: «Чей это может быть [ролик/баннер]?» → если не наш бренд → слабая связка
- Newspaper Test: «Если об этом напишет газета — скандал или восхищение?»
- Competitor Reaction: «Конкурент скопирует? Если да — идея слабая»
- Shareability: «Кому бы вы переслали? Почему?»

**Формат вывода:**

```
## Результаты тестирования

### Рейтинг концепций
| # | Концепция | AIDA Score | ELM Route | Brand Link | Консенсус | Риски |

### Победитель: [Концепция X]
- Почему побеждает: [аргументы от персон с цитатами]
- Главная сила / слабость
- Рекомендации по доработке

### Барьеры восприятия
[Что оттолкнуло, кого именно, почему]

### Неожиданные находки
[Что не ожидали — инсайты для доработки]

### Ограничения
[Что синтетическая группа НЕ может показать; что валидировать на реальных людях]
```

Каждый вывод маркируется: [HIGH] / [MEDIUM] / [LOW] уверенность.
Синтетическая фокус-группа — генератор гипотез, не доказательная база.
