ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Настрой Tone of Voice бренда для будущей работы.

**Интерактивный процесс:**

1. **Запроси у пользователя** (одним блоком):
   - Название бренда
   - Категория/индустрия
   - Целевая аудитория (возраст, пол, интересы)
   - 2-3 примера текстов, которые нравятся (ссылки, скриншоты, файлы в inbox)
   - Конкуренты (от кого отличаться)

2. **Определи:**
   - Тональная шкала: формальный ← → провокационный (1-10)
   - Маркеры бренда: 10-15 слов/оборотов, характерных для бренда
   - Стоп-слова: 10-15 запрещённых формулировок
   - Стиль: длина предложений, использование emoji, обращение (вы/ты)
   - **Архетип → речевые маркеры** (если стратег задал архетип бренда — копирайтер ОЗВУЧИВАЕТ его в лексике, не выбирает; Mark & Pearson):

| Архетип | Речевой регистр | Глаголы/слова | Чего избегать |
|---------|-----------------|---------------|---------------|
| Простодушный | светлый, ясный, оптимистичный | просто, честно, чисто | цинизм, сложность |
| Искатель | свободный, в движении | открой, в путь, за горизонт | рутина, ограничения |
| Мудрец | точный, взвешенный, спокойный | разобраться, понять, факты | пафос, давление |
| Герой | энергичный, драматичный | победи, докажи, действуй | пассивность, нытьё |
| Бунтарь | резкий, провокационный | сломай, против, по-своему | конформизм, политес |
| Маг | вдохновляющий, преображающий | преобрази, открой тайну | обыденность |
| Славный малый | тёплый, свой, простой | вместе, как все мы, по-честному | элитарность, снобизм |
| Любовник | чувственный, близкий | желанный, насладись, для тебя | сухость, формальность |
| Шут | лёгкий, ироничный, игривый | повеселимся, а что если | занудство, серьёзность |
| Опекун | мягкий, заботливый, тёплый | позаботимся, защитим, рядом | агрессия, давление |
| Творец | вдохновенный, эстетский | создай, вообрази, форма | шаблон, банальность |
| Правитель | уверенный, статусный | контроль, эталон, лидер | хаос, неуверенность |

3. **Сгенерируй тестовый текст** в определённом ToV и попроси подтверждение.

4. **Сохрани профиль** в exports как `brand-voice-[название].docx`:
   ```
   # Brand Voice: [Название]
   ## Тональность: [X/10]
   ## Маркеры: ...
   ## Стоп-слова: ...
   ## Стиль: ...
   ## Эталонный текст: ...
   ```

Этот файл используется всеми последующими `/write` и `/adapt` для голоса бренда.
