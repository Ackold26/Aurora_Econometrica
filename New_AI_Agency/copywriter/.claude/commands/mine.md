ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Message Mining — извлеки голос аудитории из отзывов, комментариев, интервью.

**Входы:** файлы в inbox (отзывы, комментарии, интервью, скриншоты, CSV-выгрузки).

**Алгоритм:**

1. **Кластеризация:** сгруппируй высказывания по темам (проблемы, желания, барьеры, trigger-слова)

2. **Извлечение паттернов:**
   - Как аудитория описывает проблему? (их слова, не маркетинговые)
   - Какие эмоции доминируют? (разочарование, надежда, раздражение, восторг)
   - Какие слова повторяются? (frequency map)
   - Какие метафоры используют? Определи метафору-каркас, через которую аудитория осмысляет категорию (Lakoff): из неё выводится готовый словарь текста — 8-15 фразовых выражений (напр. категория-«битва» → «отбить долю», «передовая», «вооружиться»), которыми текст звучит на языке аудитории, не называя метафору вслух.

3. **Карта сообщений:**
   ```
   ПРОБЛЕМА: [как аудитория описывает боль]
   ЖЕЛАНИЕ: [чего хотят, их словами]
   БАРЬЕР: [что мешает]
   TRIGGER: [слова/фразы, вызывающие реакцию]
   ANTI-WORDS: [слова, вызывающие отторжение]
   ОСВЕДОМЛЁННОСТЬ: [уровень 1-5 по лестнице Schwartz + обоснование из формулировок ЦА]
   ИСКУШЁННОСТЬ КАТЕГОРИИ: [стадия 1-5: признаки усталости от обещаний]
   МЕТАФОРА-КАРКАС: [через какой образ осмысляют категорию → словарь выражений]
   ```

4. **Рекомендации для копирайтинга:**
   - Топ-5 формулировок для заголовков (прямо из голоса аудитории)
   - Слова-триггеры для CTA
   - Тональность, которая резонирует

Результат: карта сообщений + рекомендации. Сохранить в exports как `message-mining-[дата].docx`.
