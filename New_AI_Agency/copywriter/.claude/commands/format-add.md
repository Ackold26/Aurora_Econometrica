Добавь новый формат контента для использования в `/write` и `/adapt`.

**Запроси у пользователя:**
1. Название формата (например: «карточка для Telegram», «баннер VK», «email-рассылка»)
2. Канал публикации
3. Ограничения: максимальная длина, структура (заголовок + body + CTA?), тон
4. Пример хорошего текста в этом формате (если есть)

**Сгенерируй спецификацию формата:**
```
# Формат: [Название]
- Канал: [где публикуется]
- Длина: [max символов]
- Структура: [обязательные элементы]
- Тон: [специфика для этого формата]
- Пример: [эталонный текст]
```

**Сохрани** в exports как `format-[название].docx`.

Этот файл будет использоваться при `/write` и `/pack` для точной адаптации под формат.
