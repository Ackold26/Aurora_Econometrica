Создай шаблоны безопасных рекламных формулировок на основе анализа материалов из inbox. Категории:

1. **Превосходство** — замена «лучший/первый/единственный» на безопасные альтернативы
2. **Гарантии** — как обещать результат без нарушения закона о рекламе
3. **Сравнение** — корректное сравнение с конкурентами
4. **Цены/скидки** — правильное оформление акций и спецпредложений
5. **Медицинские/фарма** — безопасные формулировки для health-тематик
6. **Финансовые** — корректные обещания доходности/условий
7. **Детская аудитория** — ограничения и безопасные формулы
8. **ОРД-маркировка** — как правильно оформить erid, маркировку «Реклама», указание рекламодателя

Для каждой категории:
- ❌ Опасная формулировка → ✅ Безопасная альтернатива (3-5 примеров)
- 📋 Ссылка на статью ФЗ «О рекламе» / КоАП
- ⚖️ Пример из практики ФАС: дело/решение, где аналогичная формулировка была наказана (типичные паттерны)
- 💰 Размер штрафа за нарушение

Примеры из практики ФАС (типичные решения):
- «Лучшие цены» без рейтинга → штраф 300 000 ₽ (суперлатив без доказательства)
- «Гарантия излечения» для БАД → штраф 500 000 ₽ (терапевтические заявления)
- Мелкий шрифт для ставки кредита → штраф 400 000 ₽ (сокрытие существенных условий)
