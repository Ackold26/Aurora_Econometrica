ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Разработай messaging framework по материалам из inbox.

**Шаг 1: Value Proposition Sharpening**
- 3 угла × ≤15 слов каждый
- Каждый угол — самостоятельная причина выбрать бренд

**Шаг 2: Message Hierarchy**
- Umbrella Message: одно сообщение для всех аудиторий и каналов (≤10 слов)
- Segment Messages: адаптация под каждый сегмент аудитории
- Channel Messages: адаптация под канал (digital, TV, print, OOH, social)
- Format Messages: адаптация под конкретный формат (story, post, banner, pre-roll)

**Шаг 3: Customer Journey Mapping**
Для каждого этапа воронки — своё сообщение:

| Этап | Цель сообщения | Тип контента | Пример hook |
|---|---|---|---|
| Awareness | Category Entry Point, brand recall | Эмоция, узнаваемость | «Знакомая ситуация?» |
| Consideration | RTB, социальное доказательство | Кейсы, сравнения | «Вот почему выбирают нас» |
| Decision | Конкретное предложение, urgency | Оффер, CTA | «Только до [дата]» |
| Advocacy | Shared values, community | UGC, stories, вовлечение | «Расскажи свою историю» |

**Приоритетные принципы влияния по этапу (Cialdini, Neidert Core Motives Model).** Психологический рычаг подбирается под цель сообщения, не интуитивно:
- **Awareness — выстраивание отношения:** reciprocation, liking, unity (расположить к источнику до убеждения).
- **Consideration — снятие неопределённости:** social proof, authority (доказать разумность выбора мнением многих / экспертов).
- **Decision — побуждение к действию:** consistency, scarcity (опереться на прежние обязательства + уникальность момента).

**Шаг 4: 24 Hooks** — выбери 5-7 с обоснованием для конкретного бренда.
**Чек-лист покрытия 7 принципов влияния (Cialdini).** Проверь, что набор сообщений задействует фундаментальные рычаги согласия, а не бьёт в один-два: reciprocation, liking, social proof, authority, scarcity, commitment & consistency, unity. Пробел по принципу — кандидат на доработку набора.
