ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Сгенерируй приложение к договору на основе медиаплана из inbox.

## Алгоритм работы

### Шаг 1. Определи входные файлы
В inbox должны быть:
- **Медиаплан** (.xlsx) — источник данных
- **Шаблон приложения** (.doc/.docx) — шаблон для заполнения

Если чего-то нет — спроси. Если шаблон не предоставлен, используй стандартную структуру приложения (6 разделов: Терминология, Предмет, Права и обязанности, Финансовые условия, Ответственность, Прочие условия).

### Шаг 2. Определи структуру медиаплана
Автоматически определи структуру по содержимому листов:
- **Детальный лист** — строки с площадками, форматами, бюджетами (может называться «Медиаплан», «МП», «План размещения» и т.п.)
- **Сводный лист** — итоговые KPI (может называться «Сводные данные», «СВОДНАЯ», «Summary» и т.п.)
- **Сплит бюджета** — помесячная разбивка (может называться «Сплит бюджета», «Бюджет» и т.п.)
Если структура нестандартная — покажи найденные листы и заголовки, спроси маппинг.

Прочитай шапку медиаплана и извлеки:
- Клиент / Рекламодатель
- Бренд
- Категория
- ЦА
- Период (старт — конец)

### Шаг 3. Извлеки данные из детального листа
Для каждой строки медиаплана извлеки:
1. Уровень воронки / Задача (для группировки)
2. Канал размещения
3. Площадка / Подрядчик / Инструмент
4. Таргетинг
5. Формат размещения
6. Старт и конец размещения
7. Объём закупки (число) и единица (показы/клики/прочтения/...)
8. Бюджет без НДС по строке

Агрегируй: если в МП несколько строк по одной площадке с одинаковым форматом — объедини в одну строку приложения (суммируя объёмы и бюджеты).

### Шаг 4. Извлеки и рассчитай финансовые показатели

**4.1. Извлеки все финансовые условия из медиаплана:**
- **АВ (агентская комиссия)** — ищи строки/колонки с АВ, агентской комиссией, АК, commission, fee. Может быть разным для разных строк/инструментов/подрядчиков — сохраняй построчную детализацию
- **Менеджмент** — может применяться только к определённым площадкам, ищи отдельные строки
- **Условия предоплаты** — процент и сроки, ищи в шапке или сводном листе
- **Ставка НДС** — может быть указана явно
- Если АВ уже включено в итоговые суммы медиаплана — не добавляй повторно, а выдели из итога

**4.2. Спрашивай ТОЛЬКО то, что не найдено в медиаплане.**
Покажи, что извлечено, и уточни только отсутствующие параметры.

**4.3. Расчёт:**
- **Стоимость с НДС** = бюджет без НДС × (1 + ставка НДС)
- **АВ по каждой строке** = бюджет строки × процент АВ для этого инструмента
- **Менеджмент** = бюджет × процент (если применимо)
- **Итого** = бюджет + АВ + менеджмент (всё с НДС)

### Шаг 5. Сформируй таблицу медиаплана для приложения
Колонки: №, Площадка, Таргетинг, Формат, Старт, Конец, Кол-во единиц, Единица, Стоимость до НДС, Стоимость с НДС

Строки группируй по бизнес-целям (уровням воронки):
- **Повышение узнаваемости** (Awareness)
- **Вовлечение ЦА** (Consideration / Engagement)
- **Конверсия / Покупка** (Conversion / Purchase)
- **Прочее** (Production, Analytics, Service)

### Шаг 6. Сформируй график оплат
Из листа со сплитом бюджета (помесячная разбивка):
- Помесячная разбивка бюджета
- Добавь АВ и менеджмент к каждому месяцу
- Рассчитай предоплаты (спроси процент, типовые: 50%, 70%)
- Укажи сроки оплат (спроси формат, типовые: предоплата за 10 р.д. до начала месяца)

### Шаг 7. Заполни шаблон и сгенерируй документ
Используй skill `docx` для генерации .docx файла. Сохрани в exports/.

### Шаг 8. Верификация (ОБЯЗАТЕЛЬНЫЙ — не пропускать)

**8.1. Построчная сверка сумм:**
Для КАЖДОЙ строки таблицы медиаплана в сгенерированном документе:
- Сверь «Стоимость до НДС» с исходной ячейкой в xlsx
- Сверь «Стоимость с НДС» = «Стоимость до НДС» × (1 + ставка НДС)
- Сверь объём закупки и единицу с исходными данными
- Выведи таблицу сверки: | Площадка | МП (xlsx) | Документ (docx) | Совпадение |

**8.2. Сверка итогов:**
- Сумма построчных бюджетов = итого в документе
- Итого в документе = итого на листе «Сводные данные» / «СВОДНАЯ» медиаплана
- АВ рассчитано от правильной базы
- Менеджмент рассчитан от правильной базы
- Финальная сумма = бюджет + АВ + менеджмент (с НДС)

**8.3. Сверка графика оплат:**
- Сумма всех месяцев в графике = общему итого
- Помесячные суммы соответствуют сплиту из медиаплана
- Предоплаты рассчитаны корректно (% от месячного бюджета)

**8.4. Сверка мета-данных:**
- Бренд, период, ЦА совпадают между МП и документом
- Все даты корректны (старт/конец по каждой строке)
- Плейсхолдеры ХХХ / ___ заменены на данные или `[НЕ УКАЗАНО: ...]`

**8.5. Итоговый отчёт:**
Выведи:
- Количество строк: сколько в МП → сколько в документе (с учётом агрегации)
- Общая сумма: МП = ХХХ руб. → Документ = ХХХ руб. → Расхождение: 0 / ХХХ руб.
- Статус: ✓ ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ или ⚠ ОБНАРУЖЕНЫ РАСХОЖДЕНИЯ (список)

При расхождениях — сохрани документ, но пометь проблемные строки `[⚠ РАСХОЖДЕНИЕ: ожидалось X, найдено Y]` и выведи их в итоговом отчёте. Документ сохраняется всегда — пользователь решает, исправлять или принять.
