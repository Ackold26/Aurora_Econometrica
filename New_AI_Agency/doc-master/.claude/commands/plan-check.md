Проверь медиаплан из inbox на ошибки в расчётах.

## Алгоритм работы

### Шаг 1. Определи формат и прочитай файл
Автоматически определи структуру по содержимому листов:
- **Детальный лист** — строки с площадками, форматами, бюджетами (может называться «Медиаплан», «МП», «План размещения» и т.п.)
- **Сводный лист** — итоговые KPI (может называться «Сводные данные», «СВОДНАЯ», «Summary» и т.п.)
- **Сплит бюджета** — помесячная разбивка (может называться «Сплит бюджета», «Бюджет» и т.п.)
Если структура нестандартная — покажи найденные листы и заголовки, спроси маппинг.

Извлеки шапку: клиент, бренд, период, ЦА, медиапланнер.

### Шаг 2. Проверка построчных расчётов (лист Медиаплан / МП)
Для КАЖДОЙ строки размещения проверь:
- **Бюджет = Объём × Цена за единицу** (CPM → показы/1000 × цена, CPC → клики × цена, и т.д.)
- **Сумма понедельных значений = итого по строке** (показы, клики, бюджет)
- **Периоды:** старт ≤ конец, даты попадают в общий период кампании
- **KPI корректны:** CTR = клики / показы × 100%, VTR = просмотры / показы × 100%, CPM = бюджет / показы × 1000, CPC = бюджет / клики

### Шаг 3. Проверка сводных данных
Сравни лист «Сводные данные» / «СВОДНАЯ» с суммами из детального листа:
- **Показы (итого)** = сумма показов по всем строкам
- **Клики (итого)** = сумма кликов по всем строкам
- **Бюджет без НДС** = сумма построчных бюджетов
- **Бюджет с НДС** = бюджет без НДС × (1 + ставка НДС)
- **Бюджет с АК** = бюджет + АВ + менеджмент (если применимо)
- **CPM / CPC / CTR / VTR** — пересчитай из итоговых показов/кликов/бюджета и сравни с указанными
- **Охват / Частота** — если указана формула (показы / охват = частота), проверь

### Шаг 4. Проверка сплита бюджета
Лист «Сплит бюджета» (Формат A) или помесячная разбивка в «СВОДНАЯ» (Формат B):
- **Сумма всех месяцев = общему итого** (по каждому каналу и в целом)
- **Помесячные суммы по каналам** = суммам понедельных данных за соответствующие недели
- **% каналов** = бюджет канала / общий бюджет × 100% (сверить с указанными долями)

### Шаг 5. Проверка процентных долей
- **Доли каналов** (OLV, Banners, Search и т.д.) — пересчитай и сверь с указанными
- **Доли уровней воронки** (Awareness, Consideration, Purchase) — пересчитай
- **Доли по модели закупки** (CPM, CPC, фикс) — если указаны

### Шаг 6. Перекрёстные проверки
- **Production** — стоимость указана, но нет KPI (нормально для производства)
- **Analytics / Adserving** — фиксированная стоимость, нет медийных KPI (нормально)
- **Дубли площадок** — одна площадка встречается в нескольких строках с разными форматами? Проверь, не задвоен ли бюджет
- **Аномальные CPM/CPC** — отмечай значения, которые выглядят нетипично для указанного формата размещения. Выход за пределы — не ошибка, но предупреждение

### Шаг 7. Итоговый отчёт

Формат:

```
## Результат проверки медиаплана
**Файл:** [имя файла]
**Клиент:** ... | **Бренд:** ... | **Период:** ...

### ❌ ОШИБКИ (требуют исправления)
| № | Лист | Строка/Ячейка | Описание | Ожидалось | Найдено | Расхождение |
|---|------|---------------|----------|-----------|---------|-------------|

### ⚠ ПРЕДУПРЕЖДЕНИЯ (рекомендуется проверить)
| № | Лист | Строка/Ячейка | Описание |
|---|------|---------------|----------|

### ✓ ПРОВЕРКИ ПРОЙДЕНЫ
- [x] Построчные расчёты (N строк)
- [x] Сводные KPI
- [x] Сплит бюджета
- [x] Процентные доли
- [x] Перекрёстные проверки

**ВЕРДИКТ:** ✓ МЕДИАПЛАН КОРРЕКТЕН / ⚠ НАЙДЕНЫ ПРЕДУПРЕЖДЕНИЯ / ❌ НАЙДЕНЫ ОШИБКИ
```

При обнаружении ошибок — указывай конкретную ячейку (лист, строка, колонка), ожидаемое значение, найденное значение и величину расхождения. Для ошибок округления (расхождение < 1 руб.) — помечай как предупреждение, не ошибку.
