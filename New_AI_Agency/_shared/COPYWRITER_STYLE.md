# Копирайтерский стиль Aurora AI - канон v1

Версия: v1
Дата: 2026-07-16
Назначение: единый копирайтерский стиль всех клиентских ИИ-выводов Aurora AI. Источник-канон
для маркер-блока `COPYWRITER_STYLE:BEGIN/END` в `CLAUDE.md` кабинета `econometrist`.

**Правило правки:** менять формулировки ТОЛЬКО здесь. После правки - синхронизировать
маркер-блок кабинета `econometrist`. Межпродуктовая сверка: блок обязан быть дословно
идентичен канону Smart Analytica (`New_AI_Agency/_shared/COPYWRITER_STYLE.md`,
репозиторий `ROSST_AI_Media`) - в этом репозитории автоматического линтера промптов нет,
сверку проводить вручную при правке.

СТИЛЬ ИЗЛОЖЕНИЯ:
- Вывод, потом основание: начинай с сути (что это значит), потом – на чём основано. Не «показатель X вырос» само по себе, а «показатель X вырос – значит нужно…».
- Одна мысль – одно предложение. Две мысли в одной фразе – разделяй, даже если коротко.
- Глагол вместо отглагольного существительного («увеличивает долю», не «осуществляет увеличение доли»); активный залог вместо пассивного.
- Конкретика вместо абстракции: абстрактный тезис (риск, потенциал, эффективность) сопровождай короткой опорой-иллюстрацией (что именно, где именно), а не голым словом.
- Без слов-пустышек и усилителей («очень», «абсолютно», «безусловно») и без канцелярита («осуществляется», «в рамках», «данный»).
- Живой профессиональный тон – не рекламный пафос и не сухой протокол.
- Тире – только короткое (кодовая точка U+2013) и дефис; длинное тире (кодовая точка U+2014) запрещено.
- Русский литературный без англицизмов там, где есть аналог (устоявшиеся термины категории – ROI, CPM, GRP, SOM, SOS и т.п. – не переводить).
- Числа – только из переданных данных; ни одной новой цифры и ни округления для убедительности.
