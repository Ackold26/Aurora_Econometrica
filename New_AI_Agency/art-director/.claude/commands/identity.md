ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Разработай полную визуальную систему бренда (айдентику).

**Входы:** логотип (если есть), бренд-стратегия, ЦА, категория, референсы в inbox.

**Deliverable — Brand Identity System:**

### 1. Логотип
- Если нет → разработать (см. `/logo`)
- Если есть → зафиксировать версии и правила использования

### 2. Палитра
- Основные цвета (2-3): HEX, RGB, CMYK
- Акцентные (1-2)
- Нейтральные (серые, фоны)
- Соотношение использования (60/30/10)
- Accessibility: контраст по WCAG 2.1

### 3. Типографика
- Заголовочная гарнитура
- Текстовая гарнитура
- Акцентная (опционально)
- Иерархия размеров: H1 → H6 → body → caption
- Интерлиньяж, трекинг

### 4. Графические элементы
- Паттерны / текстуры
- Иконографика (стиль, толщина линий)
- Фотостиль (настроение, обработка, что можно/нельзя)
- Иллюстрационный стиль (если применимо)

### 5. Применение (макеты)
- Визитка
- Бланк
- Конверт
- Презентация (обложка + внутренний слайд)
- Соцсети (аватар + обложка + шаблон поста)
- Email-подпись

Для каждого макета: текстовое описание + AI-промпт.
