Из одной концепции — пакет визуалов для всех форматов.

**Входы:** концепция/big idea + бренд-стиль.

**Выходные форматы:**

1. **Instagram Feed** (1080x1080, 1:1) — основной визуал
2. **Instagram Stories** (1080x1920, 9:16) — адаптация с CTA
3. **Facebook/VK Post** (1200x630) — горизонтальный с текстом
4. **Telegram Preview** (800x418) — preview для ссылки
5. **Web Banner** (1920x600) — hero-секция сайта
6. **OOH / Print** (вертикальный 3:4) — наружная реклама

Для каждого формата:
- Текстовое описание (композиция, элементы, текст на макете)
- AI-промпт (Midjourney, с --ar для формата)
- Пометки: что адаптировано относительно основного визуала
