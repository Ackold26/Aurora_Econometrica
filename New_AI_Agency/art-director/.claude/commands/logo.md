Разработай концепцию логотипа.

**Входы:** название бренда, категория, ЦА, ценности, референсы (если есть в inbox).

**Deliverable:**

1. **Философия логотипа:**
   - Что символизирует
   - Какую эмоцию вызывает
   - Как связан с позиционированием

2. **3 концепции:**
   Для каждой:
   - Название концепции
   - Описание формы (геометрия, символ, леттеринг)
   - Палитра (2-3 цвета, HEX)
   - Типографика (гарнитура, начертание)
   - AI-промпт для генерации

3. **Система версий:**
   - Основной (горизонтальный)
   - Компактный (вертикальный)
   - Иконка (квадрат, без текста)
   - Монохром (чёрный / белый)
   - Favicon (16x16, 32x32)

4. **Минимальные размеры и охранные зоны**

Результат: документ с 3 концепциями + AI-промпты для каждой.
