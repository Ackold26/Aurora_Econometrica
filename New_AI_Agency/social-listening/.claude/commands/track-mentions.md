ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Структурируй упоминания бренда по источникам и контексту.

**Шаг 1 — Инвентаризация:**
Собери все упоминания из предоставленных данных. Для каждого определи:
- Источник (площадка, канал, автор если известен)
- Дата
- Тип: отзыв / обсуждение / жалоба / рекомендация / новость / вопрос
- Контекст: в чём суть упоминания
- Охват: количество просмотров/лайков (если доступно)

**Шаг 2 — Карта упоминаний:**

| Источник | Тип | Тональность | Охват | Приоритет | Действие |
|----------|-----|-------------|-------|-----------|----------|

Приоритет определяется по формуле: Охват x Интенсивность x Тип (жалоба > обсуждение > отзыв)

**Шаг 3 — Группировка по контексту:**
- Какие темы объединяют упоминания
- Есть ли кластеры (одна проблема обсуждается на нескольких площадках)
- Есть ли лидеры мнений среди авторов

**Шаг 4 — Рекомендации:**
- Какие упоминания требуют реакции (ответ, решение)
- Какие можно использовать (репост, UGC)
- Какие сигнализируют о тренде (мониторить дальше)
