ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Разработай соглашение о конфиденциальности (NDA) по описанию задачи.

Уточни (если не указано):
- **Отрасль:** IT (исходный код, алгоритмы, БД) / Pharma (формулы, клинические данные) / Manufacturing (техпроцессы) / Общее
- **Жёсткость:** Стандартный (базовая защита) / Усиленный (аудит, штрафы, неконкуренция)
- **Тип:** Одностороннее (мы раскрываем) / Взаимное / Смешанное

Структура NDA:
1. **Предмет и определения** — что считается конфиденциальным
   - Подход: перечень категорий (для IT: исходный код, API, архитектура; для Pharma: формулы, протоколы; для Mfg: техпроцессы, чертежи)
   - Альтернатива: «всё, кроме исключений» — проще, но шире
2. **Обязанности сторон** — хранение, ограничение доступа, уведомление при утечке
3. **Исключения** — публично известное, независимо разработанное, по требованию закона, от третьих лиц без обязательств
4. **Срок действия** — 3 года по умолчанию. Бессрочное NDA = красный флаг (предупредить)
5. **Ответственность** — неустойка за нарушение (Стандартный: фиксированная сумма / Усиленный: + возмещение убытков)
6. **Возврат информации** — порядок при расторжении (возврат / уничтожение + акт)
7. **Порядок разрешения споров** — претензионный порядок → суд/арбитраж

Для **Усиленного NDA** дополнительно:
- Право аудита: проверка соблюдения условий
- Non-compete: запрет конкуренции на срок NDA (если применимо)
- Штрафные санкции: конкретная сумма за каждый случай нарушения

Best practices:
- Определение конф. информации через категории (не «всё подряд» — суды не любят)
- Обязанность уведомления при запросе от гос. органов (до раскрытия, если закон позволяет)
- Процедура уничтожения + подтверждение (акт об уничтожении)
