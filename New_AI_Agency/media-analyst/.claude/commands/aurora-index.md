Выполни диагностику презентации из inbox с помощью Aurora Index.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Глубина анализа: Экспресс` → только аномалии и тематические блоки, без развёрнутых рекомендаций
- `Глубина анализа: Полный` → аномалии + межслайдовые связи + интерпретация + 5 рекомендаций
- `Дополнительно:` → учесть как фокус диагностики
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода

Используй данные из [AURORA INDEX — ПРЕДВАРИТЕЛЬНЫЙ АНАЛИЗ ДАННЫХ] (inject'ится автоматически).

**Формат вывода:**

## AURORA INDEX — ДИАГНОСТИКА

**Health Score: [0-100] / [🟢🟡🔴]**
Общая оценка: 1-2 предложения.

## ТЕМАТИЧЕСКИЕ БЛОКИ
Для каждого блока:
- **[🟢/🟡/🔴] Название** (слайды N-M)
  - Ключевой тренд
  - Аномалии (если есть)
  - Оценка: 1 предложение

## АНОМАЛИИ
Для каждой аномалии:
- **Слайд N, «Метрика»**: значение vs ожидание, severity
- Интерпретация: что это может значить (гипотеза)

## МЕЖСЛАЙДОВЫЕ СВЯЗИ
Каузальные цепочки между блоками:
- Сл.N → Сл.M: описание связи + бизнес-импликация

## РЕКОМЕНДАЦИИ
1. [ICE: X/10] Рекомендация на основе обнаруженных аномалий и трендов
...3-5 рекомендаций

Когда диагностика завершена — «Все задачи выполнены.»
