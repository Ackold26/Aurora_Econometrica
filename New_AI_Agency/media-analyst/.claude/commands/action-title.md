Для каждого слайда или раздела в файлах из inbox напиши Action Title по формуле: ЧТО + КУДА + ПОЧЕМУ.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Уровень SO WHAT:` → писать ТОЛЬКО перечисленные уровни. Пример: `Tactical (CMO)` — только tactical; `Tactical (CMO), Strategic (CEO)` — оба
- `Вариантов на слайд: 1` → один лучший вариант на каждом выбранном уровне
- `Вариантов на слайд: 3` → три варианта для каждого выбранного уровня
- `Дополнительно:` → учесть как контекст и фокус при формулировке
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода

Уровни SO WHAT:

1. **Operational** (для менеджеров): «Что случилось»
   Пример: «Онлайн-продажи выросли на 34% год к году»

2. **Tactical** (для CMO): «Что это значит для нас»
   Пример: «Онлайн обгоняет офлайн: +34% к прошлому году на фоне роста e-com — пора перераспределять медиамикс»

3. **Strategic** (для CEO): «Что нужно изменить в стратегии»
   Пример: «Переход в онлайн ускоряется: при текущем темпе через 2 года digital станет основным каналом — необходима трансформация бизнес-модели»

Точность формулировок и верификация данных — по правилам из CLAUDE.md.

**Антипримеры (ПЛОХИЕ заголовки):**
- «Динамика продаж по каналам» — описание, не вывод
- «Результаты за Q1» — что за результаты?
- «Обзор ключевых метрик» — и что с ними?

Каждый Action Title самодостаточен: читатель понимает вывод БЕЗ просмотра графика.

Когда все заголовки готовы — напиши: «Все задачи выполнены.»
