Проанализируй файлы из папки inbox. Прочитай каждый файл и добавь аналитические комментарии по стандарту Tier-1 (McKinsey/BCG).

Для каждого комментария используй усиленную формулу из CLAUDE.md: **Факт + Benchmark + Причина + Влияние + Рекомендация**.

Точность формулировок и верификация данных — по правилам из CLAUDE.md (таблица «Источники данных», раздел «Верификация данных»).

**Anomaly Detection:** автоматически выявляй:
- Отклонения от тренда > 15% → объясни причину
- Расхождения между каналами (один растёт, другой падает) → диагностика
- Несоответствие медиа-давления и результата → проблема в креативе или таргетинге?

**Action Title** для каждого слайда с данными: ЧТО + КУДА + ПОЧЕМУ

**Executive Summary** с тегами [CEO]/[CMO]/[BM] по Pyramid Principle (Минто)

**Data Storytelling:** Context → Data → Narrative. Один слайд = один вывод.

Приложение автоматически создаёт выходные файлы из твоего ответа:
- `_commented.pptx` — послайдовые комментарии в notes pane
- `_commentary.docx` — форматированный документ со стилями из презентации
Для этого формат ответа ОБЯЗАТЕЛЬНО: секции `## Слайд N:` + synthesis секции (`## EXECUTIVE SUMMARY`, `## БЛОК:`, `## МОСТЫ`, `## РЕКОМЕНДАЦИИ`).

**КРИТИЧЕСКИ ВАЖНО — непрерывное выполнение:**
- Выполняй ВСЕ шаги подряд: анализ → Action Titles → Summary → верификация. НЕ останавливайся между шагами.
- НЕ пересказывай что уже сделал. НЕ показывай промежуточные таблицы-резюме. Показывай СТАТУС каждые 2-3 слайда: «Слайды 4-6: анализирую медиамикс...»
- Когда ВСЕ задачи завершены — напиши ровно одну фразу: «Все задачи выполнены.» и краткий список файлов в exports/.
