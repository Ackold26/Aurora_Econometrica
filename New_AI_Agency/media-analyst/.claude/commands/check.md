ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Проверь файлы из inbox на качество аналитики. Следуй инструкции из секции `/check` в CLAUDE.md.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Что проверять:` → проверяй ТОЛЬКО перечисленные области. Если указано `Action Titles, Executive Summary` — проверяй только их, остальные пропустить
- `Режим: Только чек-лист` → выдать список ✅/⚠️/❌ БЕЗ исправлений
- `Режим: Чек-лист + исправить` → выдать список И сразу исправить все ❌ и ⚠️
- `Дополнительно:` → учесть как фокус проверки
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода

Когда проверка завершена — напиши: «Проверка завершена.» и общую оценку + список приоритетных правок.
