Проверь файлы из inbox на качество аналитики по чек-листу Tier-1.

**Блок 1 — ВЕРИФИКАЦИЯ ДАННЫХ (приоритет №1):**
Для КАЖДОГО комментария, содержащего цифру или процент:
- Сверить значение с графиком/таблицей на том же слайде
- Проверить знак (рост vs падение)
- Проверить период (YoY vs QoQ vs MoM)
- Проверить единицу измерения (%, п.п., млн ₽, тыс. шт.)
- Проверить, не перепутаны ли данные разных брендов/каналов/периодов
Каждое несоответствие → ❌ с указанием: что написано vs что на графике

**Блок 2 — Структура и формат:**
- Все слайды с данными имеют Action Title (ЧТО + КУДА + ПОЧЕМУ, не описание)
- Комментарии по усиленной формуле: Факт + Benchmark + Причина + Влияние + Рекомендация
- Нет «кладбища данных» (простой пересказ цифр без выводов)
- Есть Executive Summary с тегами [CEO]/[CMO]/[BM]

**Блок 3 — Точность формулировок:**
Формулировки соответствуют точности источников (таблица в CLAUDE.md). Если digital-активности конкурента «резко упали» без оговорки о двух гипотезах → ⚠️

**Блок 4 — Нарратив и связки:**
- Межтематические мосты (минимум 3–5)
- Narrative Arc: Setup → Tension → Resolution (не линейное перечисление)
- Data Storytelling: один слайд = один вывод

**Блок 5 — So What тест:**
- Конкурент может написать то же самое? → оригинальность слабая
- Читатель спрашивает «ну и что?» → нет вывода
- Нет указания на причину или конкретное действие → переписать

**Выходной формат:**
Для каждого слайда/комментария:
- ✅ Ок — соответствует стандарту
- ⚠️ Слабо — формально соответствует, но можно усилить (с рекомендацией)
- ❌ Нужна правка — ошибка в данных / отсутствует обязательный элемент (с указанием что исправить)

Когда проверка завершена — напиши: «Проверка завершена.» и общую оценку + список приоритетных правок.
