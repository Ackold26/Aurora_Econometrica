Выполни команду /data-analysis. Следуй инструкции из секции `### /data-analysis` в CLAUDE.md.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Типы анализа:` → выполнять ТОЛЬКО перечисленные. `Описательная статистика, Аномалии и выбросы` — только эти два
- `Рекомендации по визуализации: Да` → для каждого инсайта предложить тип графика
- `Рекомендации по визуализации: Нет` → только данные и выводы, без визуализаций
- `Дополнительно:` → учесть как фокус анализа и контекст данных
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода
