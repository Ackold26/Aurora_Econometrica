Обработай ВСЕ файлы из inbox по стандарту /analytics из CLAUDE.md.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Аудитория (уровни комментариев):` → писать ТОЛЬКО перечисленные уровни. `CEO (стратегия), CMO (тактика)` — только [CEO] и [CMO], [BM] пропустить
- `Глубина анализа: Стандарт` → полный анализ: Action Title + комментарии + Executive Summary + мосты
- `Глубина анализа: Экспресс` → для каждого файла: 3-5 ключевых выводов + Action Titles, без развёрнутых комментариев. Фокус — сводная таблица
- `Дополнительно:` → учесть как общий контекст для всех файлов
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода

Формат ответа для каждого файла: секции `## Слайд N:` + synthesis секции.

В конце — сводная таблица: файл / кол-во слайдов / ключевой вывод / приоритет / аномалии.

Когда ВСЕ задачи завершены — «Все задачи выполнены.»
