Напиши межтематические связки (мосты) между блоками презентации из inbox. Следуй инструкции из секции `/bridges` в CLAUDE.md.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Типы связей:` → искать ТОЛЬКО перечисленные типы. `Причинность, Противоречие` — не включать корреляции и усиления
- `Минимум мостов: 3` → написать минимум 3 моста
- `Минимум мостов: 5` → написать минимум 5 мостов
- `Минимум мостов: 7+` → написать 7+ мостов, покрыть все пары блоков
- `Дополнительно:` → учесть как фокус при построении связей
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода

Когда все мосты готовы — «Все задачи выполнены.»
