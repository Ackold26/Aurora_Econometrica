Напиши Executive Summary для материалов из inbox.

**Параметры запуска (из UI):**
$ARGUMENTS

**Применение параметров (приоритет над дефолтами CLAUDE.md, см. секцию "CommandBrief"):**
- `Формат: Pyramid Principle` → Governing Thought + Supporting Arguments + Evidence
- `Формат: SCR` → Situation + Complication + Resolution
- `Разметка аудитории:` → размечать ТОЛЬКО перечисленные уровни. `[CEO] стратегия, [CMO] маркетинг` — только [CEO] и [CMO], блок [BM] не включать
- `Дополнительно:` → учесть как фокус. Если `Добавить Traffic Light Summary` → добавить 🟢🟡🔴 по каждому блоку
- `Язык вывода: Русский` → весь вывод на русском. `English` → ВЕСЬ вывод на английском. Другой язык → на указанном. Термины (ROI, CPM, GRP) без перевода

**Формат 1: Pyramid Principle (Минто)**
- Governing Thought: главный вывод (1 предложение)
- Supporting Arguments: 3-5 аргументов второго уровня
- Evidence: ключевые цифры под каждым аргументом
- Разметка аудитории: [CEO] стратегия, [CMO] маркетинг, [BM] операции

**Формат 2: SCR (Situation-Complication-Resolution)**
- Situation: где мы сейчас
- Complication: что изменилось / что требует реакции
- Resolution: что предлагаем (конкретные action items)

**Traffic Light Summary** (по запросу, добавляется к любому формату):
- 🟢 Норма / лучше плана — 1 тезис
- 🟡 Требует внимания — 1 тезис
- 🔴 Критично — 1 тезис

Точность формулировок — по правилам из CLAUDE.md. Ошибка в цифре = потеря доверия.

**Проверка каждого тезиса:**
- Это действие или решение? (не описание!)
- Самодостаточно? Читатель понимает без слайдов?
- Приоритизировано? Самое важное первым

Когда Executive Summary готов — «Все задачи выполнены.»
