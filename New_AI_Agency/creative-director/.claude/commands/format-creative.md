ЯЗЫК ОТВЕТА: РУССКИЙ. Все комментарии, выводы, рекомендации, статусы — на русском языке. НЕ использовать английский (кроме терминов ROI, CPM, GRP).

Сгенерируй креативные идеи под конкретные рекламные форматы на основе материалов из inbox. Для каждого формата — отдельный блок с Attention Economics timeline:

**TV (15/30/60 сек):**
- Сценарий, визуальный ряд, CTA, музыка/атмосфера
- Attention timeline: Hook (0-3 сек) → Tension (3-15 сек) → Payoff (15-30 сек)
- Second Screen Behavior: зритель смотрит в телефон → первые 3 секунды КРИТИЧНЫ для аудио-hook
- Sound Design: что слышит зритель, даже не глядя на экран?

**OOH (билборд/сити-формат):**
- Headline, визуал, правило 3 секунд (водитель на скорости 60 км/ч)
- Максимум 7 слов в headline — меньше = лучше
- Контраст + читаемость с расстояния 50+ метров
- Ночная версия: работает ли при подсветке?

**Digital (баннеры/видео/stories):**
- Форматы, тексты, CTA, механика вовлечения
- Sound-Off Design: 85% видео в соцсетях смотрят без звука → визуальный нарратив обязателен
- Stories: вертикаль 9:16, swipe-up/link CTA, первый кадр = hook
- Баннеры: анимация ≤ 3 петли, читаемый текст ≤ 5 слов

**Print (журнал/газета):**
- Headline, body copy, визуальное решение
- Z-pattern eye tracking: заголовок → визуал → body → CTA
- Body copy: первое предложение = hook, последнее = CTA

Для каждого формата дай по 2-3 варианта разной тональности:
- Рациональный (факты, цифры, бенефит)
- Эмоциональный (история, чувство, инсайт)
- Провокационный (вызов, конфликт, неожиданность)

Каждый вариант: Идея + Hook (первые 3 сек) + Почему это работает в данном формате.
