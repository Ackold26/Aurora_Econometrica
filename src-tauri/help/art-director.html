Арт-директор

Генерация визуалов, макетов, адаптация под форматы

1. О кабинете

Кабинет «Арт-директор» помогает в разработке визуальных решений: от отдельных макетов и логотипов до полной айдентики бренда. Генерирует детальные описания для дизайнера и готовые промпты для AI-генераторов изображений (Midjourney, DALL-E, Stable Diffusion). Работает с брендбуком и референсами, адаптирует визуалы под разные форматы и платформы, создаёт раскадровки для видеороликов.

2. Быстрый старт

1. Загрузите референсы или брендбук в inbox
2. Выберите /visual или другую команду
3. Опишите задачу
4. Получите описание + AI-промпт

3. Два режима работы

Режим 1: Текстовое описание для дизайнера

Подробное техническое задание с описанием композиции, цветовой палитры, типографики, стиля и всех элементов макета. Готовый документ для передачи дизайнеру или дизайн-студии.

Режим 2: AI-промпт для генерации

Оптимизированный промпт для Midjourney, DALL-E или Stable Diffusion с учётом специфики каждой платформы: правильные модификаторы стиля, параметры качества, соотношение сторон. Можно скопировать и вставить напрямую в генератор.

По умолчанию кабинет выдаёт оба варианта. Вы можете запросить только один из них, указав это в задаче.

4a. Подробное руководство по командам

«Создать визуал» — /visual

Основная команда кабинета. Генерирует визуальную концепцию для любого формата: баннер, пост в соцсетях, наружная реклама, печатный макет, digital-креатив. Выдаёт подробное описание для дизайнера и оптимизированный промпт для AI-генератора.

Что подготовить

  • Описание задачи: что изображено, для чего, какой формат
  • Брендбук или визуальные референсы (если есть)
  • Текст для макета (заголовок, слоган — если есть)

Что получите

Детальное описание визуала (композиция, палитра, стиль, элементы) + промпт для Midjourney/DALL-E.

Примеры использования

Создай визуал для баннера 1080x1080: запуск летней коллекции одежды, стиль минимализм
Визуал для OOH 6x3: энергетический напиток, молодёжная аудитория, яркий и динамичный

«Адаптировать формат» — /adapt

Берёт существующий визуал и адаптирует его под другой формат или платформу. Учитывает требования к размерам, safe zone, размещение текста и ключевые элементы, которые должны сохраниться при перекомпоновке.

Что подготовить

  • Описание или файл исходного визуала
  • Целевой формат и размеры

Что получите

Описание адаптированного макета с учётом особенностей целевого формата.

Примеры использования

Адаптируй баннер 1080x1080 в сторис 1080x1920 и горизонтальный 1200x628
Перекомпонуй OOH-макет в формат для цифрового экрана в ТЦ

«Мультиформатный пакет» — /pack

Генерирует пакет визуалов для нескольких форматов одновременно из одного брифа. Один запрос — и вы получаете описания и промпты для всех необходимых размеров и платформ с единой визуальной концепцией.

Что подготовить

  • Описание визуальной концепции
  • Список форматов (или оставить стандартный набор)

Что получите

Комплект описаний и промптов для 4-8 форматов с единым визуальным языком.

Примеры использования

Пакет визуалов для рекламной кампании: баннер, сторис, пост VK, OOH

«Редактировать» — /edit

Корректирует и дорабатывает существующий визуал по замечаниям. Можно изменить цветовую палитру, композицию, добавить или убрать элементы, изменить стиль — система обновит и описание, и AI-промпт.

Что подготовить

  • Исходный визуал (описание или файл)
  • Список замечаний и правок

Что получите

Обновлённое описание и промпт с учётом всех правок.

Примеры использования

Измени палитру на более холодную, добавь элемент воды, убери фоновый градиент

«Логотип» — /logo

Разрабатывает концепцию логотипа: несколько вариантов с описанием идеи, символики, типографики и цветовой палитры. Выдаёт промпты для AI-генерации и ТЗ для дизайнера-финалиста.

Что подготовить

  • Название бренда/компании
  • Сфера деятельности и ценности бренда
  • Референсы или стилевые предпочтения (опционально)

Что получите

3-5 концепций логотипа с описанием символики, типографики, цветовой палитры и AI-промптами.

Примеры использования

Разработай концепции логотипа для fintech-стартапа «PayBridge», стиль — минималистичный, технологичный

«Полная айдентика» — /identity

Разрабатывает полную визуальную систему бренда: логотип, цветовая палитра, типографика, паттерны, правила использования на разных носителях. Результат — основа для брендбука.

Что подготовить

  • Бриф: позиционирование бренда, ценности, аудитория
  • Референсы (если есть)
  • Список носителей (визитки, соцсети, упаковка и т.д.)

Что получите

Комплексное описание визуальной системы: логотип, палитра, шрифтовая пара, иконография, паттерны, правила применения.

Примеры использования

Разработай айдентику для сети кофеен: лого, цвета, шрифты, паттерн для стаканов и мерча

«Дизайн упаковки» — /packaging

Создаёт концепцию дизайна упаковки продукта с учётом требований полки, конкурентного окружения и целевой аудитории. Описывает лицевую и оборотную стороны, боковые панели и крышку.

Что подготовить

  • Описание продукта и тип упаковки
  • Брендбук (если есть)
  • Конкуренты и полочное окружение

Что получите

Детальное описание дизайна упаковки с визуальной иерархией, цветовой схемой и промптами для AI-генерации.

Примеры использования

Дизайн упаковки для линейки соков: картонная пачка 1л, 3 вкуса, премиальный сегмент

«Визуальный DNA» — /brand-visual

Извлекает и структурирует визуальную ДНК бренда из загруженных материалов. Фиксирует цветовые коды, типографику, стилистические приёмы и визуальные константы для использования во всех последующих задачах.

Что подготовить

  • Брендбук или визуальные материалы бренда
  • Примеры рекламных макетов, упаковки, сайта

Что получите

Файл визуальной ДНК бренда: палитра (HEX/RGB), шрифты, стилистические правила, moodboard-описание.

Примеры использования

Извлеки визуальную ДНК бренда из загруженного брендбука и рекламных макетов

«Раскадровка» — /storyboard

Создаёт покадровый сценарий для видеоролика: описание каждого кадра, действия, текст на экране, закадровый голос, музыкальное сопровождение. Для каждого кадра генерирует промпт для AI-визуализации.

Что подготовить

  • Сценарий или концепция ролика
  • Хронометраж и формат (TV, digital, соцсети)
  • Brand voice и визуальный стиль

Что получите

Покадровая раскадровка с описанием визуала, действий, текста, звука и AI-промптами для каждого кадра.

Примеры использования

Раскадровка для 30-секундного ролика: запуск мобильного приложения банка, аудитория 25-40
Storyboard для серии из 3 коротких видео для Reels: фитнес-продукт

8. FAQ

Кабинет создаёт готовые изображения?
Нет. Кабинет генерирует детальные описания и промпты. Для создания изображений скопируйте промпт в Midjourney, DALL-E или другой генератор, либо передайте описание дизайнеру.
Какой AI-генератор лучше подходит?
Промпты оптимизированы для Midjourney v6+, DALL-E 3 и Stable Diffusion XL. Для каждого генератора система подбирает оптимальные модификаторы.
Можно ли использовать без брендбука?
Да, но с брендбуком или визуальными референсами результат будет точнее. Запустите /brand-visual для создания визуальной ДНК.

9. Ограничения

  • Не генерирует изображения напрямую — выдаёт описания и промпты
  • Не имеет доступа к интернету — загружайте референсы через inbox
  • Для юридической проверки рекламных макетов используйте кабинет «Юрист — Реклама»
  • Для текстов к визуалам используйте кабинет «Копирайтер»
