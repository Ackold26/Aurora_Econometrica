AURORA AI AGENCY – ROSST

Инструкция по удалению приложения
Версия 1.0
1

Удаление через Windows

Основной способ — стандартные средства Windows. Удаляет приложение и регистрационные записи.

  1. Откройте Настройки Windows Нажмите Win + I или через меню Пуск
  2. Перейдите в раздел Приложения Выберите «Приложения» → «Установленные приложения»
  3. Найдите приложение в списке В поиске введите AURORA AI AGENCY или ROSST
  4. Нажмите «⋯» → «Удалить» Подтвердите удаление и следуйте инструкциям деинсталлятора

После этого шага приложение удалено. Но некоторые файлы данных остаются на диске — для их удаления выполните Шаг 2.

2

Очистка остаточных файлов (необязательно)

⚠️

Выполняйте только после удаления приложения через Windows (Шаг 1). Действие необратимо — vault-файлы, лицензия и временные данные будут удалены безвозвратно.

Следующие файлы НЕ удаляются стандартным деинсталлятором:

  • Vault-файлы кабинетов C:\ProgramData\AIAgency\vaults\
  • Лицензионный файл %APPDATA%\AIAgency\license.json
  • Временные файлы сессий %LOCALAPPDATA%\AIAgency\sessions\

Для очистки: запустите скрипт uninstall-cleanup.ps1 из этой же папки (правой кнопкой → «Выполнить с помощью PowerShell»):

# Путь к скрипту в папке с программой:
C:\Program Files\AURORA AI AGENCY - ROSST\resources\help\uninstall-cleanup.ps1
?

Если приложение не удаляется стандартным способом

Попробуйте найти деинсталлятор вручную:

# Найти деинсталлятор в Проводнике:
C:\Program Files\AURORA AI AGENCY - ROSST\
# Запустить файл: Uninstall AURORA AI AGENCY - ROSST.exe

Или используйте сторонние инструменты очистки, например Revo Uninstaller.
