📄 Доку-мастер

Автоматическая генерация документов из медиапланов и шаблонов

1. О кабинете

Доку-мастер решает три ключевые задачи документооборота:

  • Перенос данных из медиаплана в приложение к договору — автоматическое извлечение площадок, объёмов, бюджетов из xlsx и заполнение шаблона .doc/.docx с расчётом НДС, агентского вознаграждения и графика оплат
  • Массовая генерация комплектов документов — создание десятков договоров, актов и дополнительных соглашений на основе шаблонов и таблицы с реквизитами подрядчиков
  • Проверка медиаплана — аудит расчётов в xlsx: построчные суммы, сводные KPI, сплит бюджета, процентные доли

Кабинет работает с любыми форматами медиапланов, автоматически определяя структуру файла по содержимому листов и заголовков. Не привязан к конкретным шаблонам — анализирует структуру каждого загруженного файла с нуля и адаптируется к ней.

Гибкость шаблонов

Система распознаёт плейсхолдеры любого вида: ХХХ, ___, «число» месяц 202Х, [ИМЯ], пустые ячейки в таблицах — любые маркеры «здесь нужны данные». Вы можете использовать собственные шаблоны документов — просто загрузите их в Inbox вместе с источником данных.

Если структура медиаплана или шаблона нестандартная, система покажет найденные элементы и спросит, как маппить данные. Предварительная регистрация шаблонов не требуется.

2. Быстрый старт

Шаг 1. Загрузите файлы в Inbox:
  • Для /plan-to-doc: медиаплан (.xlsx) + шаблон приложения (.doc/.docx)
  • Для /doc-batch: шаблоны документов (.doc/.docx) + источники реквизитов (таблица .xlsx или файлы .docx/.pdf/.jpg/.png)
  • Для /plan-check: медиаплан (.xlsx)
Шаг 2. Нажмите кнопку нужной команды или введите команду в чат.
Шаг 3. Ответьте на уточняющие вопросы (процент АВ, ставка НДС, формат нумерации и т.п.).
Шаг 4. Готовые документы появятся в папке Exports. Проверьте отчёт верификации.

/plan-to-doc — Медиаплан → Приложение к договору

Автоматически извлекает данные из xlsx-медиаплана и заполняет шаблон приложения к договору.

Что делает

  1. Определяет формат и структуру медиаплана автоматически
  2. Извлекает шапку: клиент, бренд, период, ЦА
  3. Извлекает детальные строки: площадки, таргетинги, форматы, объёмы, бюджеты
  4. Рассчитывает НДС, АВ, менеджмент, итого
  5. Формирует таблицу медиаплана с группировкой по уровням воронки
  6. Формирует график оплат с помесячной разбивкой
  7. Генерирует .docx и сохраняет в Exports
  8. Проводит 5-ступенчатую верификацию (построчная сверка, итоги, график, мета-данные, финальный отчёт)

Входные файлы

  • Медиаплан (.xlsx) — обязательно
  • Шаблон приложения (.doc/.docx) — если не предоставлен, используется стандартная структура

Финансовые условия

Система автоматически извлекает все финансовые условия из медиаплана: агентскую комиссию (включая разные проценты по разным площадкам), менеджмент, условия предоплаты, сроки. Уточняющие вопросы задаются только если соответствующие данные в медиаплане не найдены.

/doc-batch — Массовая генерация комплектов

Создаёт комплекты документов для списка подрядчиков на основе шаблонов.

Что делает

  1. Извлекает данные подрядчиков из таблицы (.xlsx/.csv) или разрозненных файлов (.docx, .pdf, .jpg, .png)
  2. Для каждого подрядчика выбирает шаблон (с НДС / без НДС)
  3. Подставляет реквизиты, суммы (цифры + прописью), даты
  4. Рассчитывает НДС при необходимости
  5. Создаёт папку с комплектом документов для каждого подрядчика
  6. Проводит верификацию (плейсхолдеры, суммы, реквизиты)

Типовой комплект на подрядчика

  • Договор оказания услуг
  • Акт сдачи-приёмки
  • ДС о согласии на обработку ПД

Входные файлы

  • Шаблоны документов (.doc/.docx) — с плейсхолдерами
  • Режим A: таблица подрядчиков (.xlsx/.csv) — один подрядчик на строку
  • Режим B: разрозненные файлы реквизитов (.docx, .pdf, .jpg, .png) — карточки ИП, выписки ЕГРИП, фото/сканы уведомлений и свидетельств. Система извлечёт реквизиты из каждого файла автоматически

Режим определяется автоматически по содержимому Inbox. Можно комбинировать: таблица как основа + файлы для дополнения.

/plan-check — Проверка медиаплана

Аудит расчётов в медиаплане — находит ошибки до передачи клиенту.

Что проверяет

  1. Построчные расчёты: бюджет = объём × цена, сумма недель = итого
  2. KPI: CTR, VTR, CPM, CPC — пересчёт и сверка с указанными
  3. Сводные данные: итоги по показам, кликам, бюджету
  4. Сплит бюджета: помесячная и поканальная разбивка
  5. Процентные доли: каналы, уровни воронки, модели закупки
  6. Аномалии: нетипичные значения CPM/CPC для указанного формата

Итоговый отчёт

Три категории: ❌ Ошибки (требуют исправления), ⚠ Предупреждения (рекомендуется проверить), ✓ Проверки пройдены. С указанием конкретных ячеек и расхождений.

4. Входные файлы

Медиапланы (.xlsx)

Система работает с любыми медиапланами в формате xlsx. Автоматически определяет структуру по содержимому листов — ищет детализацию (площадки, бюджеты, периоды), сводные данные и сплит бюджета. Типичные структуры:

ТипЧто ищет системаПримеры листов
Детальный планСтроки с площадками, форматами, объёмами, бюджетамиМедиаплан, МП, План размещения
Сводные данныеИтоговые KPI: показы, клики, бюджет, CPM, CPCСводные данные, СВОДНАЯ, Summary
Сплит бюджетаПомесячная/поканальная разбивкаСплит бюджета, Бюджет, Budget

Если система не распознаёт структуру автоматически, она покажет найденные листы и заголовки и запросит маппинг.

Шаблоны документов (.doc/.docx)

Любые документы с плейсхолдерами — система распознаёт их автоматически по контексту. Типичные паттерны:

Тип плейсхолдераПримерыЧто подставляется
ЗаполнителиХХХ, ___, [ИМЯ], {КОМПАНИЯ}Текстовые данные из источника
Даты«__» _____ 202_ г., ДД.ММ.ГГГГДаты из медиаплана или таблицы
СуммыХХХ (прописью) рублейСуммы цифрами + прописью
Пустые ячейкиПустые поля в таблицах документаДанные из соответствующих колонок

Предварительная регистрация шаблонов не требуется — загрузите свой шаблон в Inbox, и система разберёт его структуру самостоятельно.

Источники реквизитов подрядчиков (для /doc-batch)

Два режима работы:

РежимЧто загружатьКогда использовать
Таблица.xlsx/.csv — один подрядчик на строку, колонки с реквизитамиДанные уже собраны в структурированном виде
ФайлыНабор .docx, .pdf, .jpg, .png — карточки реквизитов, выписки, фото/сканы документовДанные приходят от подрядчиков в разных форматах

Режимы можно комбинировать: таблица как основа, файлы — для дополнения недостающих данных. Система автоматически группирует файлы по подрядчикам и извлекает реквизиты.

6. Инструкции

Как перенести медиаплан в приложение к договору

  1. Загрузите в Inbox: медиаплан (.xlsx) и шаблон приложения (.doc/.docx)
  2. Нажмите Медиаплан → Приложение или введите /plan-to-doc
  3. Система извлечёт финансовые условия из медиаплана автоматически. Если чего-то не хватает — уточнит
  4. Дождитесь генерации и проверьте отчёт верификации
  5. Если все проверки пройдены — документ готов к подписанию

Как сгенерировать комплекты документов для подрядчиков

  1. Подготовьте источники реквизитов: таблицу (.xlsx) или набор файлов с реквизитами (.docx, .pdf, .jpg, .png)
  2. Загрузите в Inbox: шаблоны документов + источники реквизитов
  3. Нажмите Комплекты документов или введите /doc-batch
  4. Укажите формат нумерации договоров, если система спросит
  5. Проверьте сводную таблицу — обратите внимание на строки с ⚠

Как проверить медиаплан перед отправкой клиенту

  1. Загрузите медиаплан (.xlsx) в Inbox
  2. Нажмите Проверить медиаплан или введите /plan-check
  3. Изучите отчёт: ошибки → исправить, предупреждения → проверить вручную

8. FAQ

Какие форматы медиапланов поддерживаются?
Любые медиапланы в формате xlsx. Система автоматически определяет структуру по содержимому листов — ищет детализацию, сводные данные и сплит бюджета. Если структура нестандартная — запросит маппинг.
Что если шаблон приложения не предоставлен?
Система использует стандартную структуру из 6 разделов: Терминология, Предмет, Права и обязанности, Финансовые условия, Ответственность, Прочие условия.
Как система обрабатывает НДС?
По умолчанию 22%. Если в медиаплане или шаблоне указана другая ставка — используется она. Для /doc-batch ставка определяется по статусу НДС подрядчика (нет / 5% / 7% / 20%).
Можно ли использовать свои шаблоны?
Да. Просто загрузите свой .doc/.docx в Inbox — система сама найдёт плейсхолдеры и заполнит их. Никакой предварительной настройки или регистрации шаблонов не нужно. Работает с любыми плейсхолдерами: ХХХ, ___, [ИМЯ], {КОМПАНИЯ}, пустые ячейки.
Что если шаблон немного изменился?
Система анализирует структуру каждого файла с нуля при каждом запуске. Изменение порядка разделов, добавление новых полей, смена формулировок — всё это не проблема. Система опирается на принципы (площадка → площадка, бюджет → бюджет), а не на фиксированные позиции.
Что если в медиаплане нестандартная структура?
Система покажет найденные листы и заголовки и спросит, как маппить данные. Если структура радикально отличается (например, бюджеты не в таблице, а в тексте) — система остановится и запросит уточнения.
Как проверяется правильность переноса?
5-ступенчатая верификация: построчная сверка сумм между xlsx и docx, сверка итогов, графика оплат, мета-данных и финальный отчёт. При любом расхождении — документ не сохраняется до исправления.

9. Ограничения

  • Не проверяет юридическую корректность содержания документов — для этого используйте кабинет Юрист — Контракты
  • Не работает с защищёнными паролем xlsx-файлами
  • Точность извлечения реквизитов из фотографий и сканов зависит от качества изображения — рекомендуется проверять извлечённые данные
  • Суммы прописью генерируются на русском языке — для других языков требуется ручная правка
  • Формат .doc (старый бинарный формат Word) читается, но результат сохраняется в .docx
