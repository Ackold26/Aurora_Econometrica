Что такое Aurora AI Econometrica

Aurora AI Econometrica — десктопное приложение для Marketing Mix Modeling (MMM). Байесовская модель (PyMC-Marketing) считается локально на вашем компьютере — данные не уходят в интернет.

Приложение состоит из двух рабочих режимов:

  • Visual Pipeline — 6-шаговый интерактивный процесс: Import → Validate → Model → Decompose → Optimize → Report
  • Кабинет эконометриста — чат-интерфейс для power users и нестандартных запросов

Быстрый старт

1Подготовьте данные — Excel-файл (.xlsx) с колонками: дата, KPI (продажи), медиарасходы, контрольные переменные (сезонность, цена). Минимум 52 недели.
2Создайте проект — кнопка «Новый проект» на главной. Дайте проекту название.
3Загрузите данные — перетащите xlsx-файл в зону Import или нажмите «Выбрать файл».
4Настройте колонки — укажите, какие колонки содержат KPI, медиа и контрольные переменные. Приложение определяет роли автоматически.
5Обучите модель — настройте параметры (или оставьте defaults) и нажмите «Обучить». Процесс занимает 5–30 минут в зависимости от объёма данных.
6Исследуйте результаты — Decompose показывает вклад каждого канала, Optimize — оптимальное распределение бюджета.
7Создайте отчёт — экспортируйте результаты в PPTX или DOCX.

Visual Pipeline — 6 шагов

Шаг 1: Import (Импорт)

Загрузите xlsx-файл. После загрузки отображается превью первых строк для проверки.

Шаг 2: Validate (Валидация)

Автоматическая проверка данных:

  • Определение ролей колонок (KPI, медиа, контроль, дата)
  • Светофор качества: Зелёный — готово к обучению, Жёлтый — есть предупреждения, проверьте
  • Матрица корреляций — выявляет мультиколлинеарность

Шаг 3: Model (Обучение)

Настройте параметры и запустите MCMC-обучение:

  • Adstock — тип эффекта накопления рекламы (geometric / weibull)
  • MCMC samples — больше выборок = точнее, но дольше (default: 1000)
  • Прогресс-бар обновляется в реальном времени каждые 2 секунды
  • MQS (Model Quality Score) — итоговая оценка качества модели от 0 до 10
💡 R-hat < 1.05 = хорошая сходимость. R-hat > 1.1 = попробуйте увеличить количество выборок.

Шаг 4: Decompose (Декомпозиция)

Waterfall-диаграмма показывает вклад каждого канала в итоговый KPI:

  • Baseline — органические продажи без рекламы
  • Каждый медиаканал — инкрементальный вклад
  • ROI по каждому каналу (отдача на вложенный рубль)

Шаг 5: Optimize (Оптимизация)

Интерактивный оптимизатор бюджета:

  • Слайдеры для каждого канала — перемещайте для изменения аллокации
  • Кривые насыщения (response curves) — видно, где бюджет перераспределить
  • Кнопка «Оптимизировать» — автоматический поиск оптимального распределения
  • Сценарии — сохраняйте и сравнивайте варианты аллокации

Шаг 6: Report (Отчёт)

Генерация executive-отчёта с интерпретацией результатов. Форматы: PPTX, DOCX.

Часто задаваемые вопросы

Сколько времени занимает обучение модели?
5–30 минут в зависимости от количества данных и параметров MCMC. Прогресс отображается в реальном времени. Не закрывайте приложение во время обучения.
Что такое Adstock и какой тип выбрать?
Geometric — экспоненциальное затухание, подходит для большинства медиаканалов (ТВ, digital). Weibull — более гибкая форма кривой, используйте для каналов с нелинейным carry-over (например, OOH).
Модель обучилась, но MQS низкий. Что делать?
Проверьте качество данных (нет ли пропусков, аномалий). Попробуйте увеличить количество MCMC-выборок. Убедитесь, что период данных охватывает разные уровни медиаактивности.
Можно ли использовать ежемесячные данные?
Да, но недельные данные дают более надёжную модель. При месячных данных рекомендуется минимум 36 точек (3 года).
Приложение показывает «Compute engine: unavailable»
Python-движок запускается автоматически при старте приложения. Если статус не меняется на «ready» в течение 30 секунд — перезапустите приложение. Убедитесь, что Python 3.10+ установлен в системе (или используйте установщик с bundled engine).
Как экспортировать данные для другого аналитика?
Результаты хранятся в папке проекта (раздел «Настройки» → «Папки проектов»). JSON-файлы с результатами можно передать напрямую.

Технические детали

Aurora AI Econometrica работает полностью локально:

  • Данные обрабатываются только на вашем компьютере
  • Python-движок (FastAPI) запускается как фоновый процесс на порту 7430
  • MCMC-вычисления: PyMC-Marketing (Bayesian MMM)
  • Оптимизация бюджета: scipy SLSQP
  • Кривые насыщения: Hill function с параметрами alpha, gamma из обученной модели
