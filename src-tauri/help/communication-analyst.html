📊 Коммуникационный аналитик

Мониторинг медиаполя, анализ коммуникаций, оценка эффективности

1. О кабинете

Кабинет «Коммуникационный аналитик» помогает системно работать с медиаполем: анализировать упоминания бренда и конкурентов, оценивать тональность материалов, строить отчёты по эффективности коммуникаций. Аналитика строится на основе международного стандарта измерения PR-эффективности AMEC Barcelona Principles 3.0 и модели классификации каналов PESO (Gini Dietrich). Идеален для PR-специалистов и аналитиков.

2. Быстрый старт

1. Загрузите выгрузку упоминаний (.xlsx, .csv) или текст статей во «Входящие»
2. Нажмите Мониторинг медиаполя
3. Получите структурированный отчёт с выводами и рекомендациями

3a. Подробное руководство по командам

«Мониторинг медиаполя» – /media-monitor

Полный анализ выгрузки медиаупоминаний. Команда считывает файл .xlsx/.csv, уточняет параметры (бренд, период, конкуренты, фокус) и строит структурированный отчёт по всем ключевым метрикам медиаполя.

Что подготовить

  • Выгрузку упоминаний из системы мониторинга (.xlsx или .csv)
  • Желательные колонки: дата, источник, заголовок, текст, охват (если есть)
  • Название бренда и период анализа

Как работает (пошагово)

  1. Загрузите файл выгрузки во «Входящие»
  2. Нажмите кнопку «Мониторинг медиаполя»
  3. Аналитик уточнит: бренд, период, конкуренты, на чём сфокусироваться
  4. Анализирует объём и динамику упоминаний по дням/неделям
  5. Выделяет топ-5 тем и топ-источники
  6. Оценивает тональность с примерами цитат
  7. Находит всплески упоминаний и их причины
  8. Формирует отчёт: Executive Summary, Объём, Темы, Источники, Тональность, Всплески, Рекомендации (срочные / плановые / стратегические)

Что получите

Структурированный отчёт (.md или .docx) с разделами от Executive Summary до трёхуровневых рекомендаций. Отчёт сохраняется в папку экспорта.

Примеры использования

Проанализируй медиаполе за март 2026, бренд «АльфаТех», фокус на негативе
Сделай мониторинг упоминаний, сравни с прошлым месяцем, выдели топ-темы

Советы

  • Чем больше колонок в выгрузке (охват, тип СМИ, автор) – тем детальнее отчёт
  • Если есть данные за предыдущий период – загрузите оба файла для сравнения динамики
  • Укажите конкурентов заранее, чтобы получить сравнительный контекст

«Тональность» – /sentiment

Детальный анализ тональности по пятибалльной шкале: позитив, слабый позитив, нейтраль, слабый негатив, негатив. Определяет драйверы тональности – конкретные фразы и темы, которые формируют восприятие бренда. Поддерживает тональность по аспектам (продукт, сервис, цена).

Что подготовить

  • Выгрузку упоминаний или набор текстов для анализа
  • При необходимости – список аспектов для разбивки (продукт, сервис, цена и др.)

Как работает (пошагово)

  1. Загрузите файл с материалами во «Входящие»
  2. Нажмите кнопку «Тональность»
  3. Каждый материал оценивается по шкале из 5 уровней
  4. Определяются ключевые фразы, влияющие на тональность
  5. Материалы группируются по темам и источникам
  6. Формируется таблица: Источник / Заголовок / Тональность / Ключевая фраза / Тема

Что получите

Таблицу с разметкой каждого материала по тональности, ключевым фразам и темам. Баланс тональности (% позитива минус % негатива) показывает общее настроение медиаполя.

Примеры использования

Оцени тональность всех упоминаний, разбей по аспектам: продукт, сервис, цена
Проанализируй тональность публикаций, выдели основные драйверы негатива

Советы

  • Используйте тональность по аспектам, чтобы понять, что именно хвалят или критикуют
  • Обращайте внимание на «слабые» тональности – они показывают зоны риска и роста
  • Сравнивайте баланс тональности за разные периоды для отслеживания трендов

«Анализ конкурентов» – /competitors

Сравнение медиаприсутствия вашего бренда с 2–5 конкурентами по ключевым метрикам: объём упоминаний, тональность, топ-темы и показатель медиаприсутствия (охват, умноженный на тональность). Выявляет «белые пятна» – темы, которые никто из конкурентов не покрывает.

Что подготовить

  • Выгрузку упоминаний вашего бренда и конкурентов (в одном или нескольких файлах)
  • Список конкурентов для сравнения (2–5 названий)
  • Период анализа

Как работает (пошагово)

  1. Загрузите файлы с упоминаниями во «Входящие»
  2. Нажмите кнопку «Анализ конкурентов»
  3. Укажите конкурентов (или напишите в чате заранее)
  4. Для каждого бренда считаются: объём, тональность, топ-темы
  5. Рассчитывается показатель медиаприсутствия: охват, умноженный на разницу % позитива и % негатива
  6. Определяются «белые пятна» – темы, которые не покрыты конкурентами
  7. Формируется сравнительный отчёт

Что получите

Файл competitors-[дата].md со сравнительными таблицами, рейтингом показателя медиаприсутствия и списком «белых пятен» для контент-стратегии.

Примеры использования

Сравни наш бренд с конкурентами: «КомпанияА», «КомпанияБ», «КомпанияВ»
Найди темы, которые конкуренты не покрывают – белые пятна для нашего контента

Советы

  • Оптимально сравнивать с 3 конкурентами – достаточно для контекста, не перегружает отчёт
  • «Белые пятна» – ценный источник идей для контент-плана и PR-стратегии
  • Показатель медиаприсутствия учитывает не только объём, но и качество упоминаний

«Отчёт по эффективности» – /effectiveness

Сводный отчёт об эффективности коммуникаций по международному стандарту измерения PR. Включает общий охват, показатель медиаприсутствия, баланс тональности (% позитива минус % негатива), динамику относительно предыдущего периода и оценку проникновения ключевых сообщений.

Что подготовить

  • Выгрузку упоминаний за отчётный период
  • Желательно – выгрузку за предыдущий период для сравнения
  • Список ключевых сообщений бренда (если нужна оценка проникновения)

Как работает (пошагово)

  1. Загрузите файлы во «Входящие»
  2. Нажмите кнопку «Отчёт по эффективности»
  3. Рассчитывается общий охват и показатель медиаприсутствия
  4. Определяется баланс тональности
  5. Сравнивается динамика с предыдущим периодом (если данные есть)
  6. Оценивается проникновение ключевых сообщений
  7. Формируется итоговый вывод: эффективно / нейтрально / требует корректировки

Что получите

Файл effectiveness-report-[период].md (опционально .docx) с метриками, графиками динамики и финальной оценкой эффективности.

Примеры использования

Построй отчёт по эффективности PR за Q1 2026, сравни с Q4 2025
Оцени эффективность кампании «Весенний запуск», период: 1–31 марта

Советы

  • Для полноценного отчёта загрузите данные за два периода – текущий и предыдущий
  • Укажите ключевые сообщения заранее – это обогатит раздел проникновения
  • Отчёт в формате .docx удобен для отправки руководству

«Ключевые сообщения» – /key-messages

Проверяет проникновение 3–7 ключевых сообщений бренда в медиаполе. Для каждого сообщения определяет статус: найдено / частично найдено / отсутствует, количество упоминаний и конкретные примеры из публикаций. Даёт рекомендации по усилению слабых сообщений.

Что подготовить

  • Выгрузку упоминаний или набор публикаций
  • Список из 3–7 ключевых сообщений бренда

Как работает (пошагово)

  1. Загрузите файл с материалами во «Входящие»
  2. Нажмите кнопку «Ключевые сообщения»
  3. Укажите ключевые сообщения в чате (или они будут запрошены)
  4. Каждое сообщение ищется в текстах – точное совпадение и смысловые вариации
  5. Определяется статус проникновения и подбираются примеры
  6. Формируется таблица и рекомендации

Что получите

Таблицу: Сообщение / Количество упоминаний / Примеры / Рейтинг, а также рекомендации по усилению слабых сообщений.

Примеры использования

Проверь проникновение сообщений: «Лидер инноваций», «Надёжный партнёр», «Экологичное производство»
Оцени, как часто в публикациях звучат наши ключевые тезисы из медиакита

Советы

  • Формулируйте сообщения так, как они должны звучать в медиа – аналитик ищет и точные, и смысловые совпадения
  • 3–5 сообщений – оптимально; больше 7 размывает фокус анализа
  • Используйте результаты для корректировки медиакита и спикерских тезисов

«Кризисный анализ» – /crisis-analysis

Анализирует всплески негативных упоминаний: определяет триггер (событие или публикацию, запустившую волну), отслеживает динамику распространения и формирует рекомендации по реагированию. Кризисный анализ проводится по фреймворку SCCT (Situational Crisis Communication Theory, Timothy Coombs) с определением типа кризиса и стратегии реагирования. Незаменим при кризисных ситуациях и репутационных угрозах.

Что подготовить

  • Выгрузку упоминаний с фокусом на период всплеска
  • По возможности – данные за «спокойный» период для сравнения

Как работает (пошагово)

  1. Загрузите файл с упоминаниями во «Входящие»
  2. Нажмите кнопку «Кризисный анализ»
  3. Аналитик находит всплески негатива на временной шкале
  4. Определяет триггер – первый материал или событие, запустившее волну
  5. Анализирует динамику: как быстро распространялся негатив, через какие каналы
  6. Оценивает масштаб: охват, количество источников, длительность
  7. Формирует рекомендации по реагированию и предотвращению

Что получите

Отчёт с хронологией кризиса, анализом триггера, картой распространения и пошаговыми рекомендациями по реагированию.

Примеры использования

Проанализируй всплеск негатива 15–20 марта, найди триггер и дай рекомендации
Оцени кризисную ситуацию вокруг инцидента с продуктом, предложи план реагирования

Советы

  • Чем быстрее загрузите данные после всплеска – тем точнее будет анализ триггера
  • Включите в выгрузку соцсети – они часто являются первоисточником кризиса
  • Используйте рекомендации как основу для антикризисного плана, адаптируя под специфику компании

/influencer-impact – Анализ лидеров мнений

Выявление и ранжирование ключевых лидеров мнений (KOL) из данных медиамониторинга по модели Two-Step Flow (Katz & Lazarsfeld). Классификация: адвокат / нейтрал / критик. Impact Score = Аудитория × Частота × Интенсивность тональности.

Что получите

  • Рейтинг KOL с Impact Score
  • Классификация: кто за нас, кто против, кто нейтрален
  • Рекомендации по работе с каждой группой

/batch-analysis – Мета-анализ блоков

Пирамидальный мета-анализ: сводит результаты нескольких блоков медиамониторинга в единый отчёт. Загрузите отчёты предыдущих анализов как входящие файлы.

Что получите

  • Сводная картина медиаполя: объём, охват, Media Index
  • PESO-распределение по всему массиву
  • Сквозные нарративы и их траектории
  • Executive Summary по AMEC Barcelona Principles

4. Входящие файлы

  • Форматы: .xlsx, .csv, .docx, .pdf, .txt
  • Рекомендация: выгрузка из медиамониторинга (.xlsx/.csv) даёт наиболее полный анализ
  • Структура выгрузки: дата, источник, заголовок, текст, тональность (если есть)
  • Объём: до 500 упоминаний для оптимального анализа

5. Результаты

  • Аналитический отчёт с выводами и рекомендациями (.docx, .md)
  • Таблица с размеченными упоминаниями (.xlsx)
  • Папка: Desktop/AI Agency/Коммуникационный-аналитик/exports/

6. Пошаговые инструкции

Анализ медиаполя за период

  1. Выгрузите упоминания из медиамониторинга за нужный период
  2. Загрузите файл во «Входящие»
  3. Нажмите «Мониторинг медиаполя»
  4. В результатах получите отчёт с топ-темами, тональностью и динамикой

Оценка эффективности PR-кампании

  1. Загрузите выгрузку упоминаний за период кампании
  2. Напишите в чате: «Оцени эффективность кампании [название], период [даты]»
  3. Нажмите «Отчёт по эффективности»
  4. Получите сравнение до/после и выводы по охвату и тональности

7. Примеры запросов

Чем отличается от Social Listening

Коммуникационный аналитик и Social Listening работают на разных уровнях анализа. Понимание разницы поможет выбрать нужный кабинет.

Коммуникационный аналитик (этот кабинет)Social Listening
УровеньМакроуровень – медиаполе, PR-эффективностьМикроуровень – голос конкретного потребителя
Что анализируетПубликации СМИ, Telegram-каналы, ТВ-сюжетыОтзывы, комментарии, упоминания покупателей
ИсточникиМедиамониторинг (Медиалогия, Brand Analytics), выгрузкиМаркетплейсы, отзовики, YouTube, Google Maps
Единица анализаПубликация, сюжет, нарративОтзыв, комментарий
Ключевой вопрос«Как нас освещают СМИ? Эффективен ли наш PR?»«Что потребители думают о нашем продукте?»
Кому нуженPR-менеджер, коммуникационный директорМаркетолог, продакт-менеджер, клиентский сервис
МетодологииAMEC Barcelona Principles, PESO, SCCT, SOV/ESOVJTBD (Christensen), Plutchik Wheel, Kano Model
ВыходОценка PR-эффективности, нарративы, кризисное реагированиеПродуктовые инсайты, потребительские тренды

Примеры: когда какой кабинет

Задача: «Оценить результаты PR-кампании за квартал»

→ Коммуникационный аналитик. Загрузите выгрузку медиамониторинга → /effectiveness. Вы получите: «Media Index вырос на 34%, SOV = 18% (ESOV +6 п.п. vs SOM). Earned-публикации составили 62% охвата. По AMEC: Output достигнут, Outcome – рост знания на 4% (требует проверки).» В отличие от Social Listening, здесь анализ не отзывов покупателей, а медийного поля и PR-результатов.

Задача: «Понять, почему клиенты жалуются на доставку»

→ Social Listening. Это задача микроуровня – анализ конкретных отзывов и комментариев. Коммуникационный аналитик не работает с отзывами с маркетплейсов – он работает с публикациями СМИ.

Задача: «Кризис: утечка данных, СМИ подхватили»

→ Оба кабинета. Коммуникационный аналитик (/crisis-analysis) – определит тип кризиса по SCCT (Preventable), проанализирует медийную динамику, стейкхолдеров, предложит стратегию ответа на 3 горизонтах (0-4ч / 24-72ч / 1-4 нед). Social Listening (/crisis-alert) – покажет реакцию потребителей: масштаб негатива в отзывах, конкретные претензии, эмоциональный профиль.

Как кабинеты работают вместе

Social Listening собирает «голос снизу» (потребительские инсайты, JTBD, тренды) → Коммуникационный аналитик работает с «полем сверху» (СМИ, нарративы, PR-эффективность). Результаты обоих кабинетов загружаются в Коммуникационного стратега для построения полной коммуникационной стратегии.

Анализ больших массивов данных

При работе с медиамониторингом свыше 500 публикаций рекомендуется пирамидальный подход – разбивка на блоки с последующим сведением результатов.

Метод Pyramid Analysis

1. Нарезка на блоки по 300–500 публикаций. Критерии: по типу СМИ (ТВ, онлайн, печатные, Telegram), по периоду (неделя, месяц), по теме/нарративу.
2. Анализ каждого блока отдельно. Загрузите блок → /media-monitor или /sentiment. Получите структурированный отчёт: объём, тональность, топ-источники, нарративы.
3. Мета-анализ. Загрузите все отчёты по блокам как входящие файлы → /effectiveness или /batch-analysis. Система сведёт выводы: сравнит каналы PESO, найдёт сквозные нарративы, рассчитает общий Media Index.

Для очень больших массивов (10 000+)

Добавляется промежуточный уровень: 10 000 публикаций → 20 блоков → 20 отчётов → 4 группы по 5 отчётов → 4 мета-отчёта → 1 финальный отчёт.

МассивПодходКоличество итераций
до 500Одна загрузка1

10 000+Пирамида: блоки → группы → финалПо ситуации

8. FAQ

Какой формат выгрузки подходит лучше всего?
.xlsx с колонками: дата, источник, заголовок, текст. Если есть готовая тональность – добавьте её колонкой, аналитик учтёт её при анализе.
Можно ли анализировать отдельные статьи, а не выгрузку?
Да, загрузите .txt или .docx файл со статьями и напишите в чате, что нужно проанализировать.
Работает ли с соцсетями?
Да, если выгрузить посты и комментарии в .xlsx или .csv формате.
Можно ли задать конкурентов вручную?
Да, напишите в чате: «Конкуренты для сравнения: [список]».

9. Ограничения

  • Не имеет прямого доступа к медиамониторинговым платформам – нужна ручная выгрузка
  • Анализ на русском языке работает лучше, чем на смешанных языках
  • Объём более 500 материалов может снизить детальность анализа
  • Данные в реальном времени не доступны – только загруженные файлы
