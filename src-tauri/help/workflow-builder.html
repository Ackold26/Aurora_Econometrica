Что такое Workflow

Workflow — цепочка шагов, где каждый шаг выполняет один из AI-кабинетов. Вы один раз описываете задачу, и система последовательно обходит всех нужных экспертов.

Pipeline — это Workflow с брифом и контекстной цепочкой. Каждый кабинет получает: бриф + бренд-контекст + результаты предыдущих шагов. Итог — полноценный рекламный продукт "под ключ".

Три типа шагов

⬛

Single — обычный шаг

Один кабинет выполняет задачу. Базовый строительный блок любого workflow.

⬛⬛

Parallel — параллельно

Несколько кабинетов работают одновременно. Например, копирайтер + арт-директор.

🔄

Loop — цикл

Работа → ревью → доработка. Итеративное улучшение до нужного качества.

Как создать Workflow

1. Выбрать шаблон или создать с нуля

Нажмите «Новый Workflow» на странице Workflow. Выберите готовый шаблон или пустую схему.

2. Добавить шаги

Нажмите «+» между шагами. Система подскажет подходящий кабинет. Задайте команду (необязательно).

3. Написать бриф (для Pipeline)

Раскройте секцию «Бриф задачи» и опишите цель. Бриф передаётся каждому кабинету автоматически.

4. Запустить

«Запустить Workflow» — без контекстной цепочки. «Запустить Pipeline» — с брифом и цепочкой результатов.

Pipeline — работа с контекстом

В режиме Pipeline каждый кабинет получает в начале сообщения:

  • Текст брифа, который вы написали в секции «Бриф задачи»
  • Имя и контекст активного бренда
  • Краткое резюме результатов предыдущих шагов (до 3 файлов, 300 символов каждый)
  • Файлы из экспорта предыдущего кабинета — доступны в папке inbox

Экспорт результатов

После завершения Pipeline появляется панель экспорта:

  • Экспорт ZIP — скачать все результаты в архиве с папками по шагам и сводкой summary.md
  • Открыть папку — открыть директорию с сохранёнными файлами в проводнике
  • Результаты хранятся постоянно в %APPDATA%\Aurora\campaigns\

Советы

  • Бриф — ключ к качеству. Чем детальнее описание, тем точнее результат каждого кабинета.
  • Если шаг упал с ошибкой — нажмите «Перезапустить» и начните с проблемного шага.
  • Pipeline можно оставить работать в фоне — результаты сохраняются автоматически.
  • Если приложение закрылось во время выполнения — Pipeline получит статус «прервано», данные не потеряются.
  • Переименовать Workflow — кликните на название в верхней части страницы.
