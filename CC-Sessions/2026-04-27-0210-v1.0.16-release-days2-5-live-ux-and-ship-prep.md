## Learnings

### Sidecar process model в dev mode
- Sidecar = `python.exe` (PID children of `aurora-econometrica-gui.exe`) — NOT frozen `econometrica-sidecar.exe` в dev
- Watchdog auto-respawns at unhealthy detection (3-strike) — но НЕ hot-reloads .py source on save
- For Python source changes к take effect: kill `python.exe` через PowerShell → watchdog respawns с new code на ~30 сек
- For NSIS production build: `python build_sidecar.py` ОБЯЗАТЕЛЕН (memory `feedback_sidecar_rebuild_required.md`) перед `npm run tauri build` — sidecar exe иначе stale

### Vite HMR scope
- Vite hot-reload triggers ТОЛЬКО на frontend (Svelte/CSS/JS) — Python sidecar не подхватывается
- В live-test session все UI changes показывались мгновенно через HMR; только narrative_adapter.py / sections.py changes требовали kill sidecar python process

### Narrative semantic mismatch (L22)
- channels_by_action lists в build_action_summary preserve order from caller (which sorts by contribution desc)
- Customer-facing narrative ожидает «mROAS-driven» recommendation: «По mROAS Social опережает (11.1×)» → expected «в Social»
- Pre-fix: scale_destination = `channels_by_action[Scale][0]` = top contribution (e.g. OLV для Венарус, mROAS 3.76×) — disconnect с COMPLICATION
- Post-fix: explicit re-sort by mROAS desc → scale_destination = top mROAS (Social, 11.14×)
- Same для cut_source — sort by mROAS asc (worst first)

### Cut/Underperf overlap (L23)
- `underperformer_names` = channels with verdict ∈ (Cut, Watch) — includes cut_source automatically
- Pre-fix ANSWER: «Перебалансировать из {cut_source} в {scale_dest}; сократить или остановить {underperf}» = «из TRPs в Social; сократить или остановить TRPs» (TRPs дважды)
- Post-fix: dedup cut_source from underperformer_names в narrative_adapter; sections.py + builder.py пропускают «; сократить или остановить» clause если list пустой

### $expertMode bidirectional sync
- Customer expectation: header «Эксперт» button toggle ↔ disclosure expand/collapse working both ways
- Forward (global → local): `$effect(() => { if ($expertMode) { expertExpanded = true; forecastExpanded = true; } else { ... false } })`
- Reverse (local → global): `$effect(() => { const anyOpen = expertExpanded || forecastExpanded; if (anyOpen && !$expertMode) expertMode.set(true); else if (!anyOpen && $expertMode) expertMode.set(false); })`
- Cascade trade-off: opening single local disclosure также opens другой через global cascade — acceptable «expert mode is all-or-nothing»

### Forecast volume mode math
- Pre-fix: optimizer вызывался с native budget constraint + maxPct=300 → re-allocation, искусственный +35% lift «from inflation»
- Customer model: «Сохранить объём» = raw_spend per channel остаётся прежним, цена растёт, KPI = unchanged (Hill saturation на raw_spend = same)
- Post-fix: skip optimizer для volume mode, build static forecastResult locally (per-channel raw_spend = current, money = raw × ucNew, lift_pct = 0)

### svelte-check $state type narrowing
- `let stepState = $state('idle')` — TypeScript narrows literal type 'idle' (not full union)
- Workaround #1: `let stepState = $state(/** @type {Union} */ ('idle'))` — sometimes works
- Workaround #2: `/** @typedef {...} StepState */ let stepState = $state(/** @type {StepState} */ ('idle'))` — typedef hoisted
- Real fix: `const isGenerating = $derived(String(stepState) === '...' || String(stepState) === '...')` — String() bypass type narrowing для template comparisons

## Decisions

### v1.0.16 architectural

1. **Auto-engine selection без manual override (L9 evolution)** — Customer не управляет вручную выбором Bayesian/OLS. System sets based on n_rows: <30 → OLS, ≥30 → Bayesian. Avoids неправильного matching engine к данным.

2. **Block D «Прогноз на будущий период» integrated в Block C as inline expert disclosure** — standalone section removed, Block E «Сценарии» renamed к D. Inflation overlay стал optional sub-feature внутри What-if. Customer выбирает учёт инфляции на уровне сценария.

3. **L9 «Фиксировать бюджет» — hide полностью (vs disable)** — disabled checkbox с tooltip = UX дискомфорт (control visible but inactive). Hide лучше — control возвращается в v1.1 когда true free-budget mode будет реализован.

4. **scale_destination = top mROAS, не top contribution (L22)** — narrative consistency с COMPLICATION «По mROAS Social опережает». Customer reads single-criterion narrative.

5. **Save scenario с zero-baseline support** — when applyInflation=true но whatIfMult=1.0 (slider не двинут), сохраняется current allocation × ucNew. Customer может зафиксировать «текущая аллокация + инфляция» как сценарий следующего периода.

### Memory storage decisions

6. **DAYS_PROGRESS.md tracker для autonomous mode** — single source of truth для current task / done / next concrete first step. Compress recovery protocol cross-references к нему. После каждого commit обновляется.

7. **Test policy** — 552+/552+ Python regression на каждом change set. Vitest + svelte-check baseline (31 errors pre-existing в hill.js/insights-rules.js). 8 new L4 lock-in tests + 17 new L1 lock-in tests added.

### Push policy (autonomous mode)
- Auto-commit local OK без confirmation
- Push к remote — show diff first → wait approval (per Антон's instruction)
- Schema migration / architecture decisions — questions to user
- В session push'ы выполнялись batch'ами (Day 1 → c7b2dbc, Days 2-6 prep → 5858844, post-audit → b3120e2, live-test → 90de35d)

## Errors & workarounds

### Sidecar respawn after kill
- **Issue:** killed sidecar process — Watchdog не respawns immediately, customer запросы fail
- **Workaround:** Watchdog policy = 3-strike (unhealthy 3/3 within ~90 сек) перед respawn. Wait или trigger через UI action (любой backend call → ensure_alive → respawn)

### $effect TDZ (forward reference)
- **Issue:** `ucNewMap = $derived(channels.map(...))` declared before `channels = $derived(...)` → TypeScript «Block-scoped variable used before declaration»
- **Workaround:** Move derived helpers AFTER dependent channels declaration

### svelte-check stepState narrowing in template
- **Issue:** `{#if stepState === 'generating-xlsx'}` errored с «no overlap» (type narrowed к 'idle')
- **Workaround:** `const isGenerating = $derived(String(stepState) === '...')` — String() coercion bypass narrowing

### @const placement в Svelte 5 templates
- **Issue:** `{@const}` must be immediate child of `{#if}` / `{#each}` — нельзя placed внутри `<div>` или other tags
- **Workaround:** Move computation в script через `$derived`, or wrap section с {#if true}{/if} for grouping

### Insights-rules.js still imports marginalROI
- **Concern:** L4 fix removed marginalROI import от OptimizeStep, но insights-rules.js (line 8, 1069) всё ещё его использует
- **Resolution:** marginalROI остаётся в hill.js — function not deleted, only OptimizeStep usage removed. insights-rules continues working

### Tauri dev exit 127 (background task)
- **Issue:** PowerShell `Stop-Process` killed dev gui → background task `b2aius00v` failed exit 127 (normal)
- **Workaround:** Expected behavior, restart with `npm run tauri dev` if needed
