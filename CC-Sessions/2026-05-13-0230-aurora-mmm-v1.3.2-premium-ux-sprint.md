## Learnings

### Svelte 5 specifics

1. **`<details open={x} ontoggle={fn}>` создаёт infinite render loop** — controlled attribute + event handler feedback. Fix: `bind:open={x}` (two-way native binding). Симптом: окно мигает десятки раз/сек при mount. Saved as `feedback_svelte5_details_bind_open.md`.

2. **$effect, не onMount, для init logic зависящего от async-filled store** — onMount читает store snapshot один раз; если store наполняется позже (e.g. .aurora archive open), init видит pre-fill state. Fix: $effect reactively waits, guard flag предотвращает re-trigger loop. Saved as `feedback_svelte5_effect_vs_onmount_async_store.md`.

3. **JSDoc Russian inline descriptions inside `@type {...}` literal ломают TS checkJs parser** — кириллица + non-ASCII парсятся как property names / function signatures. Cascade 12 errors. Fix: descriptions выше @type tag, type literal pure. Saved as `feedback_jsdoc_inline_comments_at_type.md`.

### Backend convention learnings

4. **Per-channel mroas/roi для count KPI = mathematical units/₽ (НЕ pre-converted CPU)** — `narrative_adapter._merge_channels` returns raw mroi_current. Display layer обязан invert (1/x). Это cross-layer cascade bug — 4 render layers независимо приставляли «₽/ед.» суффикс к raw числу. Closed via INV-22 в aurora-meta + 4-layer coordinated fix.

### UX/architecture

5. **Dual-mode UX философия** — каждая visualization работает в 2 режимах одновременно. Manager (default): insights-driven, без жаргона, premium tier-1. Expert (opt-in `$expertMode`): raw stats, formulas, posterior breakdown. Aurora positioning «продукт где результат high-end эконометриста доступен маркетологу». Saved as `feedback_aurora_dual_mode_ux.md`. Pending formalization как INV-23.

6. **Insights severity filter для destructive UI** — действия типа «Исключить» / bulk-apply принимают insights ТОЛЬКО severity ≥ `warning`. `severity='info'` insights — это optimization suggestions (ROI mode prefers paired budget), не data-quality requirements. Иначе система рекомендует destroy critical channel (TRPs Бренд >90% бюджета). Saved as `feedback_insights_severity_filter_for_exclude.md`.

7. **Project-wide mass replacement scope** — sed-style replacements включают ВСЕ source dirs: `src/ + tools/ + src-tauri/ + sidecar/ + docs/`. Не «main code only». Иначе tests с старым value fail во 2-м проходе. Saved as `feedback_mass_replace_script_scope.md`. Real cost: em-dash → hyphen двумя проходами (226 + 98 файлов).

8. **Vocabulary drift between layers** — UI roles (kpi/media/control/date/excluded) vs backend canonical (kpi/media/control/date/unused/unknown). Defensive mapping в effectiveRole(): unused/unknown/null → 'excluded' to prevent ROLE_META[undefined] crashes.

## Decisions

### Architecture decisions

- **Hard-block (Variant A) при ratio <2:1** — кнопка «Подтвердить роли» disabled + red attention banner с reason text. Soft acknowledgment (Variant B) и laissez-faire (Variant C) отклонены. Reason: при ratio <2:1 модель математически склонна overfit; manager не понимает consequences, expert использует override через role changes.

- **Severity filter convention** — `insightExcludeMap` принимает только insights severity 'warning' / 'error'. `severity='info'` (optimization suggestions) остаются в InsightsPanel где user может explicit «Применить», но НЕ trigger «Исключить» badge в Рекомендация column. Manager защищён от destructive auto-recommendations.

- **Backend convention для KPI metric storage:** per-channel mroas/roi всегда mathematical KPI_units / ₽_spend. Render layer responsibility — inversion для count KPI display. Closed как INV-22 в aurora-meta.

- **Dual-mode UX как cross-product principle** — manager primary, expert opt-in. RatioInfoCard precedent: shared widget, expert content в `{#if $expertMode}` blocks. Применять для всех new visualizations.

### Design decisions

- **Em-dash «—» → hyphen «-»** во всех текстах (324 файла) — короткое тире меньше visually доминирует, более compact в премиум-стилистике.

- **Floating 📖 glossary FAB удалён** — выбивался из премиум стилистики. Glossary остаётся через Ctrl+G + Settings + in-context tooltips.

- **«Зачем шаг» panel collapsed по умолчанию на всех шагах** — premium-style main content immediate-visible без scroll; expanded panel занимал space и отвлекал.

- **Floating bottom-right elements избегаются** — premium tier-1 brand: absence of overlay UI поверх контента. In-context discovery > global pictograph.

- **ColumnMapperConfirm restyle: emoji-free, gold color-dots, sacred-lime hairline, mono для column names** — premium tier-1 typography matches Aurora deliverable brand styling.

- **Date / KPI / Media / Control / Excluded sort order** в ColumnMapperConfirm — Date наверху всегда, KPI следующий, потом media/control, excluded в конце. Stable sort внутри role.

- **Recommendation column в ColumnMapperConfirm читает same source как InsightsPanel** — `validateInsights()` shared compute → two-way coupling. Dropdown role change → immediate validateData write → insights/recommendations recompute. InsightsPanel apply action → validateData mutate → ColumnMapperConfirm sees new state.

- **«Сбросить шаг» pattern** — ghost button справа в substep nav, gold hover. Clears all user overrides + re-triggers backend validate. Aurora pattern для всех steps.
