## Learnings

### Архитектурные инсайты

1. **cabinets.json ПЕРЕКРЫВАЕТ cabinet.rs в production** (src-tauri/src/commands/cabinet.rs:328)
   ```rust
   match super::content_pack::load_pack_file(app_local_data_dir, "cabinets.json") {
       Ok(json_str) => { /* use pack */ }
       Err(e) => warn!("... using hardcoded fallback"),
   }
   ```
   Без regen content-pack UI показывает устаревший список команд. Класс проблем — «drift между Rust static и JSON runtime».

2. **aurora-pack.py имеет два режима:**
   - `content` — собирает **JS-файлы** (для Agency-стиля pack'а: command-meta.js, psy.js и т.д.)
   - `sign` — рекурсивно хеширует любую директорию + подписывает Ed25519. **Работает с любым форматом** (JSON, JS, HTML, что угодно).
   Для Econometrica, у которой pack уже в JSON, нужен только `sign` + ручная правка JSON.

3. **Supabase Storage лимит на .exe:** v1.0.0 = 116 MB проходил впритык, v1.0.7 = 117 MB → HTTP 413. Надо либо поднимать `file_size_limit` bucket, либо идти на GitHub Releases (2 GB лимит). Для приложений с bundled Python/JAX/NumPyro — будущие версии только растут.

4. **Production URL-routing для Econometrica:**
   - primary: Supabase Edge Function (`/auth`, `/content`, `/app-update`) с product=`aurora-econometrica-gui`
   - fallback: GitHub Pages `https://ackold26.github.io/rosst-updates/{product}/latest.json`
   - Product identifier в `updater.rs` берётся из `env!("CARGO_PKG_NAME")` → `aurora-econometrica-gui`
   - Supabase bucket маппится `aurora-econometrica-gui` → `updates/econometrica/` (через `online_auth.rs:42`)

### Security-инсайты для IT-документации

5. **Классы утечек в «безобидных» IT-доках:**
   - Формула machine fingerprint → позволяет спуфинг
   - Имя crypto-алгоритма (Ed25519) + длина ключа → направляет атаку
   - Имена внутренних файлов (`license.json`, `manifest.sig`, `cabinets.json`) → цели для подделки
   - Версии bundled-зависимостей → CVE surface
   - Структура bundled Python (`_internal/`) → monkey-patch vector
   - Имена процессов Python → помогает отличить от системных (двояко: нужно IT для whitelist, но помогает и cracker'у)

6. **«Безопасно раскрыть» в IT-доках можно:**
   - Имена основных процессов (видны в Task Manager после установки)
   - `%LOCALAPPDATA%` пути (стандарт Windows)
   - SHA256 инсталлятора (публично для верификации)
   - Supabase URL, GitHub URL (уже в `.exe` bundle)
   - Loopback 127.0.0.1 (стандартный network-термин)

### Операционные инсайты

7. **UTF-8 и bash/curl с кириллицей:** прямой `curl --data '{json с кириллицей}'` даёт mojibake в PostgREST (bash конвертит в cp1251). Решение: Python `urllib.request` с `json.dumps(ensure_ascii=False).encode('utf-8')` — работает чисто.

8. **gh CLI + GitHub Release assets:** синтаксис `file#displayname` при create работает для переименования, но GitHub сохраняет имена с точками вместо дефисов (`Aurora.AI.Econometrica_1.0.7_x64-setup.exe`). URL всё равно валидный, но при формировании `download_url` в latest.json нужно использовать именно имя-с-точками.

9. **Tauri NSIS output path:** `$CARGO_TARGET/release/bundle/nsis/{productName}_{version}_x64-setup.exe` — `productName` из `tauri.conf.json` с пробелами, путь с пробелами → при shell-операциях оборачивать в кавычки.
