# TEST_FINDINGS — Т3 drill-down 4 групп + сезонная %-кривая (2026-07-04)

Приёмка реализации Т3 (последняя задача автосезонности). Метод по AVT-стандарту:
чистую логику — юнит-тестами; форму данных — программной инспекцией на РЕАЛЬНЫХ
decompose-результатах (готовые pkl, без MCMC); визуальную форму echarts —
совместно с Антоном на живом окне (UX-развилки).

## Что реализовано
- `src/lib/decomposition-view.js` — SSOT view-логики: `planViewSeries(ds, expanded)`
  (свёртка по top_group → 4 полосы / drill-down раскрытие), `seasonalityPctOfBase`,
  `presentTopGroups`, `fallbackTopGroup`, константы. **26 юнит-тестов** (тождество
  свёрнуто/развёрнуто/частично, edge-cases).
- `ChannelTimeline.svelte` — свёрнутый режим 4 полос по умолчанию, chips-раскрытие
  групп (`$state expanded`) + клик по полосе, сезонная %-кривая на второй оси Y
  (тумблер-chip), tooltip: сезонность отдельной строкой «% к базе» (вне total/групп),
  highlight пропускает %-линию.

## 🟡 Находка: знакопеременная полоса «Конкуренты» у Venarus (НАСЛЕДИЕ, не блокер)
- Симптом: свёрнутая КОНКУРЕНТЫ Venarus Σ≈0, скачет −67.6M…+47.1M, 14 периодов
  противоположного знака к назначенному стеку (side=negative по mean). В area-стеке
  читается как визуальный скачок вокруг нуля.
- Корень: `signed_competitor` реально колеблется вокруг нуля (конкурент то помогает,
  то мешает). Backend `build_decomposition_series` назначает side по mean per_period.
- **Почему НЕ регрессия Т3:** группа КОНКУРЕНТЫ = 1 член → свёрнутый агрегат == тот
  же член == как рисовал старый код до Т3 (свёрнуто=развёрнуто, 1 полоса). Моя
  свёртка новой знакопеременности не создаёт; тождество данных цело.
- Вывод: существующее поведение отображения знакопеременного signed-фактора, вне
  предмета Т3 (хирургичность — не трогаю). Показать Антону скриншотом; если решит
  улучшать подачу таких факторов — отдельная задача.
