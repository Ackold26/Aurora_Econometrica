# Пульс: зонд GetExtendedTcpTable (2026-08-14)

## Задача своими словами
Нужно фактически (не по документации) проверить: может ли обычный процесс без
прав администратора и без порождения подпроцессов узнать через системные вызовы
Windows (`GetExtendedTcpTable` + `QueryFullProcessImageNameW`), кто держит конкретный
TCP-порт — включая идентификатор процесса и полный путь к его образу, даже если
процесс чужой (не наш потомок). Если подтвердится — в продукте Econometrica можно
будет отказаться от хранимого файла состояния движка (pid/image_path/started_at,
окно допуска по времени) в пользу вопроса системе «прямо сейчас».

## План
1. Прочитать `Cargo.toml` продукта → зафиксировать версию windows-sys (0.59, фичи
   Win32_Foundation/Win32_Security/Win32_Security_Authorization/Win32_System_Threading).
2. Создать отдельный крейт-зонд в scratchpad, свой CARGO_TARGET_DIR.
3. Реализовать перечень TCP (IPv4+IPv6, LISTENER) через GetExtendedTcpTable с
   правильным двухфазным вызовом (узнать размер → заполнить).
4. Для каждого держателя — OpenProcess(QUERY_LIMITED_INFORMATION) + QueryFullProcessImageNameW.
5. Таблица порт/pid/путь или код ошибки.
6. Сверка с ручным netstat -ano (руками, не из кода зонда).
7. Замер времени — 3 прогона.
8. Коды ошибок OpenProcess для мёртвого pid и защищённого системного процесса.
9. Записать итоговый отчёт PROBE_TCPTABLE_2026-08-14.md.
