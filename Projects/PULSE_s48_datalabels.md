# PULSE s48 — цвет подписей значений в HTML-отчёте

## Задача (своими словами)
Владелец: подписи значений на графиках (числа у столбцов/точек/долей) плохо читаются и в тёмной, и в светлой теме — либо чёрный на тёмном, либо белый на светлом фоне. Нужно найти ВСЕ места, где задаётся цвет подписи (класс проблемы, не одно место), посчитать контраст WCAG до/после по всем темам отчёта, починить через токен/расчёт по яркости подложки (а не зашитую константу), доказать готовым HTML, обновить/добавить охранный тест. Ничего не коммитить.

## План
1. Разведка: найти темы отчёта, найти все места задания цвета подписи значений (aurora_html/, charts/, aurora_tokens.py, CSS).
2. Замерить контраст ДО (таблица тема×место).
3. Починить класс проблемы.
4. Прогнать генерацию отчёта на демо-данных → получить готовый HTML → замерить контраст ПОСЛЕ из готового файла.
5. Расширить/добавить охранный тест на контраст подписей.
