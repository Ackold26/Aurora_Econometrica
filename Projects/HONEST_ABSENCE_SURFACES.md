# Инвариант «нет числа – нет подписи» — охват поверхностей MQS

## Задача своими словами
Отсутствующая оценка качества модели (MQS) сейчас на части клиентских поверхностей превращается
в ноль или в пустую шкалу «- /100» вместо честного текста об отсутствии оценки (как уже сделано на
слайдах PPTX и в секции findings HTML). Нужно: (1) найти ВСЕ поверхности, где MQS показывается
клиенту, дать вердикт по каждой; (2) починить находку 3 (XLSX/markdown, report.rs) и находку 4
(пустая шкала в HTML sections.py) тем же текстом отсутствия, что в PPTX; (3) завести гейт, который
краснеет при появлении новой поверхности с нулём-заглушкой (реестр исключений по литералу, не по
номеру строки); (4) доказать красноту тестов до правки и гейта на пустом списке отдельно.

## План
1. Инвентаризация поверхностей — grep по `mqs`/`MQS`/`Model Quality`/`качество модели`/`/100`/
   `unwrap_or(0.0)`/`?? 0`/`or 0` во всех стеках (Rust/Python/JS/Svelte).
2. Вердикт по каждой поверхности + таблица + число охвата.
3. Написать падающие тесты для находки 3 (XLSX/markdown) и находки 4 (HTML-карточка).
4. Починить report.rs (Option<f64> вместо unwrap_or(0.0)) и sections.py (условный рендер карточки).
5. Прогнать pytest + cargo test, зафиксировать дословный вывод.
6. Завести гейт охвата (скрипт-скан) + доказать его красноту на пустом входе.
7. Итог в этот файл, коммит `git commit --only`.
