# PULSE s49 — побайтовое доказательство правки интерфейса в установщике

## Задача (своими словами)
Предыдущая линия побайтово доказала правку движка (.py открытым текстом в установщике),
но не смогла тем же способом доказать правку интерфейса — перехват клика мышью в правовом
гейте (`TrialConsentOverlay.svelte`, запись `5ee6c875`). Причина: фронтенд Tauri v2 внутри
exe хранится сжатым brotli, прямой текстовый поиск даёт 0 совпадений — это не доказательство
ни в одну сторону без контрольного опыта.

## План
1. Прочитать исходники tauri-codegen (embedded_assets.rs) — как именно хранится ресурс.
2. Найти нужный $OUT_DIR по окну времени сборки (14.09, 10:18/10:23/10:31).
3. Распаковать кэш-файл brotli.exe, сверить sha256 с исходным чанком в build/_app/immutable/nodes/.
4. Искать СЖАТЫЕ байты в exe — сперва в промежуточной копии, затем в exe ИЗ installer_extract.
5. Контрольный опыт: та же методика на заведомо обязательной строке (aurora_gateway / имя exe).
6. Отчёт — PROOF_s49_frontend_in_installer.md.
