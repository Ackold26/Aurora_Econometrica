# PULSE — замер дублирования Rust-ядра по линейке Aurora AI (2026-08-14)

## Пересказ задачи
Нужна не архитектура, а цифры: сколько Rust-файлов в `src-tauri/src` буквально или почти
буквально повторяются между продуктами Aurora, сколько строк это составляет и какова
цена одного кросс-продуктового дефекта в строках правки. Отдельно — что реально уникально
для каждого продукта (граница будущего общего ядра). Только чтение и подсчёт, без правок
и без переключения веток в чужих деревьях.

## План
1. Выбрать по одному дереву на продукт (9 продуктов) — предпочтительно то, что стоит на
   последней релизной метке (`git tag --sort=-creatordate` + `branch --contains`).
2. Скриптом (python) обойти `src-tauri/src/**/*.rs` в каждом дереве, посчитать sha256 и число строк.
3. Сгруппировать файлы по относительному пути → по хешу: идентичные группы (≥3 продукта — ядро).
4. Для путей с расхождением содержимого — посчитать diff-строки против самого частого варианта.
5. Свести итоговые цифры (файлов в ядре, строк, цена дублирования) + уникальные файлы.
6. Записать отчёт `DUP_MEASURE_2026-08-14.md`.
