# Маячок · Праздничные колонки клиента в прогнозе

**Исполнитель:** Маша (агент) · **Дерево:** `Aurora_Econometrica_thinwt` · **Дата:** 2026-09-08

## Задача своими словами
Когда клиент называет событийную колонку по-своему («Чёрная пятница»), движок при построении будущего вклада ищет её среди канонических машинных имён дамми-праздников и, естественно, не находит. Итог — вклад события в прогнозные месяцы молча ноль, прогноз плоский. Надо связать клиентское имя с каноническим столбцом через уже имеющееся распознавание, не заведя второй справочник синонимов и не посчитав календарь дважды.

## План
1. Свой зонд: воспроизвести нулевой вклад дословным выводом.
2. Полная картина до правки: двойной счёт (что инжектит `modeler.py`), соседняя `_compute_scenario_seasonality`, потребители функции.
3. Правка только в сопоставлении имён (`scenario.py`, при нужде `utils/holiday_calendar_ru.py`).
4. Приёмка: новые тесты + «внести-поймать-откатить» + весь набор тестов движка + замер прогноза до/после.
5. Отчёт `Projects/FIX_scenario_holidays_2026-09-08.md`.
