## 9. Платформы

**Вердикт: НЕ ЗАКРЫТО — только Windows.**

- `src-tauri/tauri.conf.json:19-23` — `"bundle": { "targets": ["nsis"] }`. NSIS — формат инсталлятора только для Windows; нет `dmg`/`app` (macOS) или `deb`/`rpm`/`appimage` (Linux) в списке targets.
- Оверлей-конфиги `tauri.dev.conf.json`, `tauri.local.conf.json`, `tauri.thin.conf.json` — переключают режим сборки (dev/локальная редакция/облегчённая), не платформу; targets в них не переопределены на другие ОС.
- CI (`.github/workflows/ci.yml`): сборка Rust-бинарника идёт на `runs-on: windows-latest` (строка 141). `ubuntu-latest` (строки 81, 116) используется только для Python-тестов sidecar — в коде рядом явный комментарий «Python tests don't need Windows MSVC — faster + cheaper», то есть это оптимизация раннера для тестов, не кросс-платформенная сборка приложения. macOS-раннера (`macos-latest`) нет вообще ни в одном workflow.
- Rust-код глубоко Windows-специфичен: `cfg(windows)`/`cfg(target_os = "windows")` встречается в 19 файлах (86 вхождений), включая отдельный модуль `src-tauri/src/win_acl.rs` (работа с Windows ACL/правами доступа) — не косметика, а функциональная зависимость от Windows API.
- Итог: за прошедшее время сборок/конфигурации под macOS или Linux не появилось — продукт остаётся Windows-only.
