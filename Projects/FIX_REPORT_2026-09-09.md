```js
const PARAM_TYPE_LABELS = {
  beta: 'сила канала',
  adstock_decay: 'затухание',
  hill_alpha: 'крутизна насыщения',
  hill_gamma: 'насыщение',
  intercept: 'базовый уровень',
  factor_beta: 'влияние фактора',
};

function paramLabel(p) {
  const key = /** @type {keyof typeof PARAM_TYPE_LABELS} */ (p.param_type ?? '');
  const root = PARAM_TYPE_LABELS[key];
  if (!root) return p.name;
  return p.channel ? `${root} · ${p.channel}` : root;
}
```


## Что не стала править и почему

1. **Английские заголовки колоды PPTX.** У модуля PPTX свой файл строк –
   `sidecar/econometrica/aurora_pptx/strings_ru.json:36-38`: `SITUATION`, `COMPLICATION`,
   `RESOLUTION`, а также `:70,72` – `ACCEPTABLE`, `INSUFFICIENT`; плюс зашитые в код
   `aurora_pptx/builder.py:1215` («MARKETING MIX MODEL REPORT») и `master.py:132`
   («CONFIDENTIAL - For ... only»). Мой пункт – HTML-отчёт; если покупателю отдают ещё и
   колоду, там ровно та же беда, но это отдельное решение оркестратора.
2. **Слово «бюджет» в именах каналов** («Онлайн-видео бюджет») – это данные, а не текст
   интерфейса, и срезать его только на одном графике нельзя.
3. **Дефисы `-` в соседних строках** обоих файлов (клиентский стандарт требует «–»).
   Соседний текст, в задачу не входит.
4. **`_meta.version` в `strings_ru.json`** не поднимала – при сборке отчёта она нигде не
   проверяется, а трогать её без спроса значит добавить лишнее изменение.

## Замеченное попутно (не правила, на решение оркестратора)

`Asset integrity failure: echarts.common.5.5.1.min.js expected sha256 a42cc531…, got d78dc4eb…`
(`aurora_html/__init__.py:42,70`). Сам файл актива в рабочем каталоге не изменён (git показывает
