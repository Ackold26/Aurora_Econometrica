# Маячок s45 — перестройка справки по шагам

## Задача своими словами
Справка Эконометрики сейчас разложена по темам (данные, методология, толкование) и кнопка
«Справка по этому шагу» из мастера ведёт всего на три файла на семь шагов. Надо собрать восемь
новых страниц — по одной на каждый шаг мастера плюс паспорта показателей — где текст идёт
в одном и том же порядке: что происходит, что нужно от клиента, как читать результат, типовые
ошибки. Материал в основном уже написан, его надо перекомпоновать из файлов-дублёров и дописать
четыре новых куска (макро «изменение, а не уровень», тринадцать праздников, чтение прогноза
и ошибки Планирования, паспорта показателей). Вместе с текстом обязаны поехать четыре места
в коде, иначе кнопка справки молча покажет пустоту.

## План
1. Разведка кода: фактические списки (макро-столбцы, праздники, типы паспортов).
2. Чтение файлов-доноров построчно.
3. Семь файлов шагов.
4. kpi-passports.html.
5. Четыре места в коде: HELP_PAGES, econ-nav.js, build_help_pdf.py, маркеры AUTO_*.
6. Внутренние ссылки — grep и починка.
7. Гейты: npm run test, npm run check, сборка PDF, длинное тире.
8. Сторож на существование файлов HELP_PAGES + доказательство падения.
