# Pulse — проверка незакоммиченных файлов перед слиянием веток

## Задача (своими словами)
Есть 11 рабочих деревьев репозитория Aurora_Econometrica (все отправлены на origin, незапушенных записей 0), но в каждом лежат незакоммиченные файлы. Нужно понять по каждому дереву и файлу: это рабочий мусор, рабочий документ (план/отчёт) или незакоммиченный КОД продукта — и не потерять ничего ценного при сведении веток. Только чтение, ничего не менять.

## План
1. По каждому из 9 деревьев (список от team-lead) — `git status --porcelain`.
2. Для изменённых (` M`) файлов — `git diff --stat`, при малом объёме (≤20 строк) — сам дифф, одна строка сути.
3. Для новых (`??`) файлов — размер + первые 30 строк, описание.
4. Вердикт по каждому файлу: КОД / РАБОЧИЙ ДОКУМЕНТ / МУСОР.
5. Свести всё в findings_dirty.md с таблицей и разделом «Требует внимания перед слиянием».
