# PULSE s48 — мышиный гейт

## Задача
Гейт «Условия ознакомительного использования» закрыт только для клавиатуры (величина
`trialConsentBlocking` читают лишь два обработчика keydown). На главной странице девять
обработчиков мыши гейт не проверяют вовсе, а разметка окна монтируется по `visible`, а не по
`blockingActive` — физического перекрытия экрана нет в первые сотни мс после запуска. Нужно
закрыть КЛАСС обхода (любой указатель/будущий обработчик), а не перечислить девять мест.

## План
1. Красный тест: клик мышью по карточке кабинета/настройкам при незавершённом ответе ядра —
   переход не должен происходить, а он происходит.
2. Физическое перекрытие: невидимый блокирующий слой, смонтированный по `blockingActive` (а не
   `visible`), перехватывающий указатель поверх всего приложения, пока гейт не снят.
3. Сверить: окно условий внутри перекрытия остаётся кликабельным (чекбокс, кнопки), после
   принятия перекрытие снимается полностью.
4. Прогоны: npx vitest run (ожидание ≥1641+новые, 0 отказов), npm run check (0 ошибок).
