# Разведка выпускных веток — PR Studio, AI Agency, Media Radar (2026-08-14)

Задача: определить, из какой ветки уходят к клиентам сборки трёх продуктов без надёжных версионных меток, чтобы не положить правку CPD-77 (живой вызов `icacls`) в мёртвую ветку. Разведка только на чтение — правок, переключений ветки, сборок не было.

Приём «`git tag --sort=-creatordate` + `git branch --contains`» применён первым для всех трёх, как и было рекомендовано. Вопреки исходной оценке задачи, теги в деревьях есть — просто раньше их, видимо, смотрели без сортировки по дате и без интерпретации, что это не продуктовые релиз-метки, а метки сессий/кабинетов.
