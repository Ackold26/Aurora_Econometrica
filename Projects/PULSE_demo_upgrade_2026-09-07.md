# Маячок: доработка демонстрационных данных до полного функционала

**Задача своими словами.** Шесть наборов-примеров, которые едут клиенту в поставке, должны честно
показывать весь продукт: и построение модели, и прогноз по будущему медиаплану. Модель на каждом
обязана сходиться (R-hat ≤ 1,01, дивергенций 0, ESS ≥ 400, R² ≥ 0,7), предполётная проверка —
давать вердикт `reliable` без кнопки обхода, а оптимизация — заметный прирост по медиа (≥ 10 %)
за счёт разброса маржинальных окупаемостей между каналами (≥ 3×). Правим ДАННЫЕ через генератор
`tools/generate_demo_samples.py`, движок и пороги не трогаем.

**План.**
1. Прочитать опись, генератор, гейт схемы; поднять свой экземпляр движка на свободном порту.
2. Замерить фактическое состояние всех 6 наборов прогоном (проверка → обучение → декомпозиция → оптимизация).
3. Довести генератор до целевых порогов (перекос насыщения с фиксированной абсолютной `sat_ref`).
4. Закрыть пробелы охвата: плановые версии Недвижимости и Ритейла; разбор по Rx-фарме.
5. Расширить `tools/test_sample_data_ssot.py` на `planning/`, проверить мутацией.
6. Отчёт `Projects/DEMO_DATA_UPGRADE_2026-09-07.md`.

**Ограничения.** Боевой `%APPDATA%\com.aurora.econometrica\projects\demo-fmcg-brand` — не трогать.
Кагоцел / Венарус / MMX — не использовать. Пороги 20/30 и 0,5/0,8 — не трогать. Не коммитить.
Удаление — только в корзину.
