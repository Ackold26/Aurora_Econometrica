# INV-50 sweep рантайм-кода — разведка (2026-07-19)

Периметр: `src/`, `sidecar/`, `src-tauri/src/` (справка `src-tauri/help-econometrica/*` и
`src/lib/glossary.js` уже приведены к канону ранее — вне этой разведки).
Канон: байесовский/статистический интервал в клиентском тексте — «правдоподобный диапазон»,
не «доверительный интервал»/«CI»/«Posterior CI»/«95% CI»/«credible interval».

Паттерн: `grep -rniI -E "доверительн|posterior ci|95%\s*ci|\bci\b|credible interval"` c
исключением `dist/`, `_internal/` (PyInstaller-бандл — копия исходников + vendored scipy/
sklearn/arviz/econml/linearmodels, НЕ источник правды, из периметра исключена целиком),
`node_modules/`, `__pycache__/`, `.svelte-kit/`, `build/`.

Плюс **2 находки вне заданного grep-паттерна** (не ловятся `\bci\b`/`доверительн`, но по духу — то же нарушение):
- кириллическая аббревиатура **«ДИ»** (= Доверительный Интервал) в живом тултипе графика прогноза;

Множественная форма «CIs» (без `\b` после s) тоже проскочила мимо строгого паттерна — 3 места
нашлись в `causal/preflight.py` только благодаря ручной перепроверке.

**Ложных срабатываний «CI» ≠ статистика: 8** — Continuous Integration (комментарии/тесты про
сборку, 6 мест в Rust + 1 в JS-тестах), Windows ACL-флаг `(CI)` в `icacls` (`session/manager.rs`),
`ci` = carry-in (adstock) в тестах питон-движка (не статистика вообще).
