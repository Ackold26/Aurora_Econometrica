# Handoff для аудитора — блок «F2 + разрыв линии + Low-хвосты» (Econometrica, сессия 2026-07-18/19)

База аудита: `756caa8..7eeb0e6` (коммиты `ec3dced` хвосты + `7eeb0e6` график). Оба на origin/feat/econ-v2.3.0.
Diff: `scratchpad/audit-session.diff` (18+/7−, 3 файла).

## 1. Цель блока
Минорные UX/качество-фиксы на шаге «Планирование» MMM-пайплайна + хвост аудита сборки:
(1) метка «Дата отсечки» на графике «Прогноз по сценариям» — горизонтальная, не повёрнутая вертикально;
(2) линия факт→прогноз рисуется непрерывно, без визуального разрыва на дате отсечки;
(3) упрощение недостижимой ветки `else []` в смоук-тесте сборочного бандла;
(4) замена длинного тире «—» на короткое «–» в клиентском тексте карточки «Сбывшиеся рекомендации».

## 2. Ключевые инварианты
- **ContinuationChart — стыковка факт→прогноз только презентационная.** Узел стыковки сажается
  в `aligned`-массив прогнозной серии (для отрисовки ECharts), НЕ в источник данных. Значение
  узла = последнее ФАКТИЧЕСКОЕ (`actualAligned[effectiveCutoff]`), не прогнозное — линия факта
  честно перетекает в прогноз из реальной точки.
- **Стыковка не перезаписывает данные:** применяется только если `aligned[effectiveCutoff] == null`
  (у прогноза нет своей точки на отсечке). Условие `cutoffValue != null` защищает от пустого факта.
- **F2:** добавлен `rotate: 0` к `label` markLine отсечки; `position: 'insideEndTop'` сохранён,
  formatter/цвет не тронуты. ECharts по умолчанию поворачивал метку вдоль вертикальной линии.
- **build_sidecar:** поведение смоук-теста идентично — `targets` всегда содержал CSV+XLSX
  (`xlsx_path` присваивается безусловно на стр. 214, `Path` всегда truthy, при провале
  xlsx-фикстуры `sys.exit(1)` до health-гейта). Упрощение `[a]+([b] if x else [])` → `[a, b]`.
- **PromisesCard:** заменено ТОЛЬКО длинное тире в клиентском (отображаемом) тексте; комментарии
  кода, логика, разметка не тронуты.

## 3. Осознанные компромиссы
- **F2 через `rotate:0`, не смена position** → минимальное вмешательство, сохранён исходный layout метки.
- **Стыковка в презентационном слое, не в данных** → визуальная непрерывность не должна мутировать
  серии, используемые логикой; данные приходят из родителя/бэкенда.
- **`else []` упрощён, не удалён с сохранением защиты** → недостижимость доказана (не косметика ради
  косметики); при 100% доказательстве предпочтён литерал списка ради читаемости.

## 4. Зоны неуверенности
1. **cutoffIndex ≠ конец истории.** Узел стыковки = `actualAligned[effectiveCutoff]`. Если `cutoffIndex`
   передан явно (проп) и указывает НЕ на последнюю фактическую точку, `actualAligned[effectiveCutoff]`
   может быть null (факт там отсутствует) → стыковка не сработает, ИЛИ посадит промежуточное значение.
   Проверить путь с явным `cutoffIndex`.
2. **CI-ленты не состыкованы.** Узел добавлен только основной линии сценария, НЕ CI-лентам
   (`ciLow`/`ciHigh`). Возможен визуальный отрыв ленты от точки отсечки (лента с cutoff+1).
   Оценено как приемлемое (CI в точке факта ≈ 0), но на проекте с видимыми CI живьём не проверено.
3. **Multi-scenario.** `cutoffValue` сажается во ВСЕ видимые сценарии в один индекс `effectiveCutoff`.
   Если у сценариев разные стартовые даты прогноза, общий узел может исказить тот, чья серия реально
   начинается позже отсечки. Проверено только на одном сценарии («Базовый план»).

## Результат внешнего аудита (opus, чистый контекст, 2026-07-19) — ГОТОВ К MERGE
Critical/High = 0. Подтверждено чистым: `else[]` реально недостижим; F2 ничего не ломает;
PromisesCard — только клиентский текст; зоны №2 (CI-ленты) и №3 (multi-scenario) приемлемы.
Открыты 2 находки (обе в бэклог, не блокеры, к клиентам не ушли — копятся в прод-ветке):
- **[Medium] Утечка стыковочной точки в axis-тултип.** На месяце отсечки каждый сценарий показывает
  в подсказке значение = последний факт (инъекция `aligned[effectiveCutoff]`), хотя прогноза там не
  было. Число реальное (=факт), одна точка. Подтверждён лично (tooltip formatter `echarts-setup.js`
  не фильтрует серии). ПРИНЯТ как известный компромисс. План фикса: пометить инъектированную точку
  (`{value, __stitch:true}`) и скрывать её в formatter для серий-сценариев (образец `isForecast` в
  `forecast-chart-format.js`). Закрыть до следующего билда (INV-50-чувствительно).
- **[Low, латентный] Ложная диагональ при mid-history `cutoffIndex`.** НЕ достижим текущим вызывающим
  (`PlanningStep` передаёт `cutoffIndex=histLen-1`). Defensive-фикс: инъектировать только при
  `effectiveCutoff==histLen-1`. В бэклоге.
