## 2. Ключевые инварианты

1. **Опорные числа не меняются.** R² 0,936 · MQS 70 · mROAS 5,66 и 10,21. Расхождение = правка
   задела расчёт, чего быть не должно.
2. **Домен хранится ТОЛЬКО в читаемом написании**, машинный адрес выводится приведением к
   строчным в момент использования. Две константы рядом запрещены — расходятся молча.
3. **Внешние ссылки открываются системно**, `target="_blank"` запрещён; требуется разрешение
   `opener:allow-open-url` — без него отказ ТИХИЙ.
4. **Свойства документа проверяются по ВСЕМУ списку инварианта**, а не по исправленным полям.
   Поле «Приложение» живёт в `app.xml` и обычным путём не правится.
5. **Сторож выходного документа обязан оставаться 34/34.** Красный после правок = регресс.
6. Отраслевые термины не переводятся (ROI, KPI, MMM, mROAS, MAPE, HDI, Performance, Search).

## 3. Осознанные компромиссы

1. **Полное имя программы заведено константой в файле настроек**, а не взято из источника:
   целиком его нет нигде — в пакете «Aurora AI Econometrica» (семейство), в конфигурации
   «Optimizer MMM» (техническое имя). Компромисс: при смене имени править в двух местах.
2. **6 длинных тире в отчёте на реальных данных не почищены** (одно в тексте вывода, пять в
   разделителях дат). Причина: пересборка ради косметики против уже проверенной сборки.
3. **Сторож отчёта по-прежнему не подключён** ни к приёмке, ни к сборке — подключать вместе со
   сторожем доставки после показа, иначе валящая проверка запрёт выпуск накануне встречи.
4. **`connect-src` не исправлен**: сейчас директива игнорируется браузером целиком, её починка
   ВКЛЮЧИТ ограничение, которого сегодня нет, и может сломать работающее.

## 4. Зоны неуверенности

1. **Экран настроек проверен только глазами владельца по снимку.** Отладочный мост в поставке
   выключен, программной инспекции интерфейса не было. Обрезание второй строки нашёл владелец,
   не проверка — значит подобное может остаться и в других местах экрана.
2. **Подчёркивание ссылок и полное имя в третьем проходе сборки на момент передачи НЕ проверены
   живьём** — сборка шла в момент написания.
3. **Отчёт и колода выгружены МОИМ вызовом движка, не через интерфейс программы.** Структура
   запроса собрана вручную; первая попытка дала неполный отчёт (пропал блок диагностики).
   Совпадение с тем, что соберёт программа, доказано только по R².
4. **Свойства колоды проверены на выгрузке, сделанной до третьего прохода сборки.**
