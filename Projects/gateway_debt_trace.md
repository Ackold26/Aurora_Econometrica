- attempts = 6: client.rs:338 `attempts: RETRY_BACKOFF.len() + 1`. Продукт НЕ переопределяет

- Повторяется ТОЛЬКО `Connection`: client.rs:922
  `let retryable = matches!(err, CloudError::Connection(_));`
- Паузы client.rs:35-41: 2 + 5 + 10 + 20 + 30 = **67 с** суммарного сна между шестью попытками.
- Сроки client.rs:31-33: соединение 15 с, тишина сокета 60 с, ОБЩЕГО срока на запрос нет.

Арифметика:

| Природа отказа | Время до сообщения |
|---|---|
| мгновенный отказ (нет маршрута / DNS / отказ в соединении / быстрый 5xx-429 от посредника) | ≈ **67 с** ✅ совпало с наблюдением |
| срок соединения 15 с на попытку | 6×15 + 67 ≈ 157 с ✗ |
| срок тишины 60 с на попытку | 6×60 + 67 ≈ 427 с ✗ |

Доказательное следствие: наблюдённая «примерно минута» означает, что **каждая из шести попыток
падала мгновенно**. Клиент не «ждал, не отправив» — он отправлял шесть раз, и все шесть умерли
до узла: либо соединение не устанавливалось вовсе, либо отвечал не наш узел, а посредник перед
ним (вход `https://rag.auroraai.pro/cloud`, gateway_executor.rs:41 — между клиентом и
приложением стоит nginx с приставкой `/cloud`).

## Что объясняет ТАКЖЕ почерк Smart Analytica (POST /jobs → 202, тишина, отмена клиентом)
Общий слой даёт готовый механизм «клиент сам отменил здоровую работу»:
- ChatPanel.svelte:892-907 — предохранительный таймер интерфейса: по истечении срока
  `invoke('cancel_claude', ...)`, то есть настоящая отмена задания НА СЕРВЕРЕ
  (gateway_executor.rs:157 `request_cancel` → `work.cancelled()` → `stop_job`, client.rs:454).
- Сроки psy.js:171-175: `default` 90 с, `media-analyst` 600 с, `econometrist` 900 с.
- Снимается таймер по СОБСТВЕННОМУ синтетическому событию init, ChatPanel.svelte:517-521,
  которое продукт шлёт сам сразу после старта (gateway_executor.rs:789-796) — признаком
  «сервер жив» служит наше же сообщение, а не ответ сервера.
- Конвейерный вход шлёт `suppress_done = true` (gateway_executor.rs:1257) → init НЕ шлётся →
  таймер остаётся взведённым и срабатывает по сроку кабинета, отменяя принятое задание.

Отсюда общий класс дефекта, а не беда одного продукта: **признак живости берётся не оттуда**.
В Эконометрике синтетический init гасит сторож в первые миллисекунды (сторожа фактически нет,
окно может висеть бесконечно), в конвейерном пути сторож, наоборот, рубит живую работу. Числа
Smart Analytica (три минуты) — из её собственного `psy.js`, здесь НЕ установлены.
