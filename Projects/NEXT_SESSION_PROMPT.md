## 🎯 Руководство по стилю действий (пополнено в s42)

1. **Условие выхода наблюдателя — артефакт РАБОТЫ, а не отчётный документ.** Трижды за сессию
   наблюдатели закрылись ложной тревогой «отчётов нет»: среда запрещает субагенту писать отчётные
   `.md`, и он отдаёт отчёт текстом. Сработало: ждать новую запись в его ветке, живость мерить
   временем изменения файлов кода.
2. **Два соседних `bool` в вызове переставляются молча.** `route_changed_notice(cloud, locked)` —
   перестановка возвращала исходный дефект, и ни один тест не краснел. Лечение не тест, а тип:
   функция принимает состояние целиком.
3. **Свой тест может быть зелёным по случайности.** Тест V57 перебирал пояса, но не подавал пояс в
   проверяемую функцию — пять одинаковых вызовов. Проверка обязана переходить через границу, на
   которой дефект проявляется (здесь — через полночь UTC).
4. **Подтверждение сторожу пишется его синтаксисом.** Причина с точкой с запятой развалила значение
   `AURORA_CRATE_TAIL_ACK`: сторож делит по ней и счёл хвост второй записью.
5. **Ложная краснота — тоже находка.** Укрепляя сторожа, исполнитель получил четыре ложных красных
   на чистом дереве; одна вскрыла живой баг разбора сырых строк в `sidecar_runtime.rs`, ломавший
   сторожа на сотни строк вниз.
6. **Текстовый сторож ловит форму, не поведение.** 28 мутаций проверяющего показали предел: сильнее
   — компилятор (`#[deprecated]` на выведенных функциях) и один модуль-посредник, вне которого
   сетевой клиент не собирается. Это Б-47.
