## 🔴 Грабли блока — дороже кода

1. **Клиентский `.docx` править ТОЛЬКО библиотекой** (`python-docx`). Ручная правка разметки
   вписала недопустимый символ, документ перестал открываться; поймала своя же проверка
   целостности. Копию делать ДО правки, открываемость проверять ПОСЛЕ.
2. **Суммы по байтам требуют закреплённых переводов строк.** У библиотеки графиков не был
   закреплён режим при `autocrlf=true` → каждый экспорт отчёта писал «Asset integrity failure».
   В июне лечили симптом (обновили константу), причина осталась и дрейф повторился. Закреплено
   `.gitattributes` в `aurora_html/templates/`.
3. **Починка одной половины оставляет вторую.** Тот же дефект «текст берёт канал из эвристики
   вместо решения оптимизатора» чинили в апреле — в презентации. В сводке отчёта запасная ветка
   осталась и всплыла через полгода, уже у клиента. Чинить класс, а не место.
4. **Проверка на фикстуре и живой прогон сторожат РАЗНОЕ.** Фикстура стережёт контракт формы,
   живой прогон — что движок этому контракту следует. Без второго сторож зелен на выдуманной
   фикстуре при снова сломанном движке.
5. **Библиотека графиков молча выбрасывает неподдерживаемый тип серии** — без ошибки и без записи
   в консоли. Проверять отрисовку по числу фигур, а не по отсутствию ошибок.
6. **Доклад исполнителя о результате сверять с диском.** Дважды за блок доклад расходился с
   фактом: один агент сообщил «приёмка красная», когда его же перегон уже лежал зелёным.
