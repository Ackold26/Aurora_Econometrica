1. **Пульс + наблюдатель + сигнал на `EXIT:`** – исполнители (Sonnet особенно) уходят ждать системного
   уведомления о фоне; ставь свой сигнал на строку итога и буди сообщением.
2. **Субагент не может писать файлы с именем report/summary/findings/analysis** – в задании имя вида
   `CIFIX_*.md` / `PREFLIGHT_*.md` либо итог текстом; отчёт в дерево пишет оркестратор.
3. **Предпосылку задания проверять фактом до постановки**: «последний зелёный CI 25.09» оказался заданием
   Supabase Keepalive – `gh run list --workflow ci.yml`, а не общий список.
4. **Зелёный CI-слой может скрывать следующий**: починили `tools` – открылись тесты движка; падающий шаг
   маскирует все шаги после себя. Читать список работ и шагов, а не одну строку итога.
5. **Оболочка харнесса – администратор**: пробы установки только пониженным токеном
   ([[feedback_harness_shell_runs_elevated_lower_token_for_install_probes]]).
6. **Сеть до github рвётся** – сразу зеркало окружением, не повторы ([[feedback_flaky_github_build_local_mirror_via_env]]).
7. **Память машины общая с 4–5 сессиями** – перед сборкой смотреть свободную память; система снимает фоновые
   команды без спроса, и перезапускать их самой нельзя – только по слову владельца.
