# Свод рядов ЦБ в макропоказатели (s46, 13.09.2026)

## Что сведено
Четыре ряда ЦБ (доллар, евро, юань, ключевая ставка) из `Projects/macro_series_draft/cbr_raw/*.xml`
слиты с уже готовым ИПЦ Росстата в `macro_monthly.csv` (121 месяц, 2016-09…2026-09) и
`macro_weekly.csv` (недели ISO за тот же период). Прогон – через сам загрузчик
(`fetch_macro_series.py --cbr-raw-dir cbr_raw`), не отдельный одноразовый скрипт: меньше риск
разъехаться с проверенной математикой агрегации.

## Правило агрегации и почему
- **Месячная таблица** – ДВЕ колонки на курс/ставку: `_уровень` (среднее дневных значений за
  месяц, ОСНОВНАЯ – от неё считается `_изменение_pct`) и `_уровень_конец_месяца` (последнее по
  дате значение). Среднее выбрано основным: показывает условия всего месяца, а не случайный
  снимок одного дня; для ставки честно отражает смену в середине месяца.
- **Недельная таблица** – ОДНА колонка `_уровень` = значение НА КОНЕЦ недели (не среднее) – по
  прямому указанию к задаче.
- **ИПЦ** – не тронут: месячное значение = официальный Росстат, `_уровень_конец_месяца` для него
  численно равен `_уровень` (нет дневной гранулярности, не второй расчёт). Понедельно –
  честный forward-fill месячного (README помечает это явно, как и раньше).
- Пропуски НЕ заполнялись – пустая клетка, если в периоде нет ни одного официального наблюдения.

## Находки при своде
1. **Реальный дефект**: `_parse_cbr_currency_xml` игнорировал `<Nominal>` – брал голое `<Value>`.
   У юаня `Nominal` реально скачет 1↔10 по истории (`cbr_raw/cny.xml`, 01.09.2016 – `Nominal=10,
   Value=97,7127`) – без деления курс на части окна был бы занижен в 10 раз. Исправлено:
   курс = `Value / Nominal`. Мутация «внеси-поймай-откати»: убрала деление → упали
   `test_parse_cbr_currency_xml_divides_by_nominal` и `..._real_cny_sample_nominal_changes_mid_series`
   (`AssertionError: Obtained: 97.7127, Expected: 9.77127`) – вернула правку, тесты снова зелёные.
2. **Разбор ставки уже был верным** по факту (`<KR><DT>/<Rate>`, а не `<KeyRate>` из документации) –
   код и раньше ориентировался на факт содержимого, докстринг был не обновлён. Подтвердила на
   настоящем файле (2524 записи) и закрепила сторожем; убрала из докстринга пометку «не проверено
   вживую».

## Маршрут через узел
`--через-узел <имя из ~/.ssh/config>` – скачивание источников ЦБ выполняется на узле по ssh
(`curl` в теле команды, тело SOAP-запроса идёт через stdin), файл забирается потоком; прямой путь
остаётся рабочим по умолчанию. Ключ не хранится, пароль не запрашивается – расчёт на уже
поднятый ssh-агент. Покрыто 5 сторожами с моком `subprocess.run` (успех GET/POST, код ошибки,
таймаут, прямой путь без ssh при не заданном флаге). Отдельно `--cbr-raw-dir <каталог>` –
для разового скорма уже скачанных файлов (как в этом своде); README честно указывает, какой
маршрут использовался в конкретном прогоне.
