# PULSE — живой сторож полей паспорта воспроизводимости (repro_fields_live)

## Пересказ задачи

Тест `test_train_model_stores_protocol_under_free_name` стережёт `data_fingerprint`
и `adstock_selection` по подстроке в исходнике `modeler.py` — слабо: другая
формулировка кода даёт ложный красный, пустое поле в реальной модели — ложный
зелёный. Нужен живой тест `tests/test_repro_fields_live.py` по образцу
`test_mcmc_determinism_live.py`: обучает модель по-настоящему, перечитывает
сохранённый файл модели с диска через `load_model_with_compat` (не по возврату
функции) и проверяет факт наличия и честности обоих полей — включая то, что
исходная настройка `'auto'` не затирается мутацией `adstock_config` на месте.
Две мутации продуктового кода должны красить тест, затем откат — снова зелёный.

## План
1. Прочитать образец (`test_mcmc_determinism_live.py`) и слабый тест
   (`test_repro_data_and_adstock.py`) — форма полей, как помечен slow/skip.
2. Прочитать `engines/modeler.py` (снятие fingerprint, `_resolve_auto_adstock`,
   сборку `model_data`), `engines/persistence.py::load_model_with_compat`,
   `utils/data_fingerprint.py` — точные имена полей и форма.
3. Написать синтетический генератор данных (без внешнего xlsx — надёжнее,
   не завязан на присутствие файла на машине) с двумя медиаканалами: один
   `'auto'` (гоняет BIC-путь), один явный (гоняет `ADSTOCK_BY_USER`).
4. Написать тест: обучение с минимальными chains/draws/tune → перечитать
   файл модели с диска → 4 проверки по заданию.
5. Прогнать зелёным, засечь время.
6. Мутация 1: убрать `'adstock_selection': dict(adstock_selection),` из
   `modeler.py` → тест должен покраснеть по факту отсутствия поля.
7. Откатить, подтвердить зелёный.
8. Мутация 2: `utils/data_fingerprint.py::build_data_fingerprint` возвращает
   отказ вместо содержательного отпечатка → тест должен покраснеть.
9. Откатить, подтвердить зелёный.
10. Отчёт команднику.

Старт: 2026-08-16.
