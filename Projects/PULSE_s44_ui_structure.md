# PULSE s44 — устройство интерфейса (прокрутка · подсказка · график фронтира)

**Задача своими словами.** Три правки интерфейса Эконометрики. (1) На шагах «Отчёт» и «Декомпозиция»
две вертикальные полосы прокрутки — привести корневые блоки к устройству вылеченного `OptimizeStep`
(прокруткой владеет внешний контейнер). (2) Всплывающая подсказка обрезается предком с прокруткой —
лечить на класс: пузырь в корень документа по координатам триггера. (3) Карточка профит-фронтира:
латиница, «Goal-Seek», дефисы вместо «–», высота/разворот, оси, легенда, троеточие.

**План.**
1. Разведка: `OptimizeStep` (эталон) / `ReportStep` / `DecomposeStep` / `.main` в `+page.svelte`.
2. Правка прокрутки → живое измерение (число полос, срезан ли верх).
3. Подсказка: `position: fixed` в портале + пересчёт по `getBoundingClientRect()` → измерение у верха и у низа окна.
4. Фронтир: семь пунктов, каждый с обоснованием; 5 и 6 — по живым данным.
5. Приёмка: `npx vitest run`, `npm run check`.
