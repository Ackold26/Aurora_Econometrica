# PULSE s44 — путь отказа обновления (исполнитель update-path)

## Задача своими словами
Чиню то, что видит клиент, когда обновление программы не встало: блокирующее окно
показывает общий текст по коду и затирает точную причину, которую Rust уже знает
(H-1), а самый частый отказ «нет сети» приходит вовсе без кода и запасной текст про
сеть молчит (H-2). Плюс четыре мелких: недостижимая ветка UP-005 (L-1), ложная
ссылка в шапке файла (L-5), слишком широкая регулярка кодов (L-6) и риск вытолкнуть
единственную кнопку за край окна раскрытыми «Подробностями» (L-7).

## План
1. Прочитать все ветки `coded_err` в `updater.rs` и лично проверить признак
   «кириллица = человеческая деталь» — без механического применения.
2. H-1: выбор детали Rust поверх таблицы + сторож на стык с доказательством мутацией.
3. H-2: `coded_err(UP001, …)` на все сетевые отказы (сборка клиента, отправка,
   разбор JSON, путь Supabase) + сеть в запасном тексте + отдельный текст для `Ok(None)`.
4. L-7: ограничение высоты карточки с прокруткой.
5. L-1, L-5, L-6 — мелкие правки с обоснованием.
6. Приёмка: `npx vitest run`, `npm run check`, `cargo check`.
