# PULSE s44 — высота графиков в разворот + ручное изменение размера

## Задача своими словами
На шаге «Модель» карточки графиков разворачиваются во весь экран через `ExpandableCard`. В прошлой сессии
высоту «починили» параметром сниппета, тесты зелёные, но живое измерение дало 24 % высоты окна вместо 70 %.
Мне надо довести до ЧИСЛА, измеренного в живом окне: график в развороте ≥60 % высоты окна, плюс сделать так,
чтобы при ручном изменении размера карточки (перетаскивание угла) холст echarts сам пересчитывался
(`ResizeObserver` в `EChartBase`, одним приёмом на все 15 графиков, а не копией в каждом файле).

## План
1. Прочитать текущее состояние: `ExpandableCard.svelte`, `EChartBase.svelte`, `ConvergenceDashboard.svelte`,
   `PPCScatter/PPCResidualsChart`, незафиксированный диф `Projects/audit_s43_uncommitted.diff`.
2. Найти дешёвый путь до панели сходимости (фикстура / готовый проект), либо запасной вариант — любая карточка с графиком.
3. Поднять `npm run tauri:dev`, мост на 9223, `driver_session` start.
4. Измерить ДО: цепочка высот оверлей → `.overlay-card` → `.chart-panel-body` → корень → `.chart-cell` → echarts → canvas.
5. Починить найденное звено + `ResizeObserver` в `EChartBase`.
6. Измерить ПОСЛЕ: % от `window.innerHeight`; программно изменить размер `.overlay-card` → заново измерить холст.
7. Приёмка: `npx vitest run` (эталон 1493), `npm run check` (эталон 0 ошибок / 177 предупреждений).
