# Пульс — правка CPD-77 (часть А) в трёх продуктах

## Задача своими словами
Убрать вызов `icacls` в `SessionManager` трёх продуктов (Legal Center, Creative Center, Oracle) —
эталон уже сделан в Эконометрике (коммит `ea560be`). Вызов не давал защиты сверх умолчаний
Windows (каталог и так внутри `%LOCALAPPDATA%` профиля), зато на каждом запуске стирал
наследуемые права SYSTEM/Администраторы через `/grant:r` (замена, не добавление) и выглядел
для антивируса как подготовка шифровальщика перед массовой записью файлов. Работаю в трёх уже
подготовленных изолированных копиях (worktree), в исходные деревья не захожу.

## План
1. Прочитать эталонный коммит `ea560be` (диф + сообщение) — образец текста и формулировок.
2. По каждому продукту (Legal → Creative → Oracle): найти блок `icacls` через `rg -n "icacls"`,
   убрать его целиком, оставить `create_dir_all`, поставить комментарий-обоснование, проверить
   нужность `use std::os::windows::process::CommandExt;` / `creation_flags` перед удалением импорта.
3. `cargo check` по каждому продукту (свой `CARGO_TARGET_DIR`).
4. `cargo test` строго последовательно по каждому продукту, зафиксировать числа.
5. Запись изменений в каждой копии отдельно, поимённый `git add`, сообщение по образцу + со-автор.
6. Написать отчёт `FIX_CPD77_THREE_2026-08-14.md` (800-1200 слов).
7. Финальная сводка руководителю.
