# Пульс s44 — ui-structure-b (Маша)

## Задача своими словами
Две правки клиентского вида в Эконометрике. (1) Всплывающая подсказка (`Tooltip.svelte`) обрезается: она `position: absolute` внутри обёртки, а место считает по окну — значит её режет ближайший предок с прокруткой/`overflow: hidden` и край окна. Лечить на класс: вынести пузырь в корень документа, `position: fixed` + координаты триггера, сохранив Esc, `aria-describedby`, `role="tooltip"`, `prefers-reduced-motion`, неперехват мыши, следование при прокрутке. (2) Карточка профит-фронтира `ProfitFrontierCard.svelte` — семь пунктов: латиница «Max» на графике, «Goal-Seek» в клиентском тексте, дефисы вместо «–», жёсткая высота 280 без разворота, оси от нуля, длинная подпись легенды, три точки вместо «…». Плюс проверить живьём правку прокрутки на «Отчёте» (сделана тим-лидом) — одна ли полоса и не срезан ли верх.

## План
1. Прочитать `Tooltip.svelte`, `ProfitFrontierCard.svelte`, соседние карточки (имена расчёта, `ExpandableCard`, эталон осей).
2. Правки в коде: сначала ProfitFrontierCard (дешевле и изолированно), затем Tooltip (класс-правка).
3. Поднять `npm run tauri:dev`, мост 9223, измерить: границы пузыря у верхнего/нижнего края; прокрутка на «Отчёте»; легенда фронтира.
4. Приёмка: `npx vitest run` (эталон 1514), `npm run check` (7 чужих ошибок — не мои).
