# Отчёт — починка F-06 и F-11 (внешний аудит колоды, 2026-08-16)

## F-06 (High) — сторож стерег собственную копию

**Было.** `test_mutation_gate_promises_condition_is_load_bearing` определял внутри себя
`_mutated_build` — переписанное тело `AuroraPPTXBuilder.build()` (16 вызовов слайдов), которое
подменяло реальный метод класса. Продуктовый `build()` не исполнялся вовсе; ассерт сводился к
тавтологии «вызов `s10d_promises()` создаёт слайд».

**Стало.** Тест вызывает НАСТОЯЩИЙ, неизменённый `AuroraPPTXBuilder.build()` дважды:
1. Эталон — обычная сборка без `promises_summary` (через `_build_deck`, без патчей).
2. Форсированная сборка — тот же payload без `promises_summary`, но `build` подменён на тонкую
   обёртку `_forced_build`, которая перед вызовом ОРИГИНАЛЬНОГО `build` (сохранённого в
   `orig_build`) точечно устанавливает `self.promises_summary = {"kept": 0, "missed": 0,
   "examples": []}` прямо на объекте — эмулирует «условие показа видит обещания как заданные».
   Дальше вызывается `orig_build(self)` — та же продуктовая функция, ни одна строка её тела не
   переписана.

Assert `n_mut == n_ref + 1` теперь опирается на реальный гейт `if self.promises_summary:
self.s10d_promises()` в строке 4304 `builder.py`.

**Мутация «внести-поймать-откатить» (обязательна).** Временно заменила в продуктовом
`build()` условие `if self.promises_summary:` на `if True:` (безусловный вызов
`s10d_promises()`). Прогнала `pytest tests/test_promises_slide.py -k
"mutation_gate or no_promises_no_extra_slide"` — **оба теста покраснели**: `s10d_promises()`
получил `ps=None` (payload без `promises_summary`) и упал `AttributeError: 'NoneType' object
has no attribute 'get'` на `ps.get("kept")`. Красный результат подтверждает, что сторож
чувствителен к реальной регрессии продуктового кода, а не к своей копии. Правку откатила —
восстановила `if self.promises_summary:`.

(Падение случилось через исключение, а не через несовпадение числа слайдов — это тоже валидный
красный результат: обе версии `build()`, что эталонная, что форсированная, используют один и
тот же мутированный источник, поэтому расхождение проявилось раньше, на стадии рендера
`s10d_promises()`, а не на стадии подсчёта `len(prs.slides)`. Тест всё равно доказал главное —
регрессия не проходит тихо.)

## F-11 (Low) — число и слово не согласованы

**Было.** Заголовок при `missed == 0`: `f"Проверка рекомендаций: все {total} из прошлого
отчёта сбылись"` — для `total=1` печаталось «все 1 … сбылись» (грамматически неверно и по
смыслу нелепо: «все 1»). Подпись героя `"рекомендаций из прошлого отчёта подтвердились на
практике"` — фиксированный текст во множественном числе, неверный при `kept=1`.

**Стало** (по образцу `optimize/frontier.py::_ru_periods`, локально в `s10d_promises`
завела вспомогательную `_ru_is_one(n)` — «оканчивается на 1, кроме 11», тот же приём, что у
существующего `_ru_channels` в этом же файле, `s09_scqar`):
- `total == 1` → отдельная ветка: «Проверка рекомендаций: рекомендация из прошлого отчёта
  сбылась» (без «все», единственное число, женский род прошедшего времени).
- `total > 1` → «все {total} из прошлого отчёта {verdict_verb}», где `verdict_verb` = «сбылась»
  для чисел, оканчивающихся на 1 (кроме 11, например 21), иначе «сбылись».
- Подпись героя — теперь собирается из `rec_of_total` (родительный падеж после «из {total}»:
  «рекомендации» при `total`, оканчивающемся на 1 (кроме 11), иначе «рекомендаций») и
  `confirmed_verb` («подтвердилась»/«подтвердились», согласован с `kept` по тому же правилу).
  Ветка `kept=1, total=1` теперь читается: «1 из 1 / рекомендации из прошлого отчёта
  подтвердилась на практике» — согласовано.
- Ветки `elif kept == 0` («{missed} из {total} не сбылось») и абзацы «Сбылось: N / Не сбылось:
  N» не трогала — это безличные обороты среднего рода, они не рассогласуются числом, аудит их
  цитировал только как соседние строки того же блока, не как отдельный дефект.

**Новый тест** `test_promises_slide_singular_agreement` (kept=1, missed=0, total=1) проверяет
обе исправленные фразы прямо и негативно (старый вариант текста ОТСУТСТВУЕТ).

**Мутация «внести-поймать-откатить» (обязательна).** Временно вернула старый текст в оба места
(заголовок и подпись героя, с комментарием `# МУТАЦИЯ F-11 (временно)`). Прогнала `pytest
tests/test_promises_slide.py -k singular_agreement` — **тест покраснел**:
`AssertionError: assert 'Проверка рекомендаций: рекомендация из прошлого отчёта сбылась' in
'...'` (искомой фразы нет, XML-текст колоды содержит старую форму). Откатила мутацию,
восстановила исправленный текст.
