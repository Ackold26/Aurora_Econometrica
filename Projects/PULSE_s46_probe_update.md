# Маячок s46 — живые пробы отказа обновления

## Задача своими словами
Провести две живые пробы пути обновления приложения и записать дословно, что видит человек:
проба 1 – адрес обновления недоступен (нет сети); проба 3 – манифест без контрольной суммы.
Тексты сверить с ожидаемым: про сеть – совет проверить подключение; без суммы – без обещания, что повтор поможет.

## План
1. Прочитать updater.rs, updateErrorText.js, найти адрес манифеста и сторожей.
2. Поднять приложение `npm run tauri:dev`, подключиться мостом MCP.
3. Проба 1 – адрес на 127.0.0.1:9. Снимок + дословный текст.
4. Проба 3 – локальный сервер с манифестом с пустой суммой. Снимок + дословный текст.
5. Откат временных правок, `git status --short` в отчёт.
6. Отчёт `Projects/PROBE_UPDATE_s46.md`.
