# PULSE — разведка выпускных веток (PR Studio, AI Agency, Media Radar)

## Задача своими словами
Нужно выяснить, из какой ветки реально уходят к клиентам сборки трёх продуктов — PR Studio, AI Agency, Media Radar — потому что у них нет надёжных версионных меток (либо их нет вовсе, либо все метки одинаковые и бесполезные). Без этого знания правку CPD-77 (живой вызов icacls) класть некуда: рискуем закоммитить в мёртвую ветку и создать иллюзию, что дефект закрыт, хотя у клиентов он останется. Только чтение, ни одной правки.

## План
1. Найти реальные пути трёх деревьев (проверить существование, при необходимости поискать по tauri.conf.json).
2. Для каждого — попробовать сортировку тегов по creatordate + branch --contains.
3. Если теги бесполезны — сравнить version в tauri.conf.json / Cargo.toml по всем веткам, сверить с клиентскими версиями.
4. Поискать следы публикации (CHANGELOG, RELEASE, latest.json, updater.rs) по всем веткам.
5. Проверить публичный манифест обновлений, если найдётся.
6. Проверить наличие/отсутствие CPD-77 (голый rg icacls) по всем веткам.
7. git fetch + поиск по истории, не закрыл ли кто-то уже CPD-77.
8. Свести итоги в таблицу, записать отчёт SCOUT_BRANCHES_2026-08-14.md.
