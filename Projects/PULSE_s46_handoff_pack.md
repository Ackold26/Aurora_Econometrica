# МАЯЧОК — s46 передаточный пакет для первого клиента

## Задача своими словами
Собираю фактуру и черновики для комплекта, который поедет первому клиенту на тестирование Aurora AI Econometrica. Не собираю установщик (это оркестратор). Нужно: опись существующих демо-данных, сам демо-проект в пакете, шаблон входного файла со списком столбцов (подтверждённых кодом), сценарий теста на одну страницу, страница про данные/приватность, черновик записки для ИТ-специалиста, черновик краткой инструкции по установке и первым 30 минутам (со ссылками на встроенную справку + процедура выдачи лицензии). Все факты — со ссылкой файл:строка в отчёте.

## План
1. Разведка: прочитать DEMO_DATA_INVENTORY, DEMO_DATA_UPGRADE, DEMO_SCRIPT, DEMO_RUNTHROUGH_CHECKLIST, generate_demo_samples.py → 00_ИНВЕНТАРИЗАЦИЯ.md
2. Демо-проект с данными → demo/
3. Шаблон входного файла (сверка с validator.py + help)
4. Сценарий теста на одну страницу (сверка с шагами мастера в help step-*.html)
5. Страница про данные и приватность (grep reqwest/fetch в src-tauri/src)
6. Черновик записки для ИТ (tauri.conf.json, installMode, пути)
7. Черновик инструкции установка + первые 30 минут + выдача лицензии (settings/+page.svelte, license.rs, online_auth.rs)
8. Отчёт исполнителя
