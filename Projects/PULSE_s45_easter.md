# PULSE s45 — Пасха в панели клиента

## Задача (своими словами)
В движок добавили 13-й праздник (Пасха), фронт-зеркало holiday-calendar.js осталось на 12,
клиент не видит и не может отключить Пасху. Тест-сторож сверяет фронт с копией самого себя,
а не с реальным движком — потому молчит. Нужно: (1) выяснить, доходит ли выбор клиента до
движка и работает ли opt-out — если да, добавить Пасху 13-й записью на правильную позицию;
если нет — не делать мёртвый переключатель, описать чего не хватает. (2) Починить сторож,
чтобы он реально читал список праздников из backend-файла (не dist/_internal копии) и падал
внятно. (3) Ответить на вопрос про N_HOLIDAYS_DEFAULT=12 в ratio-classifier.js — не чинить.

## План
1. Прочитать HolidayControlsPanel.svelte (~90, ~108) — куда уходит выбор.
2. Найти, принимает ли движок список исключаемых праздников (grep в sidecar).
3. Решить развилку: добавить Пасху или нет.
4. Починить тест-сторож — парсинг backend .py файла регуляркой, сверка состава+порядка.
5. Доказать сторож живой: сломать-поймать-откатить.
6. Проверить N_HOLIDAYS_DEFAULT=12 в ratio-classifier.js — ответить фактом.
7. Прогнать npm run test и npm run check.
8. Коммит поимённо, git show --stat HEAD.
