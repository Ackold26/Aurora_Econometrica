# Пульс: правка CPD-79 (снятие чужого процесса по переиспользованному идентификатору)

## Задача своими словами

После правки CPD-77 Эконометрика при запуске берёт идентификатор процесса-движка из собственного файла состояния, а не у держателя порта. Файл переживает падение приложения, номера процессов Windows после перезагрузки раздаёт заново, а проверка перед снятием слабая: сверяются только владелец и «имя содержит python». В итоге приложение может снять `taskkill /T /F` чужой python (Jupyter, Anaconda, соседний продукт Aurora) вместе с деревом потомков — молча, без сообщения. Надо добавить сверку времени создания процесса со `started_at`, заменить порождение `tasklist` на прямой системный вызов, убрать безусловное «python», сверять пользователя и вынести решение в чистую тестируемую функцию.

## План

1. Прочитать `econ_sidecar.rs` и `sidecar_runtime.rs` — весь путь снятия, запись состояния, порядок «порождение ↔ запись».
2. Установить формат `started_at` и фактический порядок операций в `start_sidecar`.
3. Спроектировать `ObservedProcess` + чистую `should_kill(state, observed)`.
4. Системный слой: `GetProcessTimes` + `QueryFullProcessImageNameW` по одному дескриптору.
5. Подсказки имени образа — по продукту, безусловное «python» убрать.
6. Тесты (5 обязательных случаев + граничные).
7. `cargo check` → `cargo test` (один раз, в конце) → запись изменений → отчёт.
