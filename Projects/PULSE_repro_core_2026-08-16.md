# Маячок: ядро воспроизводимости (отпечаток данных + настройка затухания)

## Задача своими словами
Сторонний аналитик по нашему документу не может восстановить модель. Закрываю два пробела
в ЗАПИСИ фактов при обучении: (1) отпечаток исходной таблицы по содержимому, устойчивый к
пересохранению файла, плюс полный SHA-256 самого файла; (2) исходная настройка затухания
(`auto` или явный тип) рядом с разрешённой, с причиной выбора. Чтение этих фактов в
сертификат делает другой исполнитель — не моя часть.

## План шагов
1. Разведка адресов: `modeler.py` (274–278, 150–221, 786, ~1600), `utils/seeding.py:114`.
2. Новый модуль `utils/data_fingerprint.py`: `compute_frame_fingerprint`, `compute_file_digest`.
3. Врезка в `train_model` после чтения таблицы + замер стоимости на реальном файле.
4. Проброс в `environment_snapshot(..., data_fingerprint=None)` → `reproducibility`.
5. `adstock_selection` — снять исходную настройку до мутации резолвера, различить 4 причины.
6. Тесты: устойчивость, чувствительность, совместимость со старой моделью, ошибкоустойчивость.
7. Мутации продуктового кода — проверить, что сторожа краснеют.
8. Отчёт `Projects/REPORT_repro_core_2026-08-16.md`.
