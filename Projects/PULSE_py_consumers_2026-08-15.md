# PULSE — счётчик потребителей Python-пакетов

## Пересказ задачи своими словами

Соседний инструмент `check_crate_consumers.py` уже считает потребителей общих
Rust-крейтов `aurora-platform-core` (нашёл: `aurora_gateway` — 5 потребителей,
`aurora_fleet` — 0, метке 61 день). Но восемь-девять общих слоёв репозитория —
это Python-пакеты (`pyproject.toml`): `aurora_common`, `aurora_reporting`,
`aurora_inference`, `aurora_design`, `aurora_engines`, `aurora_observability`,
`aurora_report_lint`, плюс `aurora_rag` (манифеста нет вовсе — разобраться,
что это). Они вне периметра текущей проверки. Ручная проверка тимлида
показала: потребителей нет ни у одного. Моя задача — сделать этот счёт
машинным: инструмент `aurora-meta/tools/check_py_consumers.py`, который читает
стиль соседа (структура вывода, список исключений, формат нарушений) и ищет
потребителей в 9 деревьях продуктов через requirements*.txt, pyproject.toml,
setup.py/cfg продукта И фактические импорты в исходниках (`import aurora_x`,
`from aurora_x import`). Обязательно исключить из обхода установленный рантайм
Python (sidecar/*/python, venv, site-packages, _internal) — иначе поиск не
уложится по времени. Красный код при 0 потребителей дольше 30 дней (дата —
из git log каталога пакета, тегов может не быть). Обязательное требование:
доказательство мутацией на изолированной фикстуре в scratchpad (не трогая
реальные деревья) — красный кейс (пакет без потребителей, старая дата) и
зелёный кейс (пакет потребляется только импортом).

## План
1. [начато] Прочитать check_crate_consumers.py целиком — стиль, структура. ГОТОВО.
2. Разведка: pyproject.toml-пакеты в aurora-platform-core, что такое aurora_rag,
   структура деревьев продуктов (где requirements/pyproject/исходники движка),
   какие каталоги рантайма исключать по факту (не угадывать — смотреть du).
3. Написать check_py_consumers.py: обнаружение пакетов → поиск потребителей
   (манифесты + импорты, с исключением рантайм-каталогов) → давность по git log
   → таблица + нарушения → список исключений.
4. Прогнать живьём на реальных деревьях, засечь время.
5. Собрать фикстуру в scratchpad: пакет-сирота (старая дата) → должен покраснеть;
   пакет с потребителем-импортом → должен позеленеть с указанием потребителя.
   Прогнать инструмент на фикстуре, оба случая.
6. Написать отчёт TOOL_PY_CONSUMERS_2026-08-15.md.
7. git add поимённо только свой файл в aurora-meta (без коммита/пуша, если не попросят).
8. Отчитаться тимлиду.
