# Маячок – CPD-88 Econometrica

## Задача своими словами
Форма обратной связи в настройках Econometrica шлёт значения переключателя категории латиницей
(`problem`/`suggestion`/`question`), а сервис Google-формы принимает только русские подписи
(«Проблемы»/«Предложения»/«Вопросы») — весь запрос отклоняется с 400, отзывы не доходят никогда.
Нужно перевести значение на бэкенде по эталону Docs Lab (`d9b02ef`), отказаться слать неизвестное
значение с внятным сообщением человеку, и поставить сторож на стык списка `<option>` из разметки
настроек и таблицы перевода (мутационным тестом подтвердить, что сторож ловит забытое значение).

## План
1. Прочитать эталон `d9b02ef` (ROSST_AI_DocMaster) и текущий код feedback.rs / +page.svelte.
2. Завести ветку `cpd88-feedback-fix`.
3. Внести перевод + отказ на неизвестное значение в `feedback.rs`.
4. Проверить/довести показ ошибки в интерфейсе (минимально).
5. Сторож на стык `<option value>` ↔ таблица перевода, по образцу guard_no_regressed_cpd77_cpd79.rs.
6. Мутация: временная 4-я тема без пары → падение с названием → откат разметки.
7. Прогон cargo test + npm run check.
8. Отчёт FIX_CPD88_ECON_2026-08-15.md.
