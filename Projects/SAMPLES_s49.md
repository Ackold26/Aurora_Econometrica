## Как повторить (пошагово, для второго прогона после пересборки движка)

1. Поднять движок: `sidecar/econometrica/dist/econometrica-sidecar/econometrica-sidecar.exe 8799` (фон, ждать `/health` 200).
2. `POST /compute/validate {file_path: ...\synth_fmcg_brand_planning.xlsx, project_dir}` — авто-роли столбцов + `media_plan_detected` (32 периода).
3. `POST /compute/confirm-media-plan {project_dir, confirmed: true}`.
4. `POST /compute/train {project_dir, data_file, kpi_column: "Выручка", media_columns: [4 денежных канала], control_columns: [3], date_column: "Дата", kpi_type: "revenue", use_holidays: true, use_seasonality: true}` — байес, ~46 с на собранной копии (NumPyro/JAX). Если движок пересобран заново — модель обязательно переобучить, старый pickle к новому движку не привязывать не проверив совместимость (`model_version`).
5. `POST /compute/decompose {project_dir}`.
6. `POST /compute/optimize {project_dir, total_budget: null, min_pct: 50, max_pct: 150}` — БЕЗ `forecast_periods` (аналитический режим, подтверждено проектом владельца).
7. `POST /compute/scenario {project_dir, scenario_name: "Базовый план", media_plan: <channels из шага 2>, future_dates: <из шага 2>, carry_in: true}` — весь хвост (32 периода), не подрезать.
8. `POST /compute/planning/save {project_dir, variant_ids: ["Базовый план"], accepted_variant: "Базовый план", disclaimers: [...]}`.
9. `POST /compute/backtest {project_dir}` — дорого (default max_windows=8, каждое окно — полное байесовское переобучение); ждать, не обрывать.
10. `POST /export/html {project_id, model_data (шаг 4), decompose_data (шаг 5, свежий), optimize_data (шаг 6), project_name, project_dir}` → скопировать файл по `path` из ответа.
11. `POST /export/pptx` — аналогично.
12. Пять исходных проверок (текст суммы, PNG-выгрузка Playwright, следы клиента, язык, числа) + шестая (состав разделов) — все на свежесобранных файлах.

Скрипты (рабочие, воспроизводимые) лежат в scratchpad: `run_pipeline.py` (шаги 1-6 с нуля), `run_from_optimize.py` (шаги 6+10-11 без переобучения), `run_forecast_and_backtest.py` (шаги 7-9).
