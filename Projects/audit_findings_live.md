## Проверено и НЕ подтвердилось (ложные гипотезы)

- Импорт `from utils.safe_io import` в `engines/*.py` — соответствует принятому в дереве стилю (`from utils.adstock`, `from utils.seeding`), ImportError нет.
- Расхождение возвращаемого пути с фактическим: `report.rs:910/960` пишут именно уникализованный `path` и его же возвращают; `server.py:2249/2315` возвращают `result` от build_pptx/build_html (с итоговым `path`), а не свой `output_path`.
- Ослепление структурных тестов (класс дефекта Creative Center): текстовых сторожей по исходникам `lib.rs` нет. `include_str!` — только self-scan в `durable_store.rs:1158`, `econ_sidecar.rs:738`, `session/manager.rs:1214` (диффом не тронуты) + `durable_store.rs:648-650` читает `tauri.conf.json` на `identifier`, не на `version`. Старый текст лога `"Workspace cleaned"` не ищется нигде.
- Поле `renamed` в событии: единственный слушатель `FileList.svelte:259` игнорирует payload. Python-тесты не сравнивают словарь целиком (строгое равенство только в `test_default_response_class_sanitizes_bare_dict.py:97`, к затронутым функциям не относится).

## Триаж (проведён лично, зондом по реальному коду — не по слову аудитора)

- **High `copy_dir_into` → понижена до Medium.** Аудитор процитировал тестовый фикстур из этого же диффа («Заключение.docx» в `lib.rs:4238`) как доказательство продакшен-именования — это МОЯ тестовая строка, не реальное имя. Зондом (чтение `auto_save_response`/`convert_to_xlsx`/partial-снимок) подтверждено: все три реальных писателя в `work_dir/exports` дают имя с СЕКУНДНОЙ меткой времени — межсессионная коллизия практически невозможна. `pretensions/nda/contracts/reports` в `sync_exports` — мёртвый код в Econometrica (грепом подтверждено: ничего их не пишет). Архитектурная граница защиты всё равно не помешает — в бэклог, не горит.
- **Medium-High `persist_step_exports` (campaign.rs:474) — НЕ опровергнута.** Не хватило бюджета сессии проверить, стабильны ли имена файлов шагов пайплайна кампании. Приоритетный пункт следующей сессии.
- **Medium `sync_dir_to` второй носитель CPD-69** — подтверждена по коду, риск на будущее (сейчас к `exports` не применяется). В бэклог.
- **Medium структурный сторож бьёт по хелперу, не по команде** — подтверждена по коду. Полноценный фикс требует мока `AppHandle` — не тривиально, оценить усилия отдельно.
- **Low-Medium `media_plan_template` без потолка счётчика** — подтверждена, но бьёт по ВХОДНОМУ шаблону, не по результату клиента — низкий вред.
- **Low diagnostics двойное переименование** — косметика.

**Вердикт:** ни одна находка не достигла уровня «подтверждённый Critical/High с воспроизводимым сценарием на живом коде» — fix-коммит по итогам аудита НЕ требуется.
