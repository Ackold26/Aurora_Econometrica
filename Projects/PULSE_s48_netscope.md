# PULSE s48 netscope

**Задача (своими словами):** Проверить фактами, срабатывает ли для Эконометрики пункт правового документа «обращение к серверам Правообладателя» (справка должна перечислять такие функции). Найти ВСЕ исходящие сетевые обращения в трёх слоях (Rust/src-tauri, фронтенд/src, питон-движок/sidecar), сверить со справкой продукта, проверить утечки ПДн (имя пользователя, машины, файла, фамилия).

**План:**
1. Разведка src-tauri (Rust): reqwest/http клиенты, updater, лицензия, шлюз.
2. Разведка src (фронтенд): fetch/invoke/внешние ссылки.
3. Разведка sidecar/econometrica: requests/httpx/urllib/websockets, narrative_adapter.py, макроданные ЦБ.
4. Найти справку продукта (content-packs/help/docs), сверить.
5. Проверить очистку ПДн (имя файла, владелец, машина) во всех каналах.
6. Записать NETSCOPE_s48.md.
