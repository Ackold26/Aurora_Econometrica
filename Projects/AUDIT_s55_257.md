  привычка «подбить итог продаж») → детектор пуст, проверка `status=warning` (только «пропусков 2,0 %» по медиа), `train_ols` →
  `ok`, **n_obs 49** – 49-й «период» с продажами ×48. То же при итоге «суммы по KPI и 4 бюджетам, средние по 7 прочим столбцам»
  (5 совпадений из 12 < половины): `status=ok`, n_obs 49.
- **Доказательство:**
  ```
  V3_kpi_sum_only    detector=[] status=warning    →  V3_kpi_sum_only.xlsx   status=ok n_obs=49
  V3c_5sums_7avgs    detector=[] status=ok         →  V3c_5sums_7avgs.xlsx   status=ok n_obs=49
  ```

- **Почему «одно совпадение» не случайность:** для неотрицательного столбца с ≥2 ненулевыми значениями выше значение, равное сумме

- **Правка:** считать строку итогом уже при ОДНОМ совпадении, если столбец неотрицателен и выше в нём ≥2 ненулевых значений
