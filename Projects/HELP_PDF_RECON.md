## 5. План реализации
- **Кнопка «Скачать справку (PDF)»** — рядом с `open_help` в CommandPalette/шапке пайплайна;
  Rust-команда открывает статический PDF из resources (паттерн `open_help`, resource_dir + dev fallback).
- **Генерация PDF:** pandoc-паттерн в проекте ЕСТЬ (`claude.rs:672-704 convert_to_pdf`,
  `--pdf-engine=wkhtmltopdf`), но НЕ годится — тихо скипает без pandoc/wkhtmltopdf у пользователя
  (они не бандлятся). Справка одинакова у всех → **генерить PDF ОДИН раз на сборке/релизе
  (pandoc у разработчика или скилл pdf/docx) и зашить готовый файл как bundled resource**
  (как template_*.xlsx и логотипы). Ноль рантайм-риска, ноль новых зависимостей.
- **Переиспользовать:** структуру/стиль HTML (dark, econ-nav.js), словарь glossary.js (SSOT),
  паттерн `tools/sync_help_lists.py` для анти-дрейфа (+ добавить авто-подстановку версии → закрыл бы §2А).
- **Риски:** правка HTML требует пересборки .exe (если нужны частые правки текста без релиза —
  ADR о переносе части в content-pack). `docs/GLOSSARY_v2_1_0.md` (источник glossary.js/html)
  сам на версии 2.1 — сверить контент до правки INV-50. INV-50-правка задевает glossary.js +
  glossary.html + PDF — синхронизировать одним проходом.
