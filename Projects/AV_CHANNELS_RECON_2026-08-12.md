# Разведка: каналы Kaspersky по ложному срабатыванию PDM:Trojan.Win32.Generic

Дата: 2026-08-12. Контекст: неподписанный установщик (258 МБ) удалён Kaspersky Internet Security 21.26 с вердиктом `PDM:Trojan.Win32.Generic` (поведенческая эвристика, компонент System Watcher / Проактивная защита).

## 2. Рекомендуемый канал для нас

**OpenTIP (https://opentip.kaspersky.com/) → «Submit to reanalyze» + одновременно тикет через `support.kaspersky.com/us/common/diagnostics/15898`-инструкцию (файл трассировки + логи System Watcher).**

Почему:
- Это единственный канал, для которого нашлась актуальная официальная инструкция именно под вердикт PDM (диагностика 15898) — он прямо просит артефакты, которые релевантны поведенческому детекту (трассировка, логи System Watcher), а не просто сам файл.
- OpenTIP — публичный портал без необходимости заводить корпоративный аккаунт, самый быстрый старт.
- CompanyAccount имеет смысл параллельно, если после OpenTIP не будет реакции в разумный срок, либо если понадобится юридический статус компании-заявителя (ООО «Платформа Аврора») для более весомого обращения — но это медленнее.
- `false_detection@kaspersky.com` не использовать — не подтверждён как живой адрес.

## 3. Программа белого списка — ЕСТЬ

**Kaspersky Allowlist Program** — https://www.kaspersky.com/partners/allowlist-program

- Участие **бесплатное** для вендоров/разработчиков ПО.
- Даёт: экспертную оценку ПО Kaspersky, подтверждение отсутствия ложных срабатываний, поддержку участников.
- Требования к компании: активный веб-сайт с актуальной информацией, указанный юридический адрес, понятные пользователю функции взаимодействия.
- Требования к ПО: не имитировать интерфейс сторонних приложений или системные сообщения ОС; не рекламировать несвязанное ПО; не обращаться к вредоносным ресурсам; не использовать вводящий в заблуждение текст для принуждения к оплате; не использовать скомпрометированные чужие цифровые подписи.
- Регистрация — через форму на самой странице программы («Register in the program»); отдельного email или прайса на странице не раскрыто.
- 🔴 Устаревшая ссылка `whitelisting.kaspersky.com/whitelist-for-partners-ru`, которая всплывала в старых обсуждениях, сейчас **редиректит на kaspersky.com** — программа переехала, канон — ссылка выше.

**Это для нас важнее разовой жалобы** (как и отметил Антон) — стоит подавать заявку на участие сразу, параллельно с разовым обращением по текущему файлу: разовая жалоба закрывает конкретный инцидент, Allowlist снижает частоту повторов на будущих сборках.

## 4. Ограничение на размер файла

- По данным агрегированного поиска (страницы `opentip.kaspersky.com/Help_ru/Doc_data/SubmittingFile.htm`), лимит загрузки на OpenTIP — **256 МБ**. 🔴 **Не подтверждено первоисточником напрямую** — прямой запрос страницы дважды оборвался по сети (DNS/ECONNRESET), информация взята из выдачи поиска, не из текста самой страницы.
- Наш установщик — 258 МБ, то есть **впритык к границе или чуть выше** — прямая загрузка на OpenTIP может не пройти.
- Способ обойти по факту из практики сообщества (форум kasperskyclub, тема про файл >50 МБ): **не грузить весь инсталлятор** — вычленить конкретный exe/dll-компонент, на который сработал детект (обычно счётные килобайты-мегабайты), и отправить его отдельно через OpenTIP или как вложение в тикет техподдержки/CompanyAccount.
- 🔴 Явного механизма «прислать ссылку вместо файла» на официальных страницах не нашла (только упоминание, что при проблемах с загрузкой пробовать другой браузер/инкогнито). Возможно, такая опция есть в форме тикета CompanyAccount — не подтверждено.

## 5. Ответ на вопрос про подпись (Authenticode)

**Подпись НЕ снимает поведенческие вердикты вроде PDM.** Она работает на другом уровне защиты:

- Authenticode подтверждает **личность издателя** и целостность файла — это адресует SmartScreen «неизвестный издатель» и статические/репутационные эвристики (проверка по хешу/сертификату), где антивирус ещё не видел файл и подозревает его только за анонимность.
- PDM:Trojan.Win32.Generic — детект **System Watcher**, поведенческого компонента, который анализирует, ЧТО делает процесс в системе (изменения реестра, инжекты, сетевые вызовы и т.п.) уже после запуска, независимо от того, подписан файл или нет.
- Подтверждающий сигнал из практики: на GitHub заведено множество issue про PDM false positive на новых сборках легитимных open-source приложений (opencode, wealthfolio, Kiro, Files) — часть из них подписаны, что показывает: подпись снижает вероятность попадания под статический/репутационный фильтр, но не гарантирует иммунитет от поведенческого.
- Косвенно это подтверждает и логика самого антивирусного рынка: подписанные сертификаты неоднократно похищали именно для того, чтобы обойти репутационные проверки — то есть подпись сама по себе не проверяется поведенческим движком как признак безобидности.
- Практический вывод: сертификат ценен (репутация издателя копится со временем, попадание под SmartScreen прекращается быстрее), но он **не решает** конкретно проблему PDM-детекта на новой неизвестной сборке — здесь нужен либо путь через Allowlist Program / OpenTIP-реанализ, либо накопление репутации файла через постепенное распространение.

## 6. 🔴 Чего подтвердить не удалось

- Точный текст официальной страницы `opentip.kaspersky.com/Help_ru/Doc_data/SubmittingFile.htm` про лимит 256 МБ — взят из вторичной агрегации поиска, не с самой страницы (сетевые ошибки при прямом запросе).
- Жив ли адрес `newvirus@kaspersky.com` как рабочий канал приёма файлов.
- Существование адреса `false_detection@kaspersky.com` — не нашла нигде в открытых источниках, похоже на неверный/устаревший.
- Есть ли в форме CompanyAccount или в тикете техподдержки штатная возможность передать ссылку на файл (Google Drive/облако) вместо прямой загрузки — не нашла прямого подтверждения ни за, ни против.
- Точные сроки рассмотрения обращения (форумные темы жалуются на задержки до 10+ дней, но это не официальный SLA).
- Детальный текст формы регистрации в Allowlist Program (какие документы юрлица нужны, какой SLA рассмотрения) — страница описывает условия, но не саму форму.
