# Маячок s45 — Кривые отдачи (заглушка врёт после оптимизации)

## Как я поняла задачу (своими словами)
На шаге «Оптимизация» после успешного расчёта блок «Кривые отдачи» вместо графиков
показывает подсказку «Запустите оптимизацию» – то есть советует сделать уже сделанное.
Надо живым замером выяснить, какая из двух половин условия показа ложна
(`optData?.response_curves` или непустой `scaledParams`), найти звено, где данные теряются,
починить корень, а если рисовать реально нечем – заменить лживый текст на правдивый.

## План
1. Поднять `npm run tauri:dev` в фоне, дождаться моста 127.0.0.1:9223.
2. Параллельно тихой фазе – статическая разведка: кто заполняет `modelData.channelParams`,
   кто пишет/читает `models/latest-params.json`, что кладёт движок в ответ оптимизации.
3. Через мост открыть проект, дойти до «Оптимизации», выполнить расчёт, снять числа:
   ключи `channelParams`, `currentSpend`, наличие и структура `response_curves`, факт `scaledParams`.
4. Однозначный вердикт: какая половина условия ложна и почему → сразу в маячок.
5. Починка корня (хирургически) либо честный текст заглушки (INV-50).
6. Гейты: `npm run test`, `npm run check` (+ pytest из sidecar/econometrica, если тронут движок).
7. Сторож: тест, который падает ДО правки и проходит после (проверить внесением-откатом).
