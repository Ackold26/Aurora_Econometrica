# Маячок: починка формы waterfall в выгрузках

## Задача (своими словами)
Движок отдаёт `waterfall` словарём `{labels, values, types}`, а Rust в двух местах
(`report.rs:717` разметка, `report.rs:1597` лист .xlsx) ждёт массив `[{category,value}]`.
`as_array()` на словаре даёт `None` → оба блока молча не исполняются, лист «Декомпозиция»
и раздел «Вклады в продажи» пропадают из клиентской выгрузки, а вместе с ними мёртвая
правка CPD-104 (сохранённый результат формулы) наконец должна заработать.

## План
1. Прочитать оба места в report.rs + существующий сторож `waterfall_formula_results_are_cached_not_zero`.
2. Написать разбор словарной формы (с обратной совместимостью на старый массив), пропускать `types[i]=="total"`.
3. Применить в обоих местах, сохранить поведение CPD-104 (кэш формул).
4. Переписать сторож на реальную форму движка + добавить проверку присутствия листа «Декомпозиция».
5. cargo test (зелёный), мутационная проверка (откатить правку → сторож должен упасть именно на отсутствии листа), вернуть правку.
6. Собрать книгу на живом demo-fmcg-brand/decomposition.json, прочитать xl/workbook.xml — проверить список листов и суммы долей.
