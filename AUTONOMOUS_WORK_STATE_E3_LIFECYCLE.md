## Цель E3 (из ROADMAP, дословно)
Клиент обновляет данные → переобучение → продукт САМ сравнивает с прошлой моделью:
«ROI ТВ был 3.2 [2.6-3.9], стал 3.4 — стабильно» / «изменился резко — вот причины».
1. Версионирование поколений с метаданными. 2. Сравнение поколений per-channel
ROI/decay/долей С ИНТЕРВАЛАМИ; вердикт «стабильно / сдвиг в пределах интервалов /
резкий сдвиг» (перекрытие CI — критерий, канон Jin: у оценок есть дисперсия).
3. Дрейф: качество СТАРОЙ модели на новых точках падает → «пора переобучить»
(связка с E1). 4. Доставка: карточка «История модели» + раздел отчёта «Что
изменилось с прошлого квартала».
**Критерий готовности:** два поколения на Кагоцеле (обучение 25 мес vs 31 мес) →
корректное сравнение с интервалами; UI-карточка; повторный запуск детерминирован.

## Дизайн-решения (E3-0)
- **D-E3-1 Сравнение через расширение decompose (вариант A, подтверждено чтением):**
  decompose жёстко на models/latest.pkl (стр. 411) и пишет один файл
  results/decomposition.json (стр. 1179). Два additive-параметра —
  `model_path=None` (архивная модель) и `save_results=True` (сравнение не
  перетирает результаты) — переиспользуют ВЕСЬ канонический ROI/CI-путь
  (roi, roi_ci_low/high из posterior/bootstrap, contribution, decay) без
  дублирования формул. Движок сравнения = 2 вызова decompose(save_results=False)
  с ОДИНАКОВЫМИ override'ами (честность сравнения) + диф. Урок хода: реестр
  сначала записал «вариант B» до проверки — исправлено по факту чтения.
- **D-E3-2 Вердикт сдвига:** per-channel: |Δroi| внутри перекрытия CI поколений →
  «стабильно»; CI пересекаются частично → «сдвиг в пределах неопределённости»;
  CI не пересекаются → «резкий сдвиг» + top-3 вероятные причины (новые данные,
  изменение конфигурации каналов, сезонный вклад). Канон Jin 2017.
- **D-E3-3 Дрейф:** score(старая модель, новые точки) через E1-механику
  (predict + MAPE/coverage на хвосте, который старая модель не видела; хвост =
  строки данных новее data-окна архива). Порог: MAPE_new > 1.5×MAPE_train ИЛИ
  coverage_new < 0.6 → «пора переобучить». Пороги документировать честно.
- **D-E3-4 Хранение результата сравнения:** models/generation_compare.json
  (atomic, как backtest.json); PPTX-раздел читает его; без файла раздел не
  рисуется (урок B1 — без wireframe).
- **D-E3-5 Идентификатор поколения:** timestamp архива (params-YYYYmmdd_HHMMSS);
  «данные до» = последняя дата из config/data_coverage снимка, если есть.
