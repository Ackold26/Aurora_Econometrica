Какой режим выбрать: ROI, Эффективность или Смешанный

Режим анализа определяет единицы, в которых медиа-каналы подаются в модель. Это не зависит от KPI — один и тот же KPI (продажи) может быть рассчитан в любом режиме. Правильный выбор влияет на интерпретацию выходных метрик.

ROI режим ₽ / ROI

Все медиа-каналы подаются в рублях (фактические бюджеты спенда). Модель напрямую оценивает финансовую отдачу — ROI (₽ выручки на ₽ вложений) и CPU (₽ на единицу KPI — лид, упаковка, посещение).

Когда использовать
  • Прямые закупки без посредников
  • Данные бюджетов точные и прозрачные
  • ROI / CPU — ключевая отчётная метрика
  • Нужно оправдать маркетинговые расходы перед финансовым директором
Когда не подходит
  • Бартерные размещения или агентские скидки «в конверте»
  • Неизвестная наценка агентства (30–50%)
  • TV-кампании с данными только по GRP, без ₽
  • Бюджет «по медиаплану» значительно расходится с реальным
Результат: ROI и CPU по каждому каналу с доверительным интервалом. Декомпозиция показывает ₽ вклада в продажи.

Эффективность режим TRP / Показы

Медиа-каналы подаются в физических единицах контакта: TRP для телевидения, показы (impressions) для Digital и OOH, клики для Performance. Модель считает долю вклада каждого канала в % от KPI без пересчёта в деньги.

Когда использовать
  • TV-heavy микс без прозрачных бюджетов (закупка по GRP)
  • Бартерные размещения — ₽ данных нет или ненадёжны
  • Brand-кампании, где KPI — охват, узнаваемость
  • Агентские скидки меняют реальную стоимость контакта
Ограничения
  • Нет прямой финансовой метрики ROI (только % вклад)
  • Для оптимизации бюджета нужна дополнительная ставка CPP/CPM
  • Нельзя сравнить «телевизор vs Performance» по стоимости конверсии напрямую
% вклад в KPI Sales share по каналу Saturation кривые
Рекомендация по умолчанию: если сомневаетесь — выбирайте этот режим. Он даёт стабильные оценки вкладов даже при неточных или смешанных бюджетных данных. Переключить режим можно в любой момент — модель пересчитается.

Смешанный (Expert) Expert only

Каждый канал настраивается индивидуально: часть каналов в рублях, часть в физических метриках. Физические каналы требуют ставок конверсии (CPP или CPM) для приведения к единому знаменателю.

Когда оправдан
  • Performance-каналы с точными ₽ + TV с данными только по GRP
  • Опытный аналитик контролирует ставки CPP
  • Необходима унифицированная ROI-оценка при разнородных данных
Предупреждения
  • Добавляет ±10–25% неопределённости в ROI из-за ставок конверсии
  • Требует unit_cost или CPP ставки для каждого физ. канала
  • Сложнее интерпретировать — Manager mode не отображает Expert UI
Важно: этот режим доступен только при включённом Expert mode в настройках. Он не появится в Manager mode — это намеренное ограничение для предотвращения ошибочного использования.

Как переключить режим Шаги

1 Откройте шаг Валидация или Настройки в pipeline — в верхней части страницы находится AnalysisModeSelector.
2 Выберите нужную карточку режима. Модель автоматически сбрасывает результаты и предлагает пересчёт.
3 Для доступа к Смешанному режиму: сначала включите Expert mode в Настройках (иконка шестерёнки), затем вернитесь к AnalysisModeSelector — появится третья карточка.
4 Запустите обучение модели заново. Переключение режима в середине цикла аннулирует предыдущие результаты — это ожидаемое поведение.

Совместимость с проектами v1.3.x Авто-миграция

При открытии проекта v1.3.x программа автоматически определяет режим по ранее выбранным единицам каналов (per-channel input). Никаких ручных действий не требуется.

Конфигурация v1.3.x Результат миграции Toast
Новый пустой проект ROI режим авто Нет
Все каналы в ₽ ROI режим авто Нет
Все каналы в физ. метриках Эффективность режим авто Нет
Часть в ₽, часть в физических Смешанный + Expert mode уведомление Да
Неизвестные / null значения Смешанный + Expert mode уведомление Да
Если после миграции показывается toast об Expert mode — это означает, что ваш проект использовал смешанные единицы. Рекомендуется привести все каналы к единому режиму в шаге Валидация для повышения точности ROI.
