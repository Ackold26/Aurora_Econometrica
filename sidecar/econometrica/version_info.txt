# UTF-8
# Метаданные версии для PyInstaller-сборки econometrica-sidecar.exe.
#
# Без этого файла собранный .exe несёт ПУСТЫЕ VERSIONINFO-поля (нет издателя,
# описания, версии) — Windows Explorer и антивирусные эвристики видят
# безымянный неопознанный бинарь, что повышает подозрительность при
# SmartScreen/AV-сканировании. Правка чисто метаданных, поведения не меняет.
#
# Формат — объект VSVersionInfo из PyInstaller.utils.win32.versioninfo,
# передаётся движку через exec() при сборке с флагом --version-file
# (см. build_sidecar.py). Синтаксис соответствует официальному примеру
# PyInstaller «Version Information» (structs FixedFileInfo/StringFileInfo/
# StringTable/StringStruct/VarFileInfo/VarStruct).
#
# Издатель и copyright — как в оболочке Tauri (src-tauri/tauri.conf.json:
# "publisher": "Aurora Platform LLC", "copyright": "© 2026 Aurora Platform LLC").
# Версия — как в src-tauri/Cargo.toml / tauri.conf.json (2.5.0).
#
# 🔴 Версия здесь СТАТИЧЕСКАЯ строка — при каждом бампе версии продукта обновлять
# И filevers/prodvers, И обе строки FileVersion/ProductVersion ниже вручную.
#
# Язык/кодовая страница таблицы строк: 1049 (ru-RU) + 1200 (Unicode UTF-16),
# т.к. FileDescription/ProductName содержат кириллицу — это должно совпадать
# с языком таблицы, иначе часть просмотрщиков (включая старый Explorer
# properties dialog) показывает описание из таблицы по умолчанию/latin1-мусор
# вместо кириллицы. Hex-ключ StringTable кодирует langID+codepage: 1049 dec =
# 0x0419, 1200 dec = 0x04B0 → '041904B0'. VarStruct('Translation', [...]) —
# те же числа в десятичном виде.
VSVersionInfo(
  ffi=FixedFileInfo(
    filevers=(2, 5, 0, 0),
    prodvers=(2, 5, 0, 0),
    mask=0x3f,
    flags=0x0,
    OS=0x40004,       # VOS_NT_WINDOWS32
    fileType=0x1,     # VFT_APP
    subtype=0x0,
    date=(0, 0),
  ),
  kids=[
    StringFileInfo(
      [
        StringTable(
          '041904B0',
          [
            StringStruct('CompanyName', 'Aurora Platform LLC'),
            StringStruct('FileDescription', 'Aurora AI Econometrica — расчётный движок (Marketing Mix Modeling)'),
            StringStruct('FileVersion', '2.5.0.0'),
            StringStruct('InternalName', 'econometrica-sidecar'),
            StringStruct('LegalCopyright', '© 2026 Aurora Platform LLC'),
            StringStruct('OriginalFilename', 'econometrica-sidecar.exe'),
            StringStruct('ProductName', 'Aurora AI Econometrica Optimizer MMM'),
            StringStruct('ProductVersion', '2.5.0.0'),
          ],
        )
      ]
    ),
    VarFileInfo([VarStruct('Translation', [1049, 1200])]),
  ],
)
