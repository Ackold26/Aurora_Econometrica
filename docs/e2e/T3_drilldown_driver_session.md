# E2E-сценарий: drill-down декомпозиции (Т3) через tauri-мост

> Воспроизводимый сценарий живой приёмки механики свёртки/раскрытия. НЕ CI-тест
> (нужен запущенный dev + MCP-мост 9223). Регрессия механики на уровне данных
> покрыта юнит-тестами (`decomposition-view.test.js`: planViewSeries тождество +
> seriesIdentity groupId); ЭТОТ сценарий проверяет реальное GUI-взаимодействие,
> которое код структурно не докажет. Прогонять в момент живой приёмки с Антоном
> и после правок ChannelTimeline. Метод — AVT-стандарт (клик работает, hover нет).

## Подготовка
1. `npm run tauri:dev` (НЕ `tauri dev` — нужен `tauri.dev.conf.json`, мост 9223).
2. Открыть готовую фикстуру с сезонностью (без MCMC), напр. проект на данных
   `mmx_4groups` / `Venarus` — дойти до шага «Декомпозиция», карточка
   «Динамика по периодам». Проверить мост: `webview_execute_js` → `!!window.__TAURI__`.
3. Grid-элемент графика — обёртка `ExpandableCard` (EChartBase единственный потомок).

## Шаги и ожидаемые результаты

### 1. Свёрнутый вид по умолчанию (4 полосы)
- Прочитать серии графика:
  `webview_execute_js`: достать инстанс echarts и `getOption().series`
  (фильтровать по `stack` — только area-полосы, без `seasonality-pct`).
- **Ожидаемо:** ровно столько area-полос, сколько присутствующих групп (обычно
  4: «База», «Медиа», «Внешние факторы», «Конкуренты»; для MMX без внешних — 2).
- Chips видны: «Развернуть всё» + по одному на группу + «Сезонность, %».

### 2. Клик по chip раскрывает группу
- `webview_interact` click по `[data-drill="БАЗА"]`.
- **Ожидаемо:** серия «База» заменяется на «Базовый уровень» + «Сезонность» +
  «Праздники» (число area-полос растёт на memberCount−1). Chip «База» получает
  `aria-pressed=true`, каретка `▾`. Плавный морф (universalTransition), не скачок.

### 3. Клик по полосе тоже раскрывает/сворачивает
- `webview_interact` click по области полосы «Медиа».
- **Ожидаемо:** «Медиа» разворачивается в отдельные каналы; повторный клик по
  под-компоненту — сворачивает группу обратно.

### 4. «Развернуть всё» / «Свернуть всё»
- Click `[data-drill="__all__"]`.
- **Ожидаемо:** все группы разворачиваются (полос = сумма всех под-компонентов);
  надпись меняется на «Свернуть всё», `aria-pressed=true`. Повторный клик — 4 полосы.

### 5. Тумблер сезонной %-кривой
- Click `[data-drill="seasonality-pct"]`.
- **Ожидаемо:** пунктирная violet-линия на второй (правой) оси «% к базе»
  появляется/исчезает; правая ось симметрична вокруг 0. В tooltip строка
  «Сезонность к базе +X%» (наведение проверять скриншотом — hover синтетикой не идёт).

### 6. Сохранение зума при раскрытии (регресс А-2)
- Потянуть dataZoom-слайдер к окну (напр. центр 40–70%), затем click chip раскрытия.
- **Ожидаемо:** окно зума СОХРАНЯЕТСЯ (не сбрасывается на 0–100%).

### 7. Тождество не ломается визуально
- Скриншот свёрнутого и полностью развёрнутого вида: суммарная высота стека
  (верхняя граница area) в каждом периоде совпадает. Тождество данных — юнит.

## Что проверять глазами (скриншот, 2–3 экрана)
- Цвета групп читаемы, наложение чистое; знакопеременные «Конкуренты» ниже нуля.
- Сезонная кривая не перекрывает подписи оси; каретки/подсветка chips видны.
