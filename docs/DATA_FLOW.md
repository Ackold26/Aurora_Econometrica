# Aurora AI Econometrica — Потоки данных (Data-Flow Disclosure)

> Назначение: техническое описание **всех** сетевых потоков данных приложения для оценки
> соответствия 152-ФЗ (защита персональных данных) и внутреннего комплаенса заказчика.
> Документ описывает фактическое поведение ПО (проверяемо по исходному коду). **Правовая
> квалификация и лицензионный договор/политика обработки ПДн — отдельный документ** (EULA);
> настоящий документ её не заменяет, а служит фактической основой.
>
> Версия продукта: 2.1.0. Редакции: **Локальная** и **Облачная** (см. §1).

---

## 1. Две редакции

| | **Локальная редакция** | **Облачная редакция** |
|---|---|---|
| MMM-анализ (модель, декомпозиция, оптимизация, отчёт, графики) | Локально, на машине пользователя | Локально, на машине пользователя |
| Кабинеты-советники (AI-интерпретация на Claude/Anthropic) | **Отсутствуют** (отключены на этапе сборки) | Присутствуют |
| Передача анализируемых данных третьим лицам | **Нет** | Да — в кабинетах-советниках (с согласия) |
| Целевой сценарий | Чувствительные данные, строгий комплаенс (фарма и т.п.) | Низкочувствительные данные, потребность в AI-интерпретации |

Редакции собираются из одного кода (feature-flag `cloud_advisors`). В локальной редакции
код вызова Claude **не достигается** — гарантия на этапе сборки, не настройка в рантайме (см. §4).

---

## 2. Где выполняются вычисления

**Вся «тяжёлая» математика MMM считается локально**, в Python-процессе (sidecar),
запущенном на машине пользователя. Обмен между интерфейсом и вычислителем идёт по
**локальной петле** `http://127.0.0.1:<порт>` — этот трафик **не покидает машину** и
недоступен из сети (привязка к loopback-интерфейсу 127.0.0.1).

К локальным вычислениям относятся: парсинг загруженных файлов, обучение модели (MCMC),
декомпозиция продаж, оптимизация бюджета, построение графиков, формирование отчётов.
Эти операции **не используют Claude/Anthropic** ни в одной из редакций.

## 4. Локальная редакция: гарантия неисхода анализируемых данных

**Утверждение:** в локальной редакции анализируемые данные (наборы пользователя и любые
производные) **не передаются третьим лицам** и **не покидают машину** — ни в Anthropic, ни
на серверы Aurora, ни куда-либо ещё.

**Техническая основа (проверяемо по коду):**

1. **Единственный канал внешней передачи анализируемых данных — кабинеты-советники на
   Claude.** Все остальные сетевые потоки (C/D/E) передают только служебные метаданные
   лицензирования/версий (см. §5) и физически не содержат анализируемых данных.
2. **Единственная точка вызова Claude** — функции `run_claude` / `run_claude_pipeline`
   (`src-tauri/src/commands/claude.rs`). В локальной сборке (без feature `cloud_advisors`)
   они выполняют ранний возврат с ошибкой **до запуска** клиента Claude — путь к Anthropic
   **статически недостижим** на этапе компиляции, а не блокируется в рантайме.
3. **Кабинет-советник скрыт** во всех точках интерфейса единым серверным фильтром
   (`filter_by_product`), поэтому в локальной редакции его нельзя ни выбрать, ни вызвать.
4. **Автоматические тесты** фиксируют поведение в обеих сборках:
   - `local_edition_hides_all_advisor_cabinets` — локальная сборка не показывает ни одного
     кабинета-советника;
   - `cloud_advisors_const_matches_build_feature` — флаг доступности Claude соответствует
     конфигурации сборки.

**Как заказчик может проверить независимо:** запустить локальную редакцию в среде с
мониторингом сетевого трафика (firewall / прокси-лог) и убедиться, что при работе с
MMM-пайплайном исходящих соединений к доменам Anthropic нет; единственные внешние соединения —
к серверу лицензирования/обновлений Aurora (потоки C/D/E, §5).

---

## 5. Что передаётся даже в локальной редакции (служебные метаданные)

Локальная редакция **не передаёт анализируемые данные**, но для лицензирования и обновлений
обращается к серверам Aurora. Передаётся **минимальный служебный набор**, не содержащий
анализируемых данных и не содержащий персональных данных субъектов из загруженных наборов:

- **Лицензирование (поток C):** хэш аппаратного отпечатка машины (необратимый), технические
  идентификаторы экземпляра/сессии, версии приложения и контента, идентификатор продукта,
  **имя хоста** операционной системы.
- **Обновления (потоки D/E):** хэш отпечатка, продукт, версия, имя файла пака.

**Замечания для оценки 152-ФЗ:**
- Эти потоки **не передают** анализируемые маркетинговые/продажные данные и не передают
  персональные данные субъектов, содержащиеся в наборах пользователя.
- **Имя хоста** ОС теоретически может содержать имя сотрудника (например, `ivanov-pc`) —
  это следует учесть при оценке; передаётся оно серверу лицензирования Aurora.
- Лицензионные/обновленческие соединения можно **полностью заблокировать** на firewall
  заказчика без потери MMM-функциональности (приложение работает офлайн по выданной
  бессрочной/срочной лицензии); это переводит локальную редакцию в режим **нулевого** внешнего
  трафика.

---

## 6. Облачная редакция: дополнительный поток в Anthropic

В облачной редакции активны кабинеты-советники (поток B). При **явном** запуске команды
кабинета контекст задачи (включая фрагменты анализируемых данных, необходимые для
интерпретации) отправляется в Claude (Anthropic) и возвращается ответ. Это:

- происходит **только по инициативе пользователя** (запуск конкретной команды), не фоново;
- требует **согласия на облачную обработку** (фиксируется в EULA — отдельный документ);
- **маршрутизация в российские LLM (резидентность данных) в эту редакцию не входит** —
  обработка идёт в Anthropic.

Для заказчиков с чувствительными данными рекомендуется **локальная редакция**.

---

## 7. Резюме для комплаенс-офицера

- **Локальная редакция:** анализируемые данные обрабатываются **исключительно локально**;
  внешне уходят только служебные метаданные лицензирования/обновлений (§5), которые можно
  заблокировать на firewall без потери функциональности. Передача анализируемых данных
  третьим лицам отсутствует — гарантия зафиксирована на этапе сборки и покрыта тестами.
- **Облачная редакция:** добавляет AI-интерпретацию через Anthropic по явному запросу
  пользователя и с согласия.
- **Правовая квалификация, перечень мер защиты ПДн и условия обработки** — в лицензионном
  договоре / политике обработки ПДн (отдельный документ).
