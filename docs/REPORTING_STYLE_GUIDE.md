# Стайлгайд отчётов MMM Optimizer (PPTX · HTML · XLSX)

> B4 коммерческого аудита, 2026-07-03. Задание Антона: отчёты должны быть
> понятны, легко усваиваемы, красиво оформлены и полезны — эконометрика
> остаётся профессиональной, но доступной маркетологу без матподготовки.
> Канон: Ильяхов «Ясно, понятно» + «Пиши, сокращай» (RAG-библиотека),
> Knaflic «Storytelling with Data», принципы визуальной иерархии.

## Пять правил (SSOT для всех билдеров отчётов)

### 1. Плотность: ни одного полупустого слайда
Слайд или раздел с несколькими строками текста — объединить с соседним.
Каждый элемент экрана тратит внимание читателя (Knaflic: «every element
takes up cognitive load» — убирай всё, что не работает на вывод).
- Секционные перебивки не живут отдельным слайдом, если несут <5 строк
  смысла — секцию открывает плашка на первом содержательном слайде.
- Проверка: если слайд можно пересказать одной строкой — это не слайд,
  а заголовок следующего.

### 2. Язык: русский, короткий, без мусора
По Ильяхову («Пиши, сокращай»): убрать слова-паразиты и канцелярит
(«данный», «является», «осуществляет», «по сути», «следует отметить»),
короткие предложения, одна мысль — одно предложение.
- Англицизмы заменяются русским, когда термин НЕ является именем метода:
  baseline → базовый уровень; lift → прирост; saturation → насыщение;
  Executive summary → Главное; confidential → конфиденциально.
- Профессиональные обозначения (mROAS, R², MAPE, CI, MQS) остаются —
  каждое расшифровано в глоссарии простыми словами.

### 3. В мире читателя
По «Ясно, понятно»: контекст → мир читателя → примеры. Каждое число
сопровождается ответом «что это значит для решения»: не «ESS 478»,
а «выборка достаточна, чтобы доверять интервалам». Статистика без
следствия для бюджета — в приложение, не в основной поток.

### 4. Иерархия: главная мысль видна за секунду
Визуальная иерархия сообщает важность мгновенно («Разработка
интерфейсов»): лид-мысль слайда — крупно/полужирно (action title);
поддержка — обычным; служебное — мелким серым.
- Больших массивов однородного текста нет: максимум 4–5 строк подряд,
  дальше — подзаголовок, список или перебивка.
- В каждом абзаце первая фраза = главная (лид-абзац); выделения
  (полужирный) — только для смысловых якорей, не для украшения.

### 5. Честность превыше красоты (INV-50, связка с B1)
Ни одно упрощение формулировки не должно менять смысл числа. Квалификаторы
(«медиа-вклада», «90% HDI», «в 80% сценариев») не сокращаются ради
компактности. Оговорки о надёжности — часть основного потока, не сноска.

## Иллюстрации (перспектива, решение по месту)
Библиотека шаблонных иллюстраций (~несколько десятков): пиктограммы
каналов (ТВ, диджитал, наружная), концепций (насыщение, отложенный эффект,
базовый уровень, интервал), статусов (надёжно/осторожно/недостаточно).
Реализация: статичные SVG в ресурсах приложения + семантическая привязка
секция→иллюстрация в билдерах. Не фотостоки: единый строгий стиль
(линейные пиктограммы в фирменных цветах). Статус: прототип — после
текстовых правил (B4-2/B4-3).

## Чек-лист приёмки отчёта (для канарейки и ревью)
- [ ] Нет слайдов, пересказываемых одной строкой
- [ ] Нет абзацев длиннее 5 строк без акцента/разбивки
- [ ] Нет англицизмов вне списка профессиональных обозначений
- [ ] Каждый вывод отвечает «что делать с бюджетом»
- [ ] Лид-мысль каждого слайда читается за секунду (action title)
- [ ] Оговорки честности на месте (см. B1-канарейку)
