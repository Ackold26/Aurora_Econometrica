# Backlog — отложено к среднему сроку (3-6 месяцев)

**Создан:** 2026-05-15 после анкеты Антона по приоритетам следующего цикла v2.1.0.

Отложенное здесь — НЕ отменено, просто перенесено к следующему циклу после v2.1.0 (текущий цикл доводки русскоязычного Windows-выпуска).

**Сроки возврата:** через 3-6 месяцев (после завершения v2.1.0 цикла + пилотного использования первыми клиентами).

---

## 1. Английский язык — интерфейс (~50-70 ч)

**Что внутри:**
- Вынуть все русские надписи из ~100 окон в общий словарь (фундамент `src/lib/i18n/` уже заложен)
- Черновой перевод через помощника
- Проверка живого носителя английского
- Проверка эконометрической терминологии специалистом
- Переключатель языка в настройках
- Пилот на иностранном бренд-менеджере

**Триггер возврата:** первый англоязычный клиент в очереди ИЛИ оформление ООО + готовность к международному рынку.

---

## 2. Английский язык — отчёты и шаблоны (~50 ч)

**Что внутри:**
- Перевод сообщений об ошибках с расчётной части
- Английский шаблон отчёта в PowerPoint
- Английский шаблон интерактивного отчёта
- Английский сертификат методологии (юридически чувствительно)
- Проверка фарма-специалистом всей терминологии

**Триггер возврата:** после Этапа 1 (интерфейс) → клиент готов получить отчёт от модели.

---

## 3. Расширенные тесты безопасности (части этапа 4)

**Объём:** ~25 ч
**Триггер возврата:** первый клиент с большим dataset (50+ каналов) ИЛИ перед массовым выпуском.

**Что внутри:**
- 4.2 + 4.3 — тесты на больших объёмах (100+ каналов, 10+ проектов параллельно)
- 4.4 — тест восстановления после сбоя питания
- 4.5 — независимая ревизия безопасности (повторный 4-агентный аудит или внешний специалист)

**Примечание:** 4.1 (замена устаревшего формата сохранения) включён в текущий цикл v2.1.0 и закрывает 95% риска.

## 4. Многопользовательский режим (этап 7)

**Объём:** ~50 ч
**Триггер возврата:** первое агентство (не один бренд-менеджер) попросит совместную работу ИЛИ паттерн от 2+ независимых клиентов.

**Что внутри:**
- Опциональная синхронизация проектов через облако
- Совместный просмотр модели в режиме «только чтение»
- Защита от одновременной записи через сеть
- Уведомления о изменениях в общем проекте
- Пилотное использование командой из 2-3 аналитиков агентства

## Принципы возврата к этому списку

1. **Сигнал клиента** — конкретный запрос или повторяющийся паттерн от 2+ клиентов
2. **Накопленный опыт** — пилоты v2.1.0 выявят какие из отложенных пунктов реально критичны
3. **Свободные ресурсы** — Маша небесная, специалисты, бюджет внешних рецензентов
4. **Стратегия линейки** — решение Антона расширить ICP к EU / командам / другим продуктам

**Суммарно при возврате ко всему backlog:** ~290-320 часов работы (3-6 месяцев календарно при текущем темпе).

Не разбираем этот список «когда будет время» — только по сигналу.
