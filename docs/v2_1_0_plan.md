# План v2.1.0 — следующий цикл доводки

**Создан:** 2026-05-15 после анкеты Антона по приоритетам.
**Цель цикла:** довести Aurora MMM Optimizer до 94% готовности — русскоязычный Windows-выпуск для группы 50-100 клиентов через прямые продажи.

**Стартовая точка:** v2.0.1-rc2 (78% готовности), 947 тестов проходят, ветка `feat/v2.0.0-explicit-mode-wizard`.

**Объём:** ~95-100 часов работы, ~3-4 недели календарно при автономии 75-80%.
