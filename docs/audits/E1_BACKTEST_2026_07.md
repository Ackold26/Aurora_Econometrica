## Критерий готовности ROADMAP — сверка

| Требование §E1 | Факт |
|---|---|
| Rolling-origin, обучение [1..k) → прогноз [k..k+h), k скользит | `run_rolling_backtest`: окна-кварталы без нахлёста (M→3, W→13, D→90 периодов), min_train по режиму (bayesian 20 / OLS 12, ≥ p+2) |
| Coverage 90%-интервала — главная метрика | Две: per-period (канон) + per-window «X из Y кварталов» (язык клиента); канарейка-пересчёт в тестах И в живом зонде — сошлось бит-в-бит |
| Сравнение с наивным, «модель обязана бить» | naive-last + seasonal-naive; сравнение с ЛУЧШИМ; проигрыш → вердикт `worse_than_naive` прямо в заголовке слайда |
| Доставка сразу все слои | POST /compute/backtest (+read_only) → econ_backtest (Rust, таймаут 3600с) → BacktestCard в шаге обучения → слайд №10 PPTX + вердикт-заголовок |
| Честный holdout на Кагоцеле | Живой зонд: bayesian, 3 окна × ~8с (24с всего, JAX-кэш), coverage 0/9, MAPE 47.8% vs сезонный наивный 18.7% → worse_than_naive |
| Coverage сверен канарейкой | Пересчёт из per_period в тестах (2 канарейки) и в зонде — расхождений 0 |
| N<3 окон → «истории недостаточно» | status='insufficient' (HTTP 200 — результат, не сбой); карточка показывает плашку, слайд не рисуется |
| Никакого in-sample вранья | Обучение окна не видит будущего; метрики только по holdout; у слайда НЕТ wireframe-режима по построению (канарейка B1 расширена) |

## Главная находка хода (методологическая, исправлена)

**Интервал СРЕДНЕЙ ≠ ПРЕДИКТИВНЫЙ интервал.** Первый живой зонд дал
coverage 0/9 при ширине интервалов ±5%: bayesian-путь брал HDI сценария —
неопределённость параметров, без шума наблюдения ε_t. Против такого интервала
coverage проваливается даже у честной модели. Исправлено по канону posterior
predictive (Gelman BW): var_pred = var_mean + σ², σ ≈ in-sample RMSE окна,
полуширины расширены квадратурой (`_widen_pi_with_noise`), тотал окна ⊕ √h·σ.
Метод честно подписан `posterior_predictive_90` (при недоступном RMSE —
`posterior_hdi_90_mean_only`). OLS-путь не менялся: conformal уже включает
остатки (синтетика: coverage 100%).

Точный путь — sigma-samples в pickle (per-draw noise) — зафиксирован
кандидатом на E3 (additive-поле, обратная совместимость не страдает).

**Родственный класс для проверки (передано в UX-волну):** CI-веер сценариев
(MultiScenarioChart) и forecast-fan — подписаны ли как интервал «прогноза»
или «средней»? (F-E1-4 в реестре).

## Содержательная находка о реальном проекте (для пилотов)

Модель реального Kagocel-проекта (обучена 24.06, 31 месяц, БЕЗ сезонных
контролов) на квартальном holdout: продажи противопростудного пика ноя–янв
(1.62 млрд) и летнего дна (0.59 млрд) моделью не различаются — прогноз ~1.0–1.1
млрд везде. MAPE 47.8% против сезонного наивного 18.7%. **Витрина честно
говорит: этой конфигурации нельзя доверять квартальные прогнозы.** Раньше
продукт этой правды не показывал. Практический вывод для пилотов: включать
сезонность/праздники в конфигурацию модели — иначе витрина справедливо
забракует (и будет права).

## Решения, принятые самой (обоснование в реестре D-1..D-10)

Авто-запуск при переобучении отложен в E3 (5× удорожание обучения против
пометки устаревания — пометка реализована); окна без нахлёста = кварталы;
сравнение со строжайшим наивным; результат хранится в models/backtest.json
(atomic, fsync); слайд после методологии со сдвигом нумерации только при
живой витрине; отдельный Rust-клиент 3600с.

## Хвосты (зафиксированы, не блокируют)
