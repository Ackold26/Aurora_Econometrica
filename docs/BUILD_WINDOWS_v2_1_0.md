## Цифровая подпись

### Сейчас (2026-05-16)

ООО не оформлено → EV Code Signing сертификата нет.

Установщик собирается **без** цифровой подписи. Антивирусы (особенно Windows Defender SmartScreen) будут показывать предупреждение «неизвестный издатель». Это известное ограничение пилотной фазы.

Для смягчения:
- В письме клиенту прилагать инструкцию «как разрешить запуск неподписанного установщика»
- Сборка проходит smoke-test self-signed через скрипт (см. ниже)

### Когда ООО будет оформлено

1. Получить EV Code Signing сертификат через аккредитованный CA (Certum, GlobalSign, SSL.com)
2. Установить сертификат в Windows certificate store (LocalMachine\My)
3. Извлечь SHA-1 thumbprint:
   ```powershell
   Get-ChildItem -Path Cert:\LocalMachine\My | Where-Object { $_.Subject -like "*Aurora*" }
   ```
4. Задать переменную окружения:
   ```powershell
   $env:SIGNING_CERT_THUMBPRINT = "<SHA-1 thumbprint>"
   ```
5. Подписать установщик:
   ```powershell
   .\scripts\build\sign_installer.ps1 -InstallerPath <path-to-installer.exe>
   ```

### Проверка инфраструктуры без сертификата

```powershell
# Dry run — показывает signtool команду без выполнения
.\scripts\build\sign_installer.ps1 -InstallerPath <path> -DryRun

# Self-signed smoke test — проверяет что signtool найден и работает
.\scripts\build\sign_installer.ps1 -InstallerPath <path> -UseSelfSigned
```

## Тестовая установка в чистом окружении

**Цель:** проверить что установщик содержит **всё нужное** — без зависимости от Python, Node, библиотек, которые могут оказаться установленными на рабочей машине разработчика.

### Почему не на основной машине

На текущей машине Антона стоит Python, Node, Tauri CLI, все библиотеки. Если в bundle забыли упаковать какой-то DLL или Python-модуль — приложение «подхватит» его из системного PATH и заработает. На машине клиента — упадёт.

Нужно **чистое окружение без этих зависимостей**.

### Основной путь: Windows Sandbox (рекомендуется)

Встроенная фича Windows 11 Pro / Enterprise. Стартует за 20-30 секунд, при закрытии всё стирается.

**Включить (один раз):**
1. Win+R → `optionalfeatures` → отметить «Песочница Windows» → ОК → перезагрузка

**Запуск проверки:**
1. Пуск → Песочница Windows
2. Перетащить установщик `.exe` в окно песочницы (через буфер обмена или drag-drop)
3. Запустить → SmartScreen «Подробнее» → «Выполнить в любом случае»
4. Принять путь по умолчанию
5. Запустить из меню Пуск песочницы
6. Прогнать чеклист ниже

После теста — просто закрыть окно. Песочница не оставляет следов.

### Альтернатива 1: новый профиль пользователя

Если Sandbox недоступен (Home edition или отключён в политике):

1. Создать тестового юзера в Windows (Settings → Учётные записи → Семья)
2. Войти под ним
3. Установить — Python и Node будут видны через системный PATH, но user-level пакеты не сработают

Этот вариант **слабее** — основные системные deps остаются доступны. Использовать только если Sandbox недоступен.

### Альтернатива 2: виртуальная машина

Если что-то не воспроизводится в Sandbox (например для проверки offline-режима с полностью отключённым интернетом, или для записи скриншотов с разрешением отличным от хоста):

- Создать VM Windows 10 21H2 или Windows 11 23H2
- Снять snapshot до установки
- Отключить интернет в VM
- Скопировать установщик через shared folder

Это **запасной** вариант. Sandbox должен покрыть 90% сценариев.

### Установка (в любом из окружений)

1. Запустить .exe
2. SmartScreen: «Подробнее» → «Выполнить в любом случае» (установщик неподписанный пока ООО не оформлено)
3. Принять путь установки по умолчанию (`C:\Program Files\Aurora AI Econometrica`)
4. Подождать завершения установки (30-60 сек)
5. Запустить приложение из меню Пуск

### Проверки в чистом окружении

- [ ] Приложение запускается без ошибок «vcredist not found», «Python missing», «DLL not found»
- [ ] Главный экран показывается, локализация русская
- [ ] Кнопка «Новый проект» работает
- [ ] Загрузка тестового файла (Кагоцел РФ+ Excel) проходит
- [ ] Автоопределение каналов отрабатывает
- [ ] Помощник проходит все 6 шагов
- [ ] Запуск модели проходит, не падает
- [ ] Результаты отображаются (декомпозиция, рекомендации)
- [ ] Сохранение проекта работает, файл создаётся в `%APPDATA%\aurora-econometrica-gui\projects\`
- [ ] Закрытие + повторное открытие приложения восстанавливает проект
- [ ] Видна версия 2.1.0-rc1 в Settings → About

### После проверки

- Если что-то упало — сохранить логи Python sidecar (`%APPDATA%\aurora-econometrica-gui\logs\`) до закрытия песочницы (через буфер обмена / shared folder)
- Сделать скриншоты ключевых экранов для лендинга
- Sandbox закрыть — следов не остаётся; VM — восстановить snapshot
