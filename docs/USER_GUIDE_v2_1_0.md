## 1. Кому это нужно

### Для чего этот инструмент

Aurora MMM Optimizer — это программа для анализа маркетинга. Она отвечает на три практических вопроса:

1. **Какой канал реально приносит продажи?** Не интуиция, а математика на ваших данных.
2. **Где сейчас деньги тратятся неэффективно?** Какой канал убыточен, какой насыщен до предела.
3. **Что изменится, если перераспределить бюджет?** Прогноз с оценкой вероятности.

Раньше такой анализ называли «маркетинг-микс моделирование» и заказывали у специализированных агентств. Это занимало 2–4 месяца и стоило от 500 000 ₽. Aurora делает то же самое на вашем компьютере за 15 минут.

### Кому подходит

Инструмент сделан для вас, если:

- Вы планируете рекламный бюджет и хотите понять, куда вложить следующий рубль.
- У вас есть исторические данные о рекламных затратах (или контактах) и продажах — хотя бы за год.
- Вы хотите обосновать решения перед руководством цифрами, а не ощущениями.

Инструмент подходит для категорий: лекарственные препараты (ОТС), FMCG (продукты, косметика, бытовая химия), B2B (промышленные товары, финансовые услуги).

### Чего инструмент не делает

- Не подключается к вашей рекламной кабинете автоматически — данные вводите вы.
- Не считает «атрибуцию последнего клика» — он считает системный вклад каждого канала в продажи.
- Не заменяет здравый смысл. Модель — это помощник, а не оракул.

## 2. Что нужно перед стартом

### Формат данных

Данные загружаются в формате **Excel (.xlsx)** — обычная таблица. Минимальный набор колонок:

| Колонка | Что туда писать | Пример |
|---|---|---|
| Дата / Неделя | Понедельник каждой недели ИЛИ порядковый номер | 2024-01-08 или 1, 2, 3… |
| Целевой показатель | Ваши продажи в каждую неделю | 12 500 (упаковок) или 4 200 000 (рублей) |
| Канал 1 | Бюджет (₽) или контакты (GRP, показы, клики) | 2 500 000 или 145 |
| Канал 2 | То же самое | 890 000 или 12 400 000 |
| … | … | … |

**Важно:**
- Одна строка = одна неделя. (Месячные данные тоже принимаются, но недельные — точнее.)
- Нет пропусков в целевом показателе. Для каналов пропуски допустимы (ноль = не запускали).
- Не нужны специальные формулы или макросы. Простая таблица с числами.

### Минимальный объём наблюдений

| Число каналов | Минимум наблюдений | Рекомендуется |
|---|---|---|
| 2–3 канала | 52 недели (1 год) | 78–104 недели (1,5–2 года) |
| 4–6 каналов | 78 недель (1,5 года) | 104–156 недель (2–3 года) |
| 7+ каналов | 104 недели (2 года) | 156+ недель (3+ года) |

Меньше данных = шире доверительные интервалы = менее точные выводы. Aurora работает и с малыми выборками, но предупредит об ограничениях.

### Что ещё пригодится

- **Маржа на единицу продажи** (если продаёте в штуках): цена − себестоимость. Нужна для вердикта «прибыльный / убыточный».
- **Отраслевая категория**: Aurora автоматически подберёт параметры для фармы, FMCG или B2B.
- **Пример файла**: в Aurora есть встроенный пример (кнопка «Загрузить пример» на стартовом экране), если хотите сначала попрактиковаться.

## 3. Первая модель за 15 минут

### Шаг 1. Откройте Aurora и создайте проект (1 минута)

Запустите **Aurora MMM Optimizer** с рабочего стола.

[SCREENSHOT: Стартовый экран Aurora — кнопки «Новый проект» и «Загрузить пример»]

На стартовом экране нажмите **«Новый проект»**.

Введите название проекта — например, «Кагоцел 2024». Нажмите **«Создать»**.

---

### Шаг 2. Загрузите данные (2 минуты)

Появится экран загрузки данных.

[SCREENSHOT: Экран загрузки — область перетаскивания файла с иконкой Excel]

**Вариант А:** Перетащите ваш файл Excel прямо в окно программы.

**Вариант Б:** Нажмите **«Выбрать файл»** и найдите файл через стандартный диалог Windows.

Aurora покажет превью первых пяти строк таблицы. Проверьте, правильно ли определились:
- Колонка с датой (подсвечена синим)
- Колонка с продажами (подсвечена зелёным)
- Колонки каналов (подсвечены оранжевым)

[SCREENSHOT: Превью загруженных данных с цветной подсветкой колонок]

Если Aurora что-то определил неверно — нажмите на заголовок колонки и выберите правильный тип из списка.

Нажмите **«Далее»**.

---

### Шаг 3. Подтвердите каналы (2 минуты)

Aurora автоматически распознал ваши рекламные каналы и предложил их классификацию.

[SCREENSHOT: Список каналов с иконками и типами — «Брендовый» или «Результативный»]

Для каждого канала отображается:
- **Название** (из заголовка вашей колонки)
- **Тип** — «Брендовый» (ТВ, наружная реклама, ОЛВ) или «Результативный» (контекст, таргет, аффилиаты)
- **Единица измерения** — рубли, GRP, показы, клики

Проверьте классификацию. Если тип неверный — нажмите на него и выберите нужный. Это важно: от типа зависят начальные параметры [остаточного эффекта](GLOSSARY_v2_1_0.md#остаточный-эффект-adstock-carryover).

Нажмите **«Подтвердить»**.

---

### Шаг 4. Укажите KPI и категорию (3 минуты)

Это самый важный шаг настройки.

[SCREENSHOT: Экран настройки KPI — поля «Целевой показатель», «Тип метрики», «Маржа»]

**Целевой показатель** — уже выбран из вашей таблицы. Проверьте.

**Тип метрики:**
- Если продаёте в **рублях** (выручка, GMV, прибыль) — выберите «Денежный».
- Если считаете **штуки** (упаковки, лиды, регистрации) — выберите «Штуки».

**Маржа на единицу** (только для «Штуки»): введите, сколько рублей приносит одна проданная единица. Например, цена упаковки 200 ₽, себестоимость 80 ₽ → маржа = 120 ₽.

Под полем Aurora сразу объясняет: «Канал с CPU < 120 ₽ прибыльный. CPU > 120 ₽ — убыточный.» Это и есть ваш порог. Подробнее о [CPU](GLOSSARY_v2_1_0.md#cpu-стоимость-единицы) — в глоссарии.

**Отраслевая категория** — выберите из списка. Доступные варианты:
- OTC-фарма (безрецептурные препараты)
- FMCG — продукты питания
- FMCG — косметика и гигиена
- FMCG — бытовая химия
- B2B — промышленные товары
- B2B — финансовые услуги
- Другое

[SCREENSHOT: Выпадающий список отраслей с выбранным пунктом «OTC-фарма»]

Нажмите **«Далее»**.

---

### Шаг 5. Запустите расчёт (0,5 минуты + ожидание ~2 минут)

Вы увидите итоговый экран с параметрами проекта. Проверьте всё ещё раз.

[SCREENSHOT: Сводный экран перед запуском — название, каналы, KPI, категория, кнопка «Запустить»]

Нажмите **«Запустить расчёт»**.

Появится прогресс-бар. Расчёт занимает от 1 до 5 минут в зависимости от объёма данных и мощности компьютера. Компьютер может немного шуметь вентилятором — это нормально, идёт интенсивный математический расчёт.

[SCREENSHOT: Прогресс-бар с сообщением «Строится модель… 60%»]

Пока идёт расчёт — можете выпить кофе.

После завершения Aurora автоматически откроет вкладку **«Результаты»**.

---

### Шаг 6. Сохраните проект

Нажмите **Ctrl+S** или кнопку «Сохранить» в верхней панели. Проект сохранится в папку `Документы\Aurora MMM Optimizer\`. Вы сможете открыть его позже и сразу увидеть результаты.

## 4. Как читать результат

### Вкладка «Декомпозиция»

[SCREENSHOT: Вкладка «Декомпозиция» — стопчатый график по неделям]

На этом графике — история ваших продаж, разложенная по источникам.

**Что смотреть:**

- **Серая зона (нижняя)** — [базовые продажи](GLOSSARY_v2_1_0.md#базовые-продажи-base-sales). Столько продали бы без рекламы. Это ваш «фундамент бренда».
- **Цветные зоны выше** — вклад каждого рекламного канала.
- **Общая высота столбца** — фактические продажи за неделю.

**Что это значит на практике:**

Если базовые продажи составляют 50%+ — у вас сильный бренд, реклама работает «на усиление». Если меньше 25% — бизнес очень зависит от рекламного давления, без него продажи упадут резко.

**Интерактивность:** нажмите на любую зону — появится детальная карточка канала за выбранную неделю.

---

### Вкладка «Окупаемость каналов»

[SCREENSHOT: Таблица каналов с колонками «Вклад», «Стоимость упаковки», «Вердикт»]

Главная таблица с вердиктом по каждому каналу.

**Колонки таблицы:**

| Колонка | Что значит |
|---|---|
| Вклад (упак / ₽) | Сколько продаж принёс этот канал за весь период |
| Затраты | Ваш бюджет на канал |
| CPU (₽/упак) или ROI | Стоимость упаковки или возврат на рубль |
| Интервал | Диапазон неопределённости (90% [вероятность](GLOSSARY_v2_1_0.md#доверительный-интервал-posterior-ci)) |
| Вердикт | Прибыльный / Убыточный / На грани |

**Как читать вердикт:**

- **Зелёный «Прибыльный»** — CPU ниже маржи, которую вы задали. Этот канал окупается.
- **Красный «Убыточный»** — CPU выше маржи. На каждой упаковке теряете деньги.
- **Жёлтый «На грани»** — CPU близко к марже. Требует наблюдения.

**Обратите внимание на интервал.** Если диапазон очень широкий — данных недостаточно для уверенного вывода по этому каналу. Не принимайте сильных решений по таким каналам.

---

### Вкладка «Диагностика»

[SCREENSHOT: Вкладка диагностики — R-hat, ESS, R²]

Это техническая проверка качества модели. Вам не нужно понимать каждое число — просто смотрите на цвета.

| Показатель | Зелёный | Жёлтый | Красный |
|---|---|---|---|
| [R-hat](GLOSSARY_v2_1_0.md#r-hat-сходимость-mcmc) | < 1,05 | 1,05–1,1 | > 1,1 |
| [R²](GLOSSARY_v2_1_0.md#r²-коэффициент-детерминации) | > 0,75 | 0,5–0,75 | < 0,5 |

Если все зелёные — результатам можно доверять. Если хотя бы один красный — читайте раздел «[Когда обратиться за помощью](#6-когда-обратиться-за-помощью)».

---

### Вкладка «Параметры каналов»

[SCREENSHOT: Карточка одного канала — кривая отклика, период затухания, насыщение]

Здесь — «характер» каждого канала по мнению модели.

**Кривая отклика** ([Response Curve](GLOSSARY_v2_1_0.md#кривая-отклика-response-curve)): как меняются продажи при изменении бюджета. Вертикальная линия — ваш текущий бюджет на кривой.

**Насыщение** ([Saturation](GLOSSARY_v2_1_0.md#насыщение-saturation)): светофор — зелёный (есть куда расти), жёлтый (в норме), красный (перегружен).

**[Период полураспада](GLOSSARY_v2_1_0.md#период-полураспада-half-life)**: через сколько недель эффект канала уменьшится вдвое после остановки кампании.

## 5. Сценарии «что если»

### Что это и зачем

Сценарии — это ваша «лаборатория» для проверки гипотез перед тем, как потратить реальные деньги. Вы двигаете слайдеры бюджета — Aurora мгновенно пересчитывает прогноз продаж.

[SCREENSHOT: Экран сценариев — слайдеры бюджета слева, прогноз продаж и диапазон справа]

### Как пользоваться

**Шаг 1.** Перейдите на вкладку **«Сценарии»** в разделе результатов.

**Шаг 2.** Вы увидите текущий бюджет каждого канала. Слева — слайдер или поле для ввода числа.

**Шаг 3.** Измените значение любого канала. Прогноз справа обновится автоматически.

**Шаг 4.** Смотрите на прогноз:
- **Центральная цифра** — наиболее вероятный результат.
- **Диапазон в скобках** — где может оказаться реальный результат с вероятностью 90%.
- **Вероятность (%)** — шанс достичь или превысить этот результат.

**Шаг 5.** Нажмите **«Сохранить сценарий»** — и он появится в списке рядом с текущим планом. Можно сохранить несколько сценариев и сравнить их.

### Типичные задачи для сценариев

**«Что если срезать контекст?»**
Снизьте бюджет контекстной рекламы на 30–50%. Посмотрите, как падает прогноз. Если падение незначительное — контекст можно срезать безопасно.

**«Что если добавить бюджет в онлайн-видео?»**
Увеличьте бюджет онлайн-видео. Aurora покажет, сколько дополнительных продаж это принесёт и с какой вероятностью.

**«Тот же бюджет, но иначе распределённый»**
Уменьшайте одни каналы и увеличивайте другие, сохраняя общую сумму. Ищите комбинацию с максимальным прогнозом. Aurora также предложит оптимальное распределение автоматически — кнопка **«Оптимизировать»**.

### Предупреждение о безопасном коридоре

Когда вы задаёте бюджет, сильно отличающийся от исторического — Aurora предупредит жёлтым или красным цветом на слайдере. Это значит: «таких бюджетов в данных не было, прогноз менее надёжен». Подробнее — в глоссарии: [безопасный коридор](GLOSSARY_v2_1_0.md#безопасный-коридор).

## 6. Когда обратиться за помощью

### Частые ошибки и что делать

---

**Ошибка: «Файл не распознан» при загрузке Excel**

Причина: файл содержит несколько листов, формулы или объединённые ячейки.

Решение: скопируйте нужные данные в отдельный лист, убедитесь, что все ячейки — числа (не текст). Сохраните как `.xlsx`.

---

**Ошибка: «Недостаточно данных для надёжной модели»**

Причина: меньше 52 наблюдений (недель) или слишком много каналов при малой выборке.

Решение: если данных правда мало — Aurora всё равно запустит расчёт, но доверительные интервалы будут широкими. Уменьшите число каналов: объедините похожие (например, все performance-каналы в один) или уберите каналы с нулями в большинстве недель.

---

**Результаты выглядят странно: один канал даёт 90%+ всех продаж**

Причина: мультиколлинеарность — два канала всегда запускались вместе и модель не может их разделить.

Решение: посмотрите на данные — есть ли каналы, которые всегда работали синхронно? Попробуйте объединить их в один «брендовый» или «performance» канал.

---

**R-hat > 1,1 (красный в диагностике)**

Причина: модель не сошлась — вероятно, данные нестабильны или каналов слишком много относительно объёма данных.

Решение:
1. Уберите каналы с менее чем 10 ненулевыми неделями.
2. Обратитесь в поддержку через кнопку «Помощь» в программе.

---

**Средняя ошибка прогноза (MAPE) выше 15%**

Причина: модель плохо объясняет ваши данные. Возможно, упущен важный фактор.

Решение: подумайте, что ещё влияло на продажи в вашем периоде? Сезонность (Aurora учитывает автоматически), промоакции, ценовые изменения, выход нового конкурента? Если есть данные о дополнительных факторах — добавьте их как отдельные колонки.

---

**Программа зависла или выдаёт техническую ошибку**

Решение:
1. Закройте и откройте программу снова.
2. Найдите папку `Документы\Aurora MMM Optimizer\Logs\` — там файл с ошибкой.
3. Отправьте этот файл в поддержку: `support@auroraai.pro`.

---

### Как обратиться в поддержку

**Электронная почта:** `support@auroraai.pro`

**Что написать в письме:**
- Версию программы (меню → «О программе»)
- Что делали, когда возникла ошибка
- Прикрепите файл из `Документы\Aurora MMM Optimizer\Logs\`
- Если удобно — скриншот экрана с ошибкой

Время ответа: 1 рабочий день.

---

### Что НЕ нужно делать

- Не редактируйте файлы в папке `AppData` вручную — это повредит данные проекта.
- Не переименовывайте файл проекта (`.auroramodel`) вне программы.
- Не отправляйте приложение на удалённый диск во время работы — только после сохранения и закрытия.

## Конвертация в PDF

Aurora создаёт отчёт в формате `.html` с возможностью печати. Для конвертации в PDF есть несколько вариантов — выберите удобный.

---

### Вариант А: Через браузер (самый простой)

1. В Aurora нажмите **«Экспортировать отчёт»** → откроется страница в браузере.
2. Нажмите **Ctrl+P** (печать).
3. В списке принтеров выберите **«Сохранить как PDF»** (Microsoft Print to PDF или Chrome PDF).
4. Нажмите «Сохранить».

Подходит: всегда, без установки дополнительных программ.

---

### Вариант Б: Через pandoc (для продвинутых)

[pandoc](https://pandoc.org) — бесплатный инструмент конвертации документов.

**Установка:**
```
winget install pandoc
```

**Конвертация:**
```
pandoc report.html -o report.pdf
```

Подходит: если нужен точный контроль над форматированием, или вы хотите автоматизировать конвертацию.

---

### Вариант В: Через Word

1. Откройте отчёт в браузере.
2. Выделите всё (Ctrl+A), скопируйте (Ctrl+C).
3. Вставьте в Word (Ctrl+V).
4. В Word: Файл → Сохранить как → PDF.

Подходит: если нужно добавить логотип компании или отредактировать текст перед финальной версией.

---

### Вариант Г: Через weasyprint (качественный PDF)

[WeasyPrint](https://weasyprint.org) генерирует PDF с точным сохранением стилей.

**Установка:**
```
pip install weasyprint
```

**Конвертация:**
```
weasyprint report.html report.pdf
```

Подходит: если нужно профессиональное качество для презентации клиенту или руководству.

---

> Примечание: саму конвертацию выполняет Антон или пользователь. Aurora только создаёт исходный HTML-отчёт.
